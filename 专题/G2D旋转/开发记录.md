## 1. 要解决什么

旋转走 **G2D**，不要软旋当主路径。对齐 H133-dz 原厂 LVGL：

```
use_phy_addr = 1
laddr        = finfo.smem_start   /* 可以为 0，这是 IOVA 起点 */
```

不要 `FBIOGET_DMABUF` / `FBIO_GET_IONFD`。

---

## 2. 原厂控制流

```
LVGL 画 ion rotatefbp
flush_cache
G2D_CMD_BITBLT_H  flag_h=旋转角（90→G2D_ROT_270）
  src = rotatefbp_phy
  dst = smem_start，clip.y = fbindex * yres
  两边 use_phy_addr=1
失败 → CPU
FBIOPAN
```

H133 G2D 走 RCQ：`flag_h & 0xff00`（含 `G2D_ROT_0=0x400`）进 **rotate 硬件**。页拷的 `G2D_ROT_0` 也走 rotate。

内核 `g2d_blit_h` 在 `use_phy_addr=1` 时 **不** `g2d_dma_map`，`laddr=0` 合法。  
`use_phy_addr=0` 才按 fd map；原厂 LVGL **不用**这条。

---

## 3. 三笔分别干什么

第一笔 `01f2f8f9d` / 补丁 `0001`：

- 去掉 `split_fb`，DIRECT_MODE + `FBIOPAN`
- 开 `G2D` / `G2D_ROTATE`；`CACHE` 在 **defconfig** 保持关
- `libawion` 依赖；`g2d_image_enh=116`，`g2d_blt_h=236`
- blit 走 `smem_start`（这条才是原厂）

第二笔 `37bf0adfb` / 补丁 `0002`（**弯路，不要当定稿**）：

- 当时把 `smem_start=0` 当成 phy blit 会 `dma_buf_id(-1)`
- fb：`FBIOGET_DMABUF`，旋缓冲：`SunxiMemGetBufferFd`
- blit 两边 `use_phy_addr=0`
- 用户态 `close(fb_dma_fd)` 会放掉驱动还在 mmap 的那块 ION，应用重启 Kernel Oops

第三笔 / 补丁 `0004`（**产品路径**）：

- 撤回 fd，改回 `use_phy_addr=1` + `smem_start`
- 不再把 IOVA 0 当失败
- ioctl 失败才 CPU 旋

`disp_drv.rotated` 必须 `NONE`（logical_size 已换宽高）。不要设 90/270。

产品多出来的 `lv_logical_override`：逻辑分辨率 ≠ 物理页时 G2D 可能裁切/失败再退 CPU。保留。

## 4.1 换板 / 远端有哪些 lunch

G2D IOVA blit 是 IOMMU 板上的公共通路，**不是**某块屏的专有补丁。换板 **不用改 blit**。

`xia_yixian` / `xia_g2d_rotate` **只有**：

- `h133-p1_nor` / `_8733` / `_JYY070`（第一笔已开 G2D + DIRECT_MODE，含 defconfig **和** ota/qa）
- `h133-p2`（**保持关** G2D / DIRECT_MODE）

**没有** ZS101 / JL_M101 / LQ*。ZS101 实测是在 **本仓库本地** lunch 上把同样三个开关打开后编的镜像，不是远端这几笔带进去的。

要该板走 G2D 旋，其 `defconfig`：

```
CONFIG_LVGL8_USE_SUNXIFB_G2D=y
CONFIG_LVGL8_USE_SUNXIFB_G2D_ROTATE=y
CONFIG_LVGL8_USE_SUNXIFB_DIRECT_MODE=y
# CONFIG_LVGL8_USE_SUNXIFB_CACHE is not set
```

**注意：** 远端第一笔给 p1_nor / 8733 / JYY070 的 **`defconfig_ota` 仍是 `CACHE=y`**，同时又开了 G2D。编 ota 镜像若要与产品「CACHE 关」一致，需自己把 ota 的 CACHE 关掉。`defconfig_qa` 的 CACHE 已是关的。

## 5. 不要再用

| 做法 | 原因 |
|---|---|
| `FBIOGET_DMABUF` / `use_phy_addr=0` | 原厂不用；`close` 会放掉 mmap 的 ION，重启 Oops |
| 把 `smem_start=0` 当没分配 | H133 上这是合法 IOVA |
| src phy + dst fd | rotate 两边都按 fd map |
| `disp_drv.rotated` 设 90/270 | 与已换宽高叠两次 |
| 开 CACHE | 用户明确关（ota 现状见上） |
| 强制软旋当主路径 | 主路径是 G2D |
| 给内核导出 ioctl 加 `get_dma_buf` | 原厂没有；不导 fd 就不需要 |
| WSL 对 `lv_drivers` 本地 `gcc -c` | x86 `.o` 污染交叉编译 |

## 6. 实测（本地 ZS101 镜像）

```
sunxifb-g2d-20250528-v3: g2d_image_enh=116 g2d_blt_h=236 (kernel expect 116/236)
Turn on 2d hardware acceleration fill/blit/blend/scale.
```

无 `fb G2D dmabuf fd=`、无 `dma_buf_id(-1)`、无 BITBLT failed。旋转成功不打字。
