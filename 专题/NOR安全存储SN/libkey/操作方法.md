# libkey 操作方法

业务/工厂程序调 `libsst.so`（包名 `libkey`，链 **`-lsst`**）。固件须已合 [../patches/](../patches/) 的 0001+0002（SST）。不必编 `libkey-demo`。PhoenixSuit 选 **分区擦除升级**，禁止全盘。

NOR 没有 private，接口只走 SST。`private bare key not supported` 正常。

## Makefile

```makefile
DEPENDS += +libkey

ifeq ($(CONFIG_PACKAGE_libkey),y)
TARGET_LDFLAGS += -lsst
endif
```

链接是 **`-lsst`**，不是 `-lkey`。头文件：`/usr/include/api.h`。ZS101 已有 `CONFIG_PACKAGE_libkey=y`。对照：`openwrt/package/thirdparty/gui/lvgl-8/sing_ktv/Makefile`。

## 写 / 读

```c
#include <string.h>
#include "api.h"

/* 写：0 成功，-1 失败；已 fsync，不必 reboot */
int ktv_sn_write(const char *sn)
{
    if (!sn || !sn[0])
        return -1;
    return private_data_write("snum", (char *)sn, (int)strlen(sn));
}

/* 读：0 成功；-1 没烧过或失败 */
int ktv_sn_read(char *buf, int buf_len, int *out_len)
{
    int len = 0, ret;
    if (!buf || buf_len <= 0)
        return -1;
    memset(buf, 0, buf_len);
    ret = private_data_read("snum", buf, buf_len, &len);
    if (out_len)
        *out_len = len;
    return ret;
}
```

```c
char sn[512];
int len = 0;
ktv_sn_write("你的SN");
ktv_sn_read(sn, sizeof(sn), &len);
```

- 单条库上限约 4KB；本板按 **512** 用。
- 写完立刻就能 `read`。`/proc/cmdline` 的 `snum=` 要 **reboot**。
- 擦（产线一般不用）：`private_data_erase_by_name("snum");`

写顺序：先 private（本板跳过）再 SST。读顺序：先 SST，没有再 private。
