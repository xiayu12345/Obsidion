# libinflist · 命名与分层（规范）

本文是**唯一命名规范**。改文件名、加模块、写 OpenWrt 包时以本文为准。

---

## 库名：libinflist（Inflist）

| 名称 | 含义 |
|------|------|
| **Inflist** | **Inf**inite **List** — 无限滚动列表（产品名） |
| **libinflist** | Linux 惯例：`lib` + 库名 → 链接 `-linflist` |
| 头文件 | `usr/include/inflist/inflist.h`（业务只 include 这一个） |
| 符号 | 对外 `inflist_*`；内部 `inflist_grid_*` / `inflist_text_*` / `inflist_image_*` |

命名原则：

- **目录 = 层**（`text/` `image/` `render/` `core/` `include/` 固定，便于加功能）
- **文件 = 模块**：`inflist_<层>.c`，扩展用 `inflist_<层>_<特性>.c`
- **不用** `lv_` 前缀（避免像 LVGL 官方组件）；**不用** `itxt`/`iimg` 缩写

---

## 目录 = 层（必须保留）

```
libinflist/src/
├── include/     对外 API
├── core/        协调层
├── render/      渲染层
├── text/        文字层
├── image/       图片层
```

**认层**：看路径第一级；**认职责**：看文件名 `inflist_<层>.c` 或 `inflist_<层>_<特性>.c`。

各层 `README.md` 在对应目录下。

---

## 文件与符号对照

| 层 | 目录 | 源文件 | 内部头 | 类型/函数前缀 |
|----|------|--------|--------|----------------|
| 对外 | `include/` | — | `inflist.h` | `inflist_*` |
| 协调 | `core/` | `inflist_core.c` | （无独立头） | — |
| 渲染 | `render/` | `inflist_grid.c` | `inflist_grid.h` | `inflist_grid_*` |
| 文字 | `text/` | `inflist_text.c` | `inflist_text.h` | `inflist_text_*` |
| 图片 | `image/` | `inflist_image.c` | `inflist_image.h` | `inflist_image_*` |

业务 **只** `#include "inflist.h"`，**不** include 内部头。

## 后续加功能放哪

| 功能 | 目录 | 命名示例 |
|------|------|----------|
| 新渲染（瀑布流、横条） | `render/` | `inflist_waterfall.c` |
| 文字扩展（搜索、多语言） | `text/` | `inflist_text_i18n.c` |
| 图片扩展（缩略图规格） | `image/` | `inflist_image_thumb.c` |
| 协调（多实例、策略） | `core/` | `inflist_core_multi.c` |
| 新对外能力 | `include/inflist.h` + `core/inflist_core.c` | 只扩公共 API |

## 已淘汰的旧名（勿再用）

| 旧 | 新 |
|----|-----|
| `lv_grid_list` | `inflist_grid` |
| `inflist_text_db` / `itxt_*` | `inflist_text` |
| `inflist_img_db` / `iimg_*` | `inflist_image` |
| `core/inflist.c` | `core/inflist_core.c` |
