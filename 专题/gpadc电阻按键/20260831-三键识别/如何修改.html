如何改 GPADC 电阻按键配置

只改 本板 board.dts 的 &gpadc，不要改 sunxi_gpadc.c。新电压、新键码、增减键都在这张表里完成。

对照：开发记录.md（电压定稿）、测试方法.md（读电压、hexdump）

其它仍用全志默认表的板件，可合补丁（电阻网络须相同）：gpadc-5btn-0R-3.3k-5.1k-6.8k-15k.patch

p1_nor_JL_M101 当前 DTS 是板乙电压。补丁也是板乙。板甲用 3/106/161/208/404，见 开发记录.md，不要拿板乙补丁打到板甲上。电压不同的板先 cat /sys/class/gpadc/data 实测。

0. 改哪个文件

文件： device/config/chips/h133/configs/<BOARD>/linux-5.4/board.dts

京龙当前是 p1_nor_JL_M101。device/product/configs/<BOARD>/.../board.dts 若指向同一文件，改一处即可。

搜 &gpadc {。不要改全志默认的其它板件 dts，除非那块板 KEY 电压也变了。

改完只编 kernel（dtb 打进 boot.img），不必重编 rootfs：

禁止在 WSL 本地 make 出 .o。

1. 节点里每项是什么

京龙当前表（复制改）：

项单位作用
keyN_volmV这颗键按下时 GPADC0 上的电压（万用表量 KEY 对 GND）
keyN_val键码上报给 /dev/input 的 linux code
key_cnt个数必须等于写了的 key0…key{n-1} 对数
channel0_compare_lowdataµV低于此才走「按下」；空闲约 1.8V 时用 1700000
channel0_compare_higdataµV高于此才走「松开」；必须 大于最高有效键电压、小于空闲

keyN_vol 是毫伏，compare_*data 是微伏，不要混。1.16V → vol 写 1160，higdata 写 1550000。

2. 驱动怎么用这张表（改之前先算窗口）

key_vol[] 必须 严格递增，且都 < 1800。驱动会再塞一个哨兵 1800：

京龙当前：

另外还有硬门槛：采样电压 ≥ 1700mV 直接当没按。所以：

  • 有效键电压必须 明显低于 1.7V（建议 ≤ 1.60V）
  • 两颗键电压差建议 ≥ 150mV，否则窗口太窄会抖

加键、改电压后，把中点手算一遍，确认不会和隔壁键、空闲重叠。

3. 常见改法

3.1 只改某颗键的功能（电压不变）

改对应 keyN_val。常用键码（linux/input-event-codes.h）：

功能keyN_val宏
播放/暂停164KEY_PLAYPAUSE
上一曲165KEY_PREVIOUSSONG
下一曲163KEY_NEXTSONG
音量减114KEY_VOLUMEDOWN
音量加115KEY_VOLUMEUP
确认28KEY_ENTER
菜单139KEY_MENU
忽略/占位240KEY_UNKNOWN

dts 里写数字，不要写宏名。

3.2 实测电压和表不一致

  1. 按下时量 GPADC0 管脚对 GND（不是面板 3.3V 侧）
  2. 把 mV 写入对应 keyN_vol，保持从小到大
  3. 重算中点；必要时插一档 KEY_UNKNOWN 把窗口隔开
  4. 检查 higdata 仍高于最高有效键

例：上一曲实测 0.70V → key1_vol = <700>;

3.3 增加一颗有效键

  1. 新电压必须 < 1.7V，并和已有档拉开
  2. key_cnt +1
  3. 按电压插入 keyN_vol / keyN_val（编号按电压从低到高，不要乱序）
  4. 若新键比原来最高有效键还高：把 higdata 抬到「新键电压 与 空闲 1.8V」之间

例：要正式接音量减 1.46V，把现在的占位改成：

音量加 1.95V：不能写成 1950。须先在 GPADC0 上量到稳定 < 1.65V 再进表，否则和空闲一样是 ~1.8V。

3.4 减少键

key_cnt 改成实际对数，删掉后面的 keyN_*。若删的是中间档，后面的编号要前移，电压仍从小到大。

删了最高档之后，检查下一档窗口会不会吞掉板上还在的物理键（京龙 1.46V 就是因此留了占位）。

3.5 改按下/松开阈值

空闲仍是 1.8V 时：

  • lowdata 保持 1700000（1.7V）一般不用动
  • higdata：大于「最高有效键 + 余量」，小于 1.7V
最高有效键higdata 建议
≤ 0.88V（全志默认）1200000 可用
1.16V（下一曲）1400000～1550000
1.46V（音量减）1550000～1600000

higdata 低于某颗键的电压 → 这颗键会按下立刻松开。

5. 板上怎么验

完整步骤（选通道、读电压、查 event、hexdump、长按、失败判定）见 测试方法.md。改 keyN_val 后 hex 里的 code 会变，例如改成 114 则按下是 72 00 不是 a4 00。

6. 排错

现象先查
完全没 sunxi-gpadc0&gpadc 的 status；channel_select
短地对地不是 164key0_vol/val 是否被覆盖；dtb 是否打进这张镜像
按下立刻松开higdata 是否低于该键电压
A 键出成 B 键key_vol 没按从小到大排；中点窗口重叠；少了占位档
最高那颗永远没事件电压 ≥ 1.7V，或被钳成 1.8V（1.95V 就是这个）
长按刷很多包正常，value=2 是 EV_REP，不是配错

LVGL 此时仍不读 gpadc，界面不动不算配置失败。
