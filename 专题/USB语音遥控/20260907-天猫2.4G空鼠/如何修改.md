## 合入（京龙）

在 SDK 根目录：

```bash
patch -p1 < H133-AI-Skills/开发记录/USB语音遥控/20260907-天猫2.4G空鼠/patches/usb-voice-tmall-7045-2018.patch
./tools/build_p1_nor_JL_M101.sh full
```

或：

```bash
bash H133-AI-Skills/开发记录/USB语音遥控/20260907-天猫2.4G空鼠/patches/apply-usb-voice-remote.sh
```

撤回：

```bash
patch -p1 -R < H133-AI-Skills/开发记录/USB语音遥控/20260907-天猫2.4G空鼠/patches/usb-voice-tmall-7045-2018.patch
```

禁止在 WSL 本地 `make` 出 `.o`。

## 其它板

AAS / evdev 是公共的。内核 USB 声卡只写了 `p1_nor_JL_M101` 的：

- `device/config/chips/h133/configs/<BOARD>/openwrt/bsp_defconfig`
- `device/config/chips/h133/configs/<BOARD>/linux-5.4/config-5.4`

加上：

```
CONFIG_SND_USB=y
CONFIG_SND_USB_AUDIO=y
```

换遥控：先按 [测试方法.md](./测试方法.md) 看语音键是不是还是 `KEY_F24`、麦是不是 USB Audio。不是就不要硬套这补丁。
