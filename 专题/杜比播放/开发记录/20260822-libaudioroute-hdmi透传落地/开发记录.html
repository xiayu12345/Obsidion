libaudioroute HDMI 杜比透传 — 开发记录

首验板型：p1_nor_JL_M101。文档目录：杜比播放/开发记录/

1. 背景

  • 对比 H133-0820 SDK 与 H133-AIKTV：SDK 打透传补丁后 AC3 可从 HDMI 出去；AIKTV 同补丁无效。
  • JL_M101 功放走 sndowa（MCU/SPDIF），HDMI 物理在 sndi2s2，不能照搬 SDK「全走 default」方案，须保留板级分路。

2. 透传链路（定稿）

player.c 识别 AC3/EAC3
  → raw_data.nNeedDirect=1
  → AudioDecCompCreate(1) / adecoderPassthough
  → tsound: sunxi_passthough_process → IEC61937
  → libaudioroute: direct_mode 直写 sndi2s2
  → 电视解码杜比

PCM（AAC 等）：解码 → amix → OUT_HDMI_ARC → sndi2s2。

前提：CONFIG_TR_AUDIO_API_LIBAUDIOROUTE=y（非 ALSALIB）；透传逻辑在 #ifdef TPLAYER_AUDIO_API_LIBAUDIOROUTE 分支。

3. 改动清单

3.1 板级（JL_M101）

文件改动
openwrt/target/h133/h133-p1_nor_JL_M101/defconfigCONFIG_TR_AUDIO_API_LIBAUDIOROUTE=y，关 CONFIG_TR_AUDIO_API_ALSA_LIB
.../etc/audio_configuration.xmlOUT_HDMI_ARC：sndowa → sndi2s2，rate 48000 / period 960

3.2 平台（全板共用）

文件改动
libtmedia/.../tsound_ctrl.cLIBAUDIOROUTE 透传写路径；读 /etc/audio_output.mode 同步 OUT_HDMI_ARC；修 mutex 死锁
libaudioroute/AudioPortAlsaConfig.cppdirect_mode 时 snd_pcm_writei 直写，不经 amix
desk/.../desk_setting_param.c注释：tplayer 靠 adev；audio_route.sh 留给投屏/aplay

4. 踩坑

4.1 跨进程路由不同步

  • 现象：desk 已 adev_set_output_device dtype 32，播放器 log 仍 OUT_DEFAULT → OUT_SPK，card 2（sndowa）。
  • 根因：desk 与 media_session/tplayer 各进程各一份 AudioManager；current_device_type 不共享。
  • 修复：TSoundDeviceCreate 读 /etc/audio_output.mode（hdmi → OUT_HDMI_ARC），创端口时用显式 dtype，不用 OUT_DEFAULT。

4.2 openSoundDevice 死锁 → 无声

  • 现象：路由已 card 0 / snd_type 32，有 closeDevice，无 pcm_open。
  • 根因：openSoundDevice 内 syncAdevOutputRoute → adev_set_output_device → handleAudioDeviceChange 再抢 sc->mutex；TSoundDeviceStart 已持锁 → 死锁。
  • 修复：去掉 openSoundDevice 内 sync；Create 时 先 sync、再注册 callback；TSoundDeviceStart 支持 STATUS_RESET。

4.3 勿在持锁路径触发 deviceChange 回调

adev_set_output_device 总会调 deviceChangeCallback。在已持 sc->mutex 的代码路径里禁止再调 syncAdevOutputRoute。

4.4 IN_MIC 解析失败（可忽略）

log：audio_sound_type_from_string failed with IN_MIC。HAL 枚举无 IN_MIC，不影响 HDMI 播放。

6. 与其它板型关系

  • ZS101 / 8733 等：仍用 CONFIG_TR_AUDIO_API_ALSA_LIB，tsound 直开 PlaybackHDMI；不要整包替换为 libaudioroute 方案。
  • JL_M101：须 libaudioroute + 板级 xml 分路；透传平台补丁可复用到其它拟用 libaudioroute 的板型，但 audio_configuration.xml 须按硬件改。
