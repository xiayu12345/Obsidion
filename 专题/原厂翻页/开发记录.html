相对 xia_yixian 独立可合（已 git apply --check）。不是远端第一笔 01f2f8f9d 的完整导出：那一笔还开了 G2D、改了 sunxig2d / g2d_driver_enh.h / ota/qa。

本补丁里的 sunxifb.c/.h、lv_port_disp.c/.h 与 01f2f8f9d 字节相同（G2D #ifdef 路径已是 smem_start IOVA）。defconfig 里 G2D 仍关，跑起来不走 G2D。只拨 G2D 开关、不合 G2D 那几笔，会缺 sunxig2d / 结构体 116/236 / libawion，编不过或 ioctl 尺寸不对。

---

1. 原厂怎么翻页

LVGL DIRECT_MODE 画 → 后台 fb 页
        │
        ▼
FBIOPAN_DISPLAY（yoffset = 刚画完的那一页）
        │
        ▼
内核 sunxi_fb_pan_display() 末尾等 VSync

两页乒乓。本树 FBIO_WAITFORVSYNC 是空实现，等扫描只能靠 真的 FBIOPAN。

---

2. 产品当时为什么没有翻页

split_fb：page0 给 HDMI、page1 给 MIPI。pan 的 yoffset 永远停在 page1，没有换页。脏区直接写到正在扫描的 MIPI 页。

内核默认 fb0_buffer_num=2。曾试过改成 3 给 MIPI 另做乒乓，已撤销，本补丁不改内核页数。

---

3. 定稿

  1. 删 split_fb / hdmi_fbindex / mipi_fbindex。
  2. 帧末：离屏缓冲写到 当前后台页（y = fbindex * yres），再 FBIOPAN，nextindex = !fbindex。
  3. 开 DIRECT_MODE（Config.in default y；p1_nor / 8733 / JYY070 的 defconfig only）。
  4. lv_port_disp：离屏转时 disp_drv.rotated = NONE（logical 已换宽高）。
  5. 去掉 sunxifb.h 强制 USE_SUNXIFB_SOFT_ROTATE。
  6. sunxifb_hdmi_rotate_restore() 留空符号。

CACHE 保持关。旋转用 CPU 还是 G2D，由 G2D旋转 决定。

---

4. 合入（这份只解决翻页）

git am H133-AI-Skills/开发记录/原厂翻页/patches/0001-sunxifb-FBIOPAN-double-buffer.patch

| 你要 | 合什么 |

|---|---|

| 只要翻页 | 本补丁 |

| 翻页 + G2D | G2D旋转 的 0001 + 0002 + 0004（或远端 xia_g2d_rotate 现树；不要停在 0002） |

不要本补丁再叠 G2D 的 0002/0004。那些叠的是远端第一笔（已含 sunxig2d、结构体 116/236、libawion）。本补丁故意没带那些。

---

4.1 换板

公共改动在 liblvgl 的 sunxifb，不是某块板的 DTS/屏驱。换 lunch 不用重做这套逻辑。

xia_yixian / xia_g2d_rotate 上只有：h133-p1_nor、h133-p1_nor_8733、h133-p1_nor_JYY070、h133-p2。本补丁只改了前三块的 defconfig（ota/qa 未改）。p2 保持关。

本仓库其它 lunch（ZS101、JL_M101、LQ* 等）不在 xia_yixian 上。合到有那些板的树后，把该 lunch 的 # CONFIG_LVGL8_USE_SUNXIFB_DIRECT_MODE is not set 改成 =y。Config.in DIRECT_MODE 已 default y，仍以该 lunch 的 defconfig 为准。

---

5. 回归

  • 双缓冲 + 真 FBIOPAN 换页
  • 没有 split_fb
  • 帧末写后台页再 pan
  • CACHE 关、G2D 关
  • 不改 fb0_buffer_num
