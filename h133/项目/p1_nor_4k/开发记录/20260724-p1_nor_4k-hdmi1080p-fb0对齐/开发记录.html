p1_nor_4k：HDMI 1080p + fb0 与输出 1:1

板件分离（初版 4K）见 ../20260723-p1_nor_4k-板件新建与HDMI4K分离/。
当前显示基线以本文为准（不再以 4K / mode 28 为默认）。

日期：2026-07-24
板型：h133-p1_nor_4k
实机：效果确认可用（UI 1280×800 落在 1080p 左上，无 VSU 拉伸变形）

1. 目标

项取值
HDMI 输出1080p60（screen0_output_mode = 10）
fb01920×1080（与输出同尺寸 → 1:1，无 VSU 拉伸）
Guider / 业务 UI仍按 1280×800 设计；画在更大 LVGL 画布左上角
视频全屏setting.ini：video_screen_* / sun_video_screen_* = 1920×1080

2. 为何不继续 fb=1280×800

内核 dev_fb.c 默认把 layer 的 screen_win 设为整屏输出（output_width/height），fb.crop 为 fb 尺寸。
当 fb0=1280×800、HDMI=1920×1080 时：crop ≠ screen_win → DE0 VSU 放大铺满（16:10→16:9，略变形）。

screen_win 不是 DTS / setting.ini 可配项，是 disp_layer_info 字段（见 sunxi_display2.h）。

把 fb0 改成与 HDMI 同为 1920×1080 后，crop 与 screen_win 同尺寸 → 1:1。desk 侧 LVGL 分辨率随 fb 变为 1920×1080；Guider 页面仍 set_size(1280,800)，自然贴左上，右侧/下方留空。

device/product/configs/p1_nor_4k/**与 chips 硬链，改一侧即同步
