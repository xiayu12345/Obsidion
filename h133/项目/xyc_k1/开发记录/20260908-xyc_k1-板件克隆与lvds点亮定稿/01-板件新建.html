01 — 板件新建（从 p1_nor_JYY070 克隆）

1.1 为何对齐 JYY070

参照适用点
p1_nor_JYY070同是 NOR + LVDS 横屏、8733BU、desk HD、disp_rotate=0、双 DE HDMI 写回
p1_nor_JL_M101USB 注释 PB11/PB12、PT4117 经验；本板 MIPI 竖屏，不当基线
p1_nor_4kpwm0 不可 disabled 的注释

目标： 只换屏驱动、时序、背光脚和 CTP；不把本屏塞进 JYY070。

1.2 新建目录清单

源：p1_nor_JYY070 → 目标：p1_nor_XYC_K1

A. 板级配置（device）

device/config/chips/h133/configs/p1_nor_JYY070/ → p1_nor_XYC_K1/

device/product/configs/p1_nor_XYC_K1 与 chip configs 同一 inode，改一处即可。

项处理
整树拷贝cp -a p1_nor_JYY070 p1_nor_XYC_K1 后替换板名
linux-5.4/board.dts实文件；lcd0 / pwm0 / usbc0 / CTP / disp
uboot-board.dts与内核 lcd0 同步
linux-5.4/config-5.4CONFIG_LCD_SUPPORT_XYC_K1_LVDS=y
openwrt/bsp_defconfigCONFIG_TOUCHSCREEN_BETTERLIFE_TS=y；GSL/GT9xx not set
bootlogo.bmp可从 JYY070 复制；不进补丁

B. OpenWrt target

openwrt/target/h133/h133-p1_nor_JYY070/ → h133-p1_nor_XYC_K1/

项处理
defconfigCONFIG_TARGET_h133_p1_nor_XYC_K1=y；desk HD（CONFIG_LVGL8_PROJECT_HD=y）
vendorsetup.shadd_lunch_combo h133-p1_nor_XYC_K1-tina
setting.inidisp_rotate=0，tp_rotate=0
input_symlink.sh识别 *betterlife* → /dev/input/touch
hostnamep1-nor-XYC_K1

C. 编译脚本

tools/build_p1_nor_XYC_K1.sh（对齐 JYY070 脚本：kernel / rootfs / full）。

1.3 公共挂钩（最小、必须）

文件内容
内核/U-Boot lcd/KconfigCONFIG_LCD_SUPPORT_XYC_K1_LVDS（default n）
两边 disp/Makefiledisp-$(CONFIG_…) += lcd/xyc_k1_lvds.o
两边 panels.c / panels.h#ifdef 注册 xyc_k1_lvds_panel
sun8iw20p1_defconfig 与 sun8iw20p1_nor_defconfigCONFIG_LCD_SUPPORT_XYC_K1_LVDS=y（NOR 打包用 nor 这份）
touchscreen/Kconfig + Makefilesource betterlife_ts/Kconfig
兄弟板 DTS / config-5.4不改

U-Boot NOR 包必须编进 nor_defconfig。普通 sun8iw20p1_defconfig 出的 u-boot-sun8iw20p1.bin 约 1MB，pack 用的是 spinor（约 565KB）。
