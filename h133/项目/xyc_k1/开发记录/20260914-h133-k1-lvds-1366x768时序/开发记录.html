1. 结论（先看这个）

决策取值 / 做法
接口 / 开屏驱仍是 LVDS lcd_if=3，xyc_k1_lvds；不要改成 default_lcd
分辨率1366×768，fb0 同步改
时钟 / 刷新率dclk=70；70e6/(1492×782) ≈ 60 Hz
时序ht=1492/hbp=88/hspw=48，vt=782/vbp=8/vspw=4
lcd_hbp88 = 40+48。厂参数把 HBP、HSW 分开写了，全志要 hbp = 实际HBP + HSPW，且必须 hbp > hspw
PWM不动：used=1，freq=50000，ch=0，pol=0，backlight=210
线序 / 极性不动：不写 lcd_lvds_clk_polarity / lcd_lvds_io_polarity
LVDS仍单路 6bit NS，lcd_frm=1
UI 旋仍 disp_rotate=0，tp_rotate=2
触摸量程未改 TP_MAX_X/Y=1280×800

旧 1280×800 参数在 dts 里用注释留底，回退时按注释填回去即可。

2. 厂参数怎么落到全志

厂 fex 给的是：

不能整段覆盖到 K1：

  1. PWM：K1 是 PB12 PWM0 → PT4117B，必须 pwm_used=1、50 kHz。厂值 pwm_used=0 / 2 kHz 会丢掉调光。
  2. 极性：H133 实际编 de_lcd_sun50iw10.c，dts 极性写了也不进 TCON；板上线序已对，保持默认 0。见 09-09 记录第 3 节。
  3. 驱动名：继续 xyc_k1_lvds，开屏仍是 LCD-EN(PB10) → LVDS → PWM。default_lcd 可能发 MIPI 命令。
  4. 水平时序：全志 lcd_hbp = HBP + HSPW。U-Boot 还检查 lcd_hbp > lcd_hspw。原值 40 < 48 非法，TCON 里会算出负 porch。水平空白 1366+48+40+38=1492，所以 lcd_hbp=88。
  5. 垂直时序：vbp=8 > vspw=4 已合法，按全志格式保留 8。若以后上下黑边再试 vbp=12（把 8 也当成 datasheet 纯 VBP）。
