03 — 改动过程与踩坑

克隆当天计划是 CTP disabled、BL3676 另做。资料包里有 IC 和 betterlife_ts.7z，当天就接上了，和屏一起验证。显示定稿把驱动打进 01-kernel-uboot-panel.patch，DTS 打进 02-board-tree.patch。本专题把那一段拆开写清。

3.1 时间线

阶段现象结论
克隆 JYY070ctp@40 GSL本板不是这颗 IC
接入 betterlife_ts@2c第一份串口是 gslX680、1-0040烧的是 JYY070 镜像，不是 XYC_K1
烧对 XYC 包betterlife-touch / event3probe 成功
getevent 四角左上原点，约 1280×800不用交换/翻转
TP_MAX 仍 1024×600边角被裁、点偏改成 1280×800
占位屏参画面和点可能对不齐屏按时序定稿后跟手

3.2 踩坑（必读）

现象根因处理
I2C 只有 1-0040，设备名 gslX680，dmesg 无 btl镜像不是本板烧 p1_nor_XYC_K1 整包，别只烧 rootfs
I2C communication ERRORTWI1 不通：脚、0x2C、供电、RSTi2cdetect -y 1，0x2c 应是 2c
Please specify the IC model:0x??通了但 chipID ≠ 0x41bl_chip_custom.h 的 TS_CHIP/BTL_FLASH_ID
完全没 BTL 日志没编进内核 / 节点没 probebsp_defconfig BETTERLIFE=y；DTS status=okay
I2C 写失败、DMAtwi_drv_used=1必须 0
有设备、滑没点INT/RST 对调或模组没报核 gpios[0/1]；getevent
四角贴边、中间偏TP_MAX 还是 1024×600改 1280×800
id:15, x:4095, y:4095空指槽当没看见
getevent -p：Function not implementedINOTIFY_USER 关了getevent -lt /dev/input/eventN

3.3 不要做的

  • 不要给 BL3676 加 GSL 的 ctp_report_max / revert_x/y / exchange
  • 不要在 linux-5.4/config-5.4 里改触摸开关当生效（内核走 bsp_defconfig）
  • 不要开兄弟板的 TOUCHSCREEN_BETTERLIFE_TS
  • 不要在 WSL 源码树本地 make 出 .o
