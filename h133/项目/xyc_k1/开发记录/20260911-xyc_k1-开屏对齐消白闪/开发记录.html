1. 结论（先看这个）

决策取值 / 做法
开屏流pin_cfg + lcd_gpio_0(PB10)=1 → tcon_enable(50ms) → pwm_enable + backlight_enable

09-08 定稿的「PB12 GPIO EN、不开 PWM、无 lcd_gpio_0」已被本专题覆盖。定稿文档已修订指向此处。

2. 现象与排查（简）

  1. 怀疑「原厂翻页 / G2D 旋转」→ 排除（只动 LVGL 用户态，不碰 BootGUI/内核 logo）。
  2. 怀疑 disp_init_enable → 排除（U-Boot boot_gui_init() 无条件开 BootGUI，不读该字段）。
  3. 09-08 GPIO 开屏出现「logo → 白闪 → logo」→ 差在 板级 open_flow / 背光 / LCD-EN（无 PB10、未开 PWM）。
  4. 把 DTS 0x1f 写进 de_lcd_sun50iw10 → 背光亮、无图；回退后恢复。不要拿本仓 JL_M101 MIPI 当同屏对照。

3. 极性坑（必读）

DTS 写 lcd_lvds_io_polarity=0x1f改 de_lcd_sun50iw10 按 DTS 写入
H133 实际编的 de_lcd_sun50iw10.c无效：只认 LVDS_REVERT（sun8iw20 未定义 → 寄存器保持 0）硬写 0x1f → 全反相 无图

因此：DTS 字面值不等于硬件极性。 本专题：DTS 不配极性；de_lcd_sun50iw10 保持原厂 #if LVDS_REVERT。
