01 — 板件新建（从 p1_nor_8733 克隆）

1.1 为何对齐 8733

参照适用点不直接当基线的原因
p1_nor_8733同 MIPI 竖屏 UI、异显、8733BU WiFi—（选定基线）
p1_nor显示链路同源WiFi 为 AIC8800
p1_nor_JYY070「板件隔绝 + 分阶段文档」可抄LVDS 横屏 + disp_rotate=0，显示框架不同

目标： 只换屏驱动与本板 DTS；不把京龙屏硬塞进共享 p1_nor。

1.2 新建目录清单

A. 板级配置（device）

源：device/config/chips/h133/configs/p1_nor_8733/
目标：device/config/chips/h133/configs/p1_nor_JL_M101/

项处理
整树拷贝cp -a p1_nor_8733 p1_nor_JL_M101
linux-5.4/必须拆软链：从 p1_nor/8733 拷成实目录后再改（8733 原是软链 p1_nor）
board.dts顶层可软链到 linux-5.4/board.dts（与工程习惯一致）
uboot-board.dts实文件，与内核 lcd0 同步改
bootlogo.bmp可从 8733 复制；可不进补丁
openwrt/、bsp/、env.cfg、分区 fex随克隆保留；hostname 等在 OpenWrt target 改

关键改动点（详情见 03）：

  • lcd_driver_name = "jl_m101_jd9365da"
  • 时序 / DSI 4-lane / lcd_gpio_0=PB11
  • lcd_pwm_ch=0 + pwm0 绑 PB12
  • usbc0 去掉对 PB11/PB12 的占用
  • config-5.4：CONFIG_LCD_SUPPORT_JL_M101_JD9365DA=y；关无关 LVDS panel（若需）

B. OpenWrt target

源：openwrt/target/h133/h133-p1_nor_8733/
目标：openwrt/target/h133/h133-p1_nor_JL_M101/

项处理
defconfigCONFIG_TARGET_h133_p1_nor_JL_M101=y，BOARD 名改为本板
vendorsetup.sh / lunchh133-p1_nor_JL_M101-tina
busybox-init-base-files/etc/setting.inidisp_rotate=3，tp_rotate=0（随 8733）
包选型继承 8733（含 rtl8733bu-kmod），不开 AIC8800
hostname如 TinaLinux-JL_M101（可选）

1.3 公共挂钩（最小、必须）

仅这些共享点；不改其它板 DTS 业务值。

文件内容
kernel/.../lcd/KconfigCONFIG_LCD_SUPPORT_JL_M101_JD9365DA（default y，同 JYY070 风格）
kernel/.../disp/Makefiledisp-$(CONFIG_…) += lcd/jl_m101_jd9365da.o
kernel/.../lcd/panels.c / panels.h#ifdef 注册 jl_m101_jd9365da_panel
U-Boot 侧同上同名 Kconfig / panels
p1_nor / 8733 / JYY070 的 config-5.4# CONFIG_LCD_SUPPORT_JL_M101_JD9365DA is not set
上述板 OpenWrt defconfig# CONFIG_TARGET_h133_p1_nor_JL_M101 is not set
libtmedia/MakefileCONFIG_TARGET_h133_p1_nor_JL_M101 → VIDEO_WB_MIRROR_ROTATE=90

运行时选屏： 只靠本板 DTS lcd_driver_name。其它板即使误编入 panel .o，只要不写该名字就不会用。

1.4 板件隔绝检查清单

新建或改完后自检：

  • rg jl_m101 device/config/chips/h133/configs/p1_nor{,_8733,_JYY070} → 无业务引用（仅允许 config not-set）
  • rg pwm0_pin_a …/p1_nor_JL_M101 → 仅本板
  • 未改 default_panel.c / 共享 sun8iw20p1.dtsi 迁就本屏
  • lunch / .buildconfig 的 LICHEE_BOARD=p1_nor_JL_M101
