1. 产品规则

项决策
默认同显 SAME
WB 管道常开（启动/HPD enable 一次）；禁止为切模式拆建 WB
切模式只改 HDMI 上 WB 层显隐 + 视频 disp_screen
播中切模式不允许（-EBUSY）
HDMI 未插视频强制 LCD
SAMEHDMI=WB 镜像；视频 DE0；hdmi_out=1
DIFFHDMI 上 WB 层 enable=0；视频 DE1；hdmi_out=0

2. 架构（最终）

已废弃：

  • 用户态 disable / 模式里 DISP_DUAL_DISPLAY_DISABLE
  • g_dual_display_prefer_enable
  • 20260805 TEMP 补丁（编译期关 WB）

DISP_DUAL_DISPLAY_DISABLE 占号 0x408，内核直接 -EINVAL。

4. 内核 ioctl

cmd值用途
DISP_DUAL_DISPLAY_ENABLE0x407确保 WB 起来（幂等）
DISP_DUAL_DISPLAY_DISABLE0x408废弃 → -EINVAL
DISP_DUAL_DISPLAY_GET_EN0x409WB 是否已 enable
DISP_FB_CLONE_ALLOW_*0x40a/40bpan clone，默认关
DISP_DUAL_DISPLAY_SET_HDMI_OUT0x40c关/开 HDMI 上 WB 层
DISP_DUAL_DISPLAY_GET_HDMI_OUT0x40d当前 hdmi_out

踩坑（历史）

曾用 DISABLE 拆 WB → scheduling while atomic（unregister 未 unlock）。产品路径只走 SET_HDMI_OUT。

5. 用户态 / 机上命令

sunxi_disp_mode_apply：fb_clone=0 → ensure_wb_up → set_hdmi_output。

应用不必走命令：#include <disp_dual.h>、链 -luapi，调 sunxi_disp_mode_set()。异显合进全板后的头文件对齐见 20260828-libuapi内核头对齐。

6. 编译 / 验收

按目标板编 kernel + rootfs。首验：./tools/build_p1_nor_JL_M101.sh full。

步骤期望
冷启WB 开，同显
disp_mode diff 再播（HDMI 已插）LCD 仅 UI，视频只 HDMI
disp_mode same 再播同显恢复
播中切换EBUSY
