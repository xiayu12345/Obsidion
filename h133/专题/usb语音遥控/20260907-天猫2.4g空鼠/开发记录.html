1. 要解决什么

USB 语音遥控插上后，方向键能走现成 HID，说话要用遥控上的麦做 AAS 识别，且不能把板载 AC107 顶掉。

2. 设备拆解（实机）

插在 usb-sunxi-ohci-1（全速）。描述符不规范：interface 4 超出、缺 interface 2。Linux 仍绑上 HID。

接口class节点用途
4-1:1.001/01 Audio Control无 driver麦控制
4-1:1.101/02 Audio Streaming无 driver麦数据（当时 # CONFIG_SND_USB）
4-1:1.3HID Keyboardevent4 → usb-kbd方向/数字/F24
4-1:1.4HID Mouseevent7 → usb-mouse空鼠
HID Consumer（同 1.3 拆出）event5Home / Mute / Vol±；input_symlink.sh 丢掉

语音键 hexdump（event4）：HID 07:73 → KEY_F24（194）。按下 value=1，按住 2，松开 0。

event5 另测过：0xac Home、0x71 Mute、0x73 Vol+、0x72 Vol−。能力位里有 KEY_VOICECOMMAND，这次语音键没打在这条上。

arecord -l 当时只有 audiocodec。

3. 约定（已对齐、未合入）

  • 按遥控 F24 → AAS VOICE START app=usb_remote source=usb，采 USB 麦，不调 MCU
  • 机身/UI 语音 → 仍 CaptureAC107
  • 两路同时：先按的算数（现有 CAPTURE_BUSY / VOICE_BUSY）
  • USB 麦不在：F24 失败 USB_MIC_MISSING，不回退 AC107
  • 音量/Home/input_symlink.sh：不动

4. 补丁改哪些文件

文件改什么
p1_nor_JL_M101 linux-5.4/config-5.4、openwrt/bsp_defconfigCONFIG_SND_USB=y CONFIG_SND_USB_AUDIO=y
aas_capture.c/.hsource=usb|ac107；USB 用 plughw:N,0 16k 单声道；找不到 USB 卡就失败
aas_session.c/.h aas_cli_fifo.cFIFO source=usb；会话结束释放占用
lv_drivers/indev/evdev.cF24 写 /tmp/aas_cmd，不注入 LVGL

对外 aas_client.h 没改。desk 没有语音入口，F24 直接打 daemon FIFO。

其它板要同样功能：自己的 bsp_defconfig 也要开 SND_USB，AAS/evdev 补丁是公共的。

5. 未做 / 未验

  • 未刷含此补丁的镜像，USB 声卡能否出来、16k 单声道 arecord 是否被这只麦接受，都没验
  • 描述符缺 iface2 / 多 iface4，snd-usb-audio 可能还要 quirk
  • Consumer Control 音量/Home 没接 UI
  • 未编出固件（2026-09-08 决定先不合入）

6. 踩坑

  • lsusb 板上没有，用 /proc/bus/input/devices 和 /sys/bus/usb/devices/4-1:1.*
  • input_symlink.sh 跳过 Consumer Control，语音键幸好在 Keyboard 的 F24
  • AAS 采音写死 CaptureAC107；USB 麦是另一张声卡，不经 MCU
  • media_session 只管播放，和这路麦无关
