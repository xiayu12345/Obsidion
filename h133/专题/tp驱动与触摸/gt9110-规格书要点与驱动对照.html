1. 芯片概要

项目规格
型号GT9110，单芯片 10 点电容触控
通道42 Tx × 30 Rx
屏尺寸7” ~ 12.1”
扫描/上报触摸扫描约 100Hz；Normal 模式坐标刷新约 7~10ms
封装88 pin，10mm×10mm QFN（与 GT911 的 52pin 不同）
供电单电源 2.8V ~ 3.3V，内置 1.8V LDO；VDDIO 可 1.8V/与 AVDD 同接
接口标准 I2C 从机，建议 ≤400kHz

2. 与主机连接的关键管脚

脚位名称说明
29I2C_SDAI2C 数据
30I2C_SCLI2C 时钟
27INT中断，边沿可在配置寄存器选择
37/RSTB复位，外部 10K 上拉，低电平复位
33VDDIOGPIO/I2C 电平（1.8V 或接 AVDD 为 3.3V）

主机侧需：SCL、SDA、INT、RST、VCC、GND（与模组 FPC 一致）。

3. I2C 从地址（上电/复位时选定）

规格书 §7.2：两组 8 位地址（写地址示例）：

8 位写地址8 位读地址Linux 7 位地址
0x280x290x14
0xBA0xBB0x5d

地址选择时序（与 gt9xxnew/gt9xx.c 中 gtp_reset_guitar() 一致）：

  1. Reset 拉低
  2. 保持 >10ms（规格书 T2）
  3. 选地址：
    • 要 0x28/0x29（0x14）：INT 输出高 → 再 Reset 拉高 → >5ms 后 INT 改为输入（Rev.03 T4）
    • 要 0xBA/0xBB（0x5d）：INT 输出低 → 再 Reset 拉高 → >5ms 后 INT 改为输入
  4. Reset 低电平保持 >100µs（规格书 T3）

Bring-up 时：i2cdetect -y <bus> 看到 0x14 或 0x5d 后，DTS 里 reg / ctp_twi_addr 与之相同。

4. 中断触发（§7.4）

配置寄存器 INT 触发方式（0x804D 相关位）：

  • 0：上升沿触发（有触摸时 INT 由低变高）
  • 1：下降沿触发（有触摸时 INT 由高变低）

内核 gt9xx.h 中 GTP_INT_TRIGGER 需与模组/FPC 一致。
