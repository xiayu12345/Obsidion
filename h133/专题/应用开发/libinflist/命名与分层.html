libinflist · 命名与分层（规范）

本文是唯一命名规范。改文件名、加模块、写 OpenWrt 包时以本文为准。

库名：libinflist（Inflist）

名称含义
InflistInfinite List — 无限滚动列表（产品名）
libinflistLinux 惯例：lib + 库名 → 链接 -linflist
头文件usr/include/inflist/inflist.h（业务只 include 这一个）
符号对外 inflist_*；内部 inflist_grid_* / inflist_text_* / inflist_image_*

命名原则：

  • 目录 = 层（text/ image/ render/ core/ include/ 固定，便于加功能）
  • 文件 = 模块：inflist_<层>.c，扩展用 inflist_<层>_<特性>.c
  • 不用 lv_ 前缀（避免像 LVGL 官方组件）；不用 itxt/iimg 缩写

目录 = 层（必须保留）

libinflist/src/
├── include/     对外 API
├── core/        协调层
├── render/      渲染层
├── text/        文字层
├── image/       图片层

认层：看路径第一级；认职责：看文件名 inflist_<层>.c 或 inflist_<层>_<特性>.c。

各层 README.md 在对应目录下。

文件与符号对照

层目录源文件内部头类型/函数前缀
对外include/—inflist.hinflist_*
协调core/inflist_core.c（无独立头）—
渲染render/inflist_grid.cinflist_grid.hinflist_grid_*
文字text/inflist_text.cinflist_text.hinflist_text_*
图片image/inflist_image.cinflist_image.hinflist_image_*

业务 只 #include "inflist.h"，不 include 内部头。
