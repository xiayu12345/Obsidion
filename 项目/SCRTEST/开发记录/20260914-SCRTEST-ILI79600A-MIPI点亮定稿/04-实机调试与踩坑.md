# 04 — 实机调试与踩坑

## 4.1 时间线

| 阶段 | 现象 | 结论 |
|---|---|---|
| 厂家 169 + HSA=2 | U-Boot 卡 `boot_gui_init` | `dsi_hsa=hspw×3-10` 为负 |
| U-Boot 800×1280 探针 | 能开机，底下 ⅓ 彩虹 | TCON 分辨率必须跟内核一致 |
| dts 169 / 157 / 168 | 软件通、屏黑 | 实际像素钟 ×1.5，DSI 钉 150，带宽不够 |
| dts 70 | 亮，刷新太低 | 实际 ≈105MHz |
| 照抄手册 157+宽 porch | 仍黑 | 同一套分频问题，不是 porch 抄错 |
| dts 105 / **110**，VFP=270 | 出图 | 实际 ≈157 / **165**，约 56 / **59Hz** |

## 4.2 黑屏认日志，不认 dts 字面

```text
clk: pll(…), dclk(157000000) dsi_rate(157000000)
clk real: pll(…), dclk(234000000) dsi_rate(150000000)
```

上一行是想要的，下一行是芯片真跑的。`boot_gui_init:finish` + `panel_init` + desk 起来仍可能黑。

## 4.3 禁止改 `disp_al.c`

`DSI_VERSION_40` 的 `clk_tbl` 写死 `dsi_rate=150000000`；video 的 `tcon_div=4`、`dsi_div=6`。  
用户要求保持原厂。dts 只能 **倒着填**：要实际 165，写 110。

## 4.4 文档文件名

真正的 Linux LCD 指南是 **`Linux_CCU_开发指南.pdf`**（标题 Linux LCD）。  
`H13x开发文档` 是 I2S 挂 CODEC。手册 1200×1920 示例是 **157 + 宽 H porch + 小 V**，不是厂家 169 / HSA=2。

## 4.5 U-Boot 没进镜像

`./build.sh kernel bootloader` **不会编 U-Boot**。改 `uboot-board.dts` / panel 必须 `./tools/build_p1_nor_SCRTEST.sh kernel`（脚本会 force uboot）或 `./build.sh uboot`。  
横幅 `U-Boot 2018.05 (Sep 01 …)` 冻在 `lib/version.c`，**不能**当是否更新的依据。认 `scrtest_ili79600a: panel_init` 和 spinor 文件时间。

## 4.6 源码树 `.o`

禁止在 WSL 对 panel 本地 `gcc -c`（x86 `.o` 会骗过 Make，ARM 链接炸）。
