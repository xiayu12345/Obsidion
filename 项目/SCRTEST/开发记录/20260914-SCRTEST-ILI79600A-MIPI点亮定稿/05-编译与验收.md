## 5.1 编译

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
./tools/build_p1_nor_SCRTEST.sh kernel
source build/envsetup.sh && p
# setting.ini / rootfs：./tools/build_p1_nor_SCRTEST.sh full
```

产物：`out/h133_linux_p1_nor_SCRTEST_uart0_nor.img`  
定稿 MD5：`72d77193aad40ea11914bbc48ab3be97`

| 改动 | 命令 |
|---|---|
| 内核 DTS / panel | 脚本 `kernel`（含强制 U-Boot）再 `p` |
| 只改 `setting.ini` | `full` 或 `rootfs` 再 `p` |

禁止 WSL 本地 `make` 污染 `.o`。PATH 必须带 make 4.1。

## 5.2 验收

串口：

- `scrtest_ili79600a: panel_init`
- `boot_gui_init:finish` / `LCD open finish`
- `[DISP] lcd_clk_config`：**real dclk 约 165000000，dsi_rate 150000000**

屏：U-Boot logo + 内核 UI；物理 1200×1920；`disp_rotate=1`。

DTB 核对（`.sunxi.dts`）：

```text
lcd_dclk_freq = <0x6e>;   /* 110 */
lcd_hbp = <0x18>;         /* 24 */
lcd_ht  = <0x4dc>;        /* 1244 */
lcd_hspw = <0x04>;
lcd_vbp = <0x42>;         /* 66 */
lcd_vt  = <0x8d0>;        /* 2256 */
```
