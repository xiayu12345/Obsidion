# 01 — 板件新建（从 p1_nor_JL_M101 克隆）

## 1.1 为何对齐 JL_M101

同是 **NOR + MIPI 直连灌码**、RST=PB11、PWM0=PB12→PT4117、RTL8733BU。  
**不要**从 XYC_K1 / LQ140 克隆（LVDS / MIPI→eDP 桥片，时钟路不同）。

---

## 1.2 新建目录

源：`p1_nor_JL_M101` → 目标：`p1_nor_SCRTEST`

`device/product/configs/p1_nor_SCRTEST` 与 chip configs **同一套文件**，改一处即可。

| 项 | 处理 |
|---|---|
| `linux-5.4/board.dts` | 实文件；lcd0 / fb0=1200×1920 / CTP disabled |
| `uboot-board.dts` | 与内核 lcd0 **同一套时序**（分辨率不一致会花） |
| `linux-5.4/config-5.4` | `CONFIG_LCD_SUPPORT_SCRTEST_ILI79600A=y` |
| OpenWrt | `h133-p1_nor_SCRTEST`，lunch `h133-p1_nor_SCRTEST-tina` |
| `setting.ini` | `disp_rotate=1`，`video_rotate=2` |
| 脚本 | `tools/build_p1_nor_SCRTEST.sh` |

兄弟板 `config-5.4` 只追加 `# CONFIG_LCD_SUPPORT_SCRTEST_ILI79600A is not set`。

---

## 1.3 公共挂钩（最小）

| 文件 | 内容 |
|---|---|
| 内核/U-Boot `lcd/Kconfig` | `CONFIG_LCD_SUPPORT_SCRTEST_ILI79600A`（**default n**） |
| 两边 `disp/Makefile` | `lcd/scrtest_ili79600a.o` |
| 两边 `panels.c` / `panels.h` | `#ifdef` 注册 |
| `sun8iw20p1_defconfig` **和** `sun8iw20p1_nor_defconfig` | `=y`（NOR pack 用 nor 这份） |
| `libtmedia/Makefile` | 本 target 挂 `VIDEO_WB_MIRROR_ROTATE=0` |

---

## 1.4 编译

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
./tools/build_p1_nor_SCRTEST.sh kernel    # 内核 + 强制 U-Boot + pack 前还要 p
source build/envsetup.sh && p
# 或 ./tools/build_p1_nor_SCRTEST.sh full
```
