5.1 编译

产物：

定稿参考 md5（2026-07-22）：05a696f4b7672bc692c645cc3e8bb468（后续重编会变）。

改动类型 → 编什么

改动命令
panel .c / 内核 DTS / config-5.4kernel，再 pack
uboot-board / U-Boot panelkernel（含 bootloader）或单独 ./build.sh bootloader + pack；必要时删旧 u-boot-*.bin 强制重编
setting.ini / rootfs 应用rootfs
全量full

注意

  • 禁止在 WSL/x86 上对 desk/panel 源码本地 gcc -c（会污染 .o，交叉链接炸）
  • U-Boot 增量偶发旧 .o：可对 uboot 目录 make clean 或删对应 .o 后重编 bootloader
  • 改内核后若要重编 rtl8733bu ko：先有 out/kernel/build 的 Module.symvers，再 rootfs/m

5.2 验收清单（出图定稿）

  • 内核编过，含 jl_m101_jd9365da.o
  • DTB：lcd_driver_name=jl_m101_jd9365da，lcd_pwm_ch=0，lcd_pwm_freq=50000，lcd_pwm_used=1
  • dmesg：panel_init → attached ok
  • LCD 完整出图；板载背光（PWM）正常
  • 分辨率 800×1280；desk disp_rotate=3 方向正确
  • WiFi 仍 rtl8733bu
  • （回归）串编 p1_nor_8733 / p1_nor_JYY070 DTS 未被本改动改坏

5.3 常见问题速查

现象优先查
背光亮无图RESET 档（R52/R53）、RESET 波形、MIPI HS；勿外部灌 RESET
panel_init 后无后续 DISP是否又加了 DSI 读；是否 U-Boot smooth
完全不亮PWM0 是否 enable、PT4117 5V、VLED 接线
USB 异常 / RESET 浮 1.8Vusbc0 是否又占用 PB11/PB12
8733bu Unknown symbol清 .config 后未按序编 ko
