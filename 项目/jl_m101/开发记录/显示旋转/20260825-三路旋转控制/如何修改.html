如何改 HDMI / UI / 视频旋转

机制已在树，不要改 dev_disp.c / sunxifb.c / tlayer_ctrl.c 的旋转逻辑。新板只改下面三处旋钮。对照片段：patches/。

先看规格书扫描方向：原生竖屏（如 800×1280）产品要横屏 UI → 用竖屏套件；原生横屏 → 用横屏套件。

0. 选套件

竖屏 MIPI（跟 8733 / ZS101）横屏（跟 JYY070 / LQ140）
disp_rotate30
dual_display_rot3（缺省已是 3，建议显式写）必须 <0>
VIDEO_WB_MIRROR_ROTATE90（Makefile 必须点名本 target）0
video_rotate一般不写（默认 0）一般不写

三路改完后 分别验收，不要一次改完再猜是哪路错。

1. 改 HDMI（kernel）

文件： device/config/chips/h133/configs/<BOARD>/linux-5.4/board.dts
在 disp 节点、chn_cfg_mode 附近：

值G2D何时用
0rot0主屏已是横屏，HDMI 不要再转
190°少见
2180°少见
3270°竖屏主显镜像到横屏电视

不写 = 内核当 3。横屏漏写会 HDMI 方向错 / 全绿。

串口期望：[DISP] dual display HDMI G2D rot270: 或 rot0:。

2. 改 UI（rootfs ini）

文件： openwrt/target/h133/h133-<BOARD>/busybox-init-base-files/etc/setting.ini

板上若有 /mnt/UDISK/setting.ini，它会盖掉 /etc。改完看不见效果先：

argv[1] 也能盖 ini（如 sing_ktv 0），desk 启动一般不传。

启动 log 期望：sunxifb_rot=3（或 0）。

触摸是第四路：tp_rotate，与 UI 独立；勿拿 disp_rotate 去「顺便修触摸」。

3. 改视频 WB（libtmedia）

文件： openwrt/package/allwinner/multimedia/tina_multimedia/libtmedia/Makefile

新竖屏板：把本 target 加进 =90 那行的 ifeq，例如：

新横屏板：加进 =0 那行，或什么都不加（C 默认 0）。不要在 tlayer_ctrl.c 里按板名写死。

只改 ini 的 video_rotate 解决不了「UI 对、视频横着」——那是 WB 宏。

log 期望：[WB-MIRROR] ... VIDEO_WB_MIRROR_ROTATE=90（或 0）。

播放器微调朝向（少用）：同 ini 加 video_rotate = 0..3，走 TPlayerSetRotate，与 WB 宏独立。

4. 编译对照

改了什么编什么
board.dts dual_display_rotkernel
setting.ini disp_rotate / video_rotaterootfs（不必重编 desk）
libtmedia/Makefile WB 宏rootfs（重编 libtmedia）
sunxifb.c / tlayer_ctrl.c（不要为改角度动）GUI 包 / libtmedia

禁止在 WSL 本地 make 出 .o 污染交叉编译。

5. 排错

现象先查
LCD 方向错、HDMI 还行disp_rotate；UDISK 是否覆盖
HDMI 绿/歪、LCD 正常dual_display_rot（横屏是否忘了写 0）
UI 对、视频横着/竖着VIDEO_WB_MIRROR_ROTATE 是否编进本 target
改 ini 无效UDISK；是否误改了 LV_PROJECTOR_DISP_ROTATE 当运行时
子 app 切走后 HDMI 方向没了子进程误 sunxifb_exit

cedarx.conf 的 g2d_rotate_flag / dual_disp_mipi_rotate 不是当前板型主入口，不要靠改 conf 分板。
