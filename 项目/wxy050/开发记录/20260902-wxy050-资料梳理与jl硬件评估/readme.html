1. 一句话结论

这块 5 寸是 MIPI 4-lane 720×1280 + ST7121P，H133 原生 DSI 能驱。
京龙 s10 的 CON5（40P、给 JL-M101 10.1”）不能对插；缺独立 IOVCC 1.8V，RESET 必须改 1.8V 档，背光是 18V / 40mA 不能走京龙现成 ~160mA。要用京龙板点屏，必须 转接线 + 补 1.8V + 改 RESET 档 + 背光单独处理。

项目归属：规格书是 深圳市婺芯源光电，不在京龙/纽曼等客户目录，对不上现有项目。

3.1 触摸（TDDI，不是独立 TP）

这块不是 GT911 / GSL 那种外挂电容芯。ST7121P 是 显示+触摸一体（TDDI）：ITO 电极在 IC 里，主机只看到 FPC 上 4 根线。

32TP-SCLTP_I2C_SCL同上
33TP-VCC规格书 NC；结构图写 TP-VCC3V对不上，飞线前确认

京龙现成触摸：

京龙本屏
JP702 45P → 板载 GSL3670触摸在 LCD 33P 上，CON5 没有 TP 脚插座不通
主机 TWI1 PG8/PG9，0x40，INT=PG3，RST=PG2，3.3V从机是 ST7121P，IO 1.8V3.3V 直灌会超 IOVCC
驱动 gslX680new + gsl3670.bin工程里 没有 Sitronix TDDI 驱动软件不通

H133 的 TWI1/PG2/PG3 可以接到这 4 根脚（和接 GT928 同一组），但必须：

  1. 从 5” FPC 飞线，不要插 JP702 / 不要走 GSL3670
  2. I2C/RST/INT 1.8V（电平转换，或确认该 GPIO 组已是 1.8V；京龙 CTP 页是 VCC-3V3）
  3. 厂商要 I2C 7-bit 地址、报点协议、TP 固件。Datasheet §5.12 只写了 I2C/SPI 从机，地址在图里抽不出来；模组规格书初始化写「请联系我们」；树内也没有 .h / linux 驱动

点屏可以先不接 TP。要触摸就向婺芯源要 TDDI host 协议，不能复用 GSL3670。

4. 要用京龙板点屏，硬件最少做什么

  1. 33P↔40P 转接线（或夹具）：MIPI D0–D3 + CLK 按符号对接，不要按 pin 号照抄；GND 多接。
  2. IOVCC：从 VCC-LCD-1V8 接到屏 pin21。
  3. VCC：可先用 CON5 3.3V 试；稳妥则 LDO 到 2.8/3.0V。
  4. RESET：改 R52/R53 为 1.8V 档；确认屏脚静态 ≈1.8V，且 PB11 仍能打出 H→L→H。
  5. 背光：不要直接吃 CON5 LED± 的 160mA 档；外接 18V/40mA 恒流，或改 Rs 并确认升压够 18V。
  6. 软件：独立 panel + 本板 DTS（720×1280、porch/dclk 如上）；调屏期 U-Boot disp_init_enable=0。
  7. 触摸：先不接。若接：FPC 29–32 飞到 TWI1+PG2/PG3，1.8V，关掉 GSL3670；缺地址/固件前不要灌 3.3V。
