1. 一句话

纽曼 FXT101041 GT928 接主板 JP17 六线；ctp_name=gt928_fxt101041 → GROUP2（客户 cfg 原样 186B）；横屏 LVGL 1280×800 只需 ctp_revert_y_flag=1，不改 tp_rotate。

2. 改动清单

文件改动
gt9xx.hCTP_CFG_GROUP2←客户 cfg 186B（X/Y=1280/800，chk=0xCA，Fresh=1）。GROUP1（TPC3386）不动
gt9xx.cgt928_fxt101041→sensor_id 1（Allwinner 按 ctp_name 选 GROUP，不读芯片 Sensor ID）
ZS101 board.dts去掉禁用的 ctp@40 GSL；ctp@5d goodix；screen_max=report_max=1280×800；revert_y=1
ZS101 bsp_defconfig关 GSLX680NEW，开 GT9XXNEW_TS（chips 与 product 硬链接，改一处即可）

不用高通 Goodix 那套 goodix,driver-send-cfg + cfg-group0 DTS。本平台是 Allwinner gt9xxnew，cfg 进 gt9xx.h GROUPs。

3. 踩坑（必读）

现象根因处理
无 /dev/input/event3，probe -1I2C 读 0x8047 失败 -16（-EBUSY），TWI1 全地址 9th SCL clk Timeout总线没通（没电/座子/短路）。通了才会注册 gt9xxnew_ts
ctp_power fail -22、dummy regulatorDTS 无独立供电，VCC-CTP 板上 3.3V 常供可忽略（乐大海 GT911 同样）
裸跑 getevent -p：Function not implemented没跟节点时要 inotify；bsp_defconfig 关了 INOTIFY_USER（各板都关）getevent -lt /dev/input/event3（开发记录里一直是带节点的）
四角 X 对、顶边 Y≈800轴与 UI 上下反了ctp_revert_y_flag=1
客户 cfg 文件名写 1080字节 0x0500×0x0320=1280×800以字节为准

gt9110_wt097 仍映射 sensor_id 1，树内无板在用该 ctp_name。

4. 硬件对照

项值
芯片GT928（FXT101041）
接口I2C 六线（规格书写 USB 座，实际 JP17：SCK/SDA/INT/RST/VCC 3.3V/GND）
主板ZX30-D618-H133 JP17；GPIO 表 PG8=TWI1_SCK、PG9=TWI1_SDA
地址0x5d（复位时 INT 低；备选 0x14）
供应商 cfg硬件资料/纽曼/FXT101041_GT928_1080_VER00_Config_20260827_115020 - 副本.cfg
