# 双板串编验证脚本（个人用，非 SDK tools）

| 项 | 内容 |

| 日期 | 2026-07-14 |
| 定位 | **验证助手**：改公共代码后，确认 `p1_nor_8733` / `p1_nor_JYY070` UI 都正确 |

## 为何单独放

公共代码（`media_session`、视频 rect、播放链路等）两板共用，板差异目前靠编前切换 UI 档。正式产品构建仍各自 lunch；本脚本只用于本地「改完共有部分 → 双板各打一包」。

## 用法

```bash
# 仍在本目录时（会自动向上找 SDK）
./verify_build_8733_then_JYY070.sh

# 拷走后
export H133_SDK_ROOT=/path/to/H133-AIKTV
./verify_build_8733_then_JYY070.sh
# 或
./verify_build_8733_then_JYY070.sh --sdk-root /path/to/H133-AIKTV
```

编完默认把源码 UI 档还原为 8733；要停在 JYY 档加 `--leave-jyy-ui`。
