# 00 — 背景与路径统一

**下一步：** [01-kernel-panel驱动.md](./01-kernel-panel驱动.md)

---

## 1. 背景与目标

异显（HDMI WB 镜像 + split_fb）在 **p1_nor（MIPI rot=3）** 上开发完成。JYY070 换 LVDS 横屏后，要求 **应用层显示路径与 p1_nor 保持一致**，仅旋转角度不同，便于维护与后续异显功能复用。

| 项 | p1_nor | JYY070 |
|---|---|---|
| Panel | 800×1280 MIPI 竖屏 | 1024×600 LVDS 横屏 |
| 主 UI | `desk` / `sunxifb_rot=3` | `desk` / `sunxifb_rot=0`，LVGL **1280×800** |
| sunxifb 框架 | `rotatefbp + split_fb` | **相同** |
| LCD 页输出 | CPU 软转 270° | 直拷贝 1280×800 → fb |
| DE0 输出 | 1:1（800×1280 fb） | **VSU 缩放到 1024×600** |
| HDMI 内核 rot | `dual_display_rot=3` | `dual_display_rot=0` |

---

## 2. 统一后的显示链路

```
LVGL 绘制 → rotatefbp（独立 draw buffer）
                ↓
         split_fb 双页脏区同步
    ┌───────────┴───────────┐
 HDMI page0              LCD page1
 直拷贝                   rot=3: CPU 软转 270°
                          rot=0: 直拷贝（SUNXIFB_ROT_0）
                ↓
         FBIOPAN → LCD 固定 page1
```

### rot=0 与 rot=3 唯一差异

| | rot=3 (p1_nor) | rot=0 (JYY070) |
|---|---|---|
| init / flush / pan 框架 | **相同** | **相同** |
| `sinfo.rotated` | `SUNXIFB_ROT_90` | `SUNXIFB_ROT_0` |
| LVGL 逻辑尺寸 | 1280×800 | 1024×600 |
| LCD 页 | 软转 270° | 直拷贝 |
| split_fb log（debug 开） | `... MIPI page1 rotate` | `... MIPI page1 copy` |

## 3. fix_lcd_page 已废弃

早期 bring-up [02-rotate0双缓冲修复](../../JYY070-7寸LVDS屏-bringup/02-rotate0双缓冲修复记录.md) 使用 **独立路径** `fix_lcd_page`（直写 fb、不走 rotatefbp）。

**2026-07-08 决策：** 与 p1_nor 异显框架对齐，**回退 fix_lcd**，改回统一 `rotatefbp + split_fb`。

| 方案 | 状态 |
|---|---|
| `fix_lcd_page` + `draw ping-pong, LCD fixed page1` | ❌ 已废弃 |
| `rotatefbp + split_fb` + `MIPI page1 copy/rotate` | ✅ 当前采用 |
