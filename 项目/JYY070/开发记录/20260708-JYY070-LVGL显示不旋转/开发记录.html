JYY070 LVGL 显示不旋转 — 开发记录（编译宏双板）

| 项 | 内容 |

|---|---|

| 日期 | 2026-07-08 |

| 板型 | p1_nor_JYY070（p1-nor-JYY070） |

| 关联板型 | p1_nor（保持横屏 270° 旋转，不受影响） |

| 需求 | JYY070 新固件 LCD 显示不做软件旋转 |

| 本记录方案 | sunxifb.mk 按 target -DLV_PROJECTOR_DISP_ROTATE=0（编译宏双板） |

| 补丁 | jyy070-lvgl-no-rotate.patch |

| 树内当前落地 | 应用层适配硬编码（UI 默认 rot=0 + 视频 rect；不兼顾 p1_nor） |

| 说明 | 本文件保留完整双板做法；树内若已走最小硬编码，打本补丁前须把头文件默认先恢复为 3 |

---

1. 背景

  • 物理屏：7.2" MIPI 800×1280 竖屏（board.dts 中 lcd_x=800, lcd_y=1280）；后续 LVDS 板 UI FB 可能为 1280×800，旋转宏语义不变（0=不转）
  • 原 UI 设计按横屏逻辑，通过 sunxifb CPU 软转 270°（LV_PROJECTOR_DISP_ROTATE=3）适配
  • JYY070 产品要求：UI 不再旋转，sunxifb_rot=0

启动方案说明（与旧 rootfs 对比）

| | 旧参考 rootfs | 当前 p1_nor / JYY070 |

|---|---|---|

| 主程序 | lv_projector 3 & | desk & |

| 旋转方式 | 启动参数 3（运行时） | 编译宏 LV_PROJECTOR_DISP_ROTATE（编译时） |

| desk 是否读 argv | — | 否，改 rc.final 传参无效 |

当前 rc.final 路径：openwrt/target/h133/h133-p1_nor_JYY070/busybox-init-base-files/etc/init.d/rc.final

---

2. 方案选型

| 方案 | 结论 |

|---|---|

| 直接改 projector_config.h 默认值为 0 | 可用但伤 p1_nor；树内见 应用层适配硬编码 |

| 改 setting.ini / rc.final 传参 | ❌ desk 不读 ini/argv |

| 各 GUI 包 Makefile 单独加 -D...=0 | ✅ 可行但重复（多包） |

| sunxifb.mk 按 target 覆盖宏 | ✅ 双板采用：一处修改，所有 include 该 mk 的 LVGL GUI 包生效 |

---

3. 最终实现（编译宏双板）

3.1 核心改动

文件： openwrt/package/thirdparty/gui/lvgl-8/sunxifb.mk

# p1_nor_JYY070: UI 不旋转；p1_nor 等仍用 projector_config.h 默认 3
ifeq ($(CONFIG_TARGET_h133_p1_nor_JYY070),y)
TARGET_CFLAGS+=-DLV_PROJECTOR_DISP_ROTATE=0
endif
  • 所有 include ../sunxifb.mk 的 GUI 包（desk、sing_ktv、liyuan_opera 等）编 JYY070 时自动带上该宏
  • p1_nor 不满足 CONFIG_TARGET_h133_p1_nor_JYY070，仍用默认值 3

文件： platform/thirdparty/gui/lvgl-8/app/desk/src/projector_port/include/projector_config.h

  • 保持 #define LV_PROJECTOR_DISP_ROTATE 3 不变
  • 注释说明：JYY070 由 sunxifb.mk 的 -D 覆盖（#ifndef 跳过默认）

3.2 宏与显示链路

projector_config.h (#ifndef 默认 3)
        ↓
sunxifb.mk（仅 JYY070: -DLV_PROJECTOR_DISP_ROTATE=0 预定义，跳过默认值）
        ↓
desk main → sunxifb_init(rotated) → CPU 软转（USE_SUNXIFB_SOFT_ROTATE）
        ↓
JYY070: sunxifb_rot=0
p1_nor: sunxifb_rot=3，LVGL 逻辑多为 1280×800

3.3 未改动的部分

  • setting.ini 中 disp_rotate：desk 不读取，对主界面无效
  • 内核 disp_rotation_used：未启用
  • 视频 WB 旋转：另见 WB-mirror（VIDEO_WB_MIRROR_ROTATE）
  • 视频小窗/全屏 rect：双板用 KTV_BOARD_JYY070，见 rect双板兼容

5. 注意事项

  1. 不可并行编译同一 SDK 目录下的 p1_nor 与 JYY070（共享 .buildconfig / .config）
  2. 子应用：desk 拉起 sing_ktv 等时不传旋转参数，依赖各自编译时的宏（同样受 sunxifb.mk 控制）
  3. 运行时勿 sing_ktv 3 / lv_projector 3（会覆盖编译默认）
  4. 若与 rect 双板补丁 同改 sunxifb.mk：合并为一个 ifeq，同时带 -DKTV_BOARD_JYY070=1 与 -DLV_PROJECTOR_DISP_ROTATE=0
