## 1. 背景

### 1.1 UI 旋转

- 默认 `LV_PROJECTOR_DISP_ROTATE=3`（270° 软转）不适配 JYY070
- `desk` 不读 argv / `setting.ini`，只能编译期默认或 `-D`
- **最小做法**：各 app `projector_config.h` / 兜底宏改默认 **0**（不在 mk 加板型分支）

### 1.2 视频小窗 / 全屏

| 层 | 分辨率 | 说明 |
|---|---|---|
| UI FB / Guider | 1280×800 | VSU 缩放到面板 |
| DE0 / LVDS | **1024×600** | 视频 `frame` 坐标系 |
| Guider `btn_30` | (347,151,599,316) | 热区 @1280×800 |

现象：小窗仍用竖屏 `(330,360,320,570)`；全屏用 FB `1280×800` → 花屏。

```
# mgr0: 1024x600
# UI: fb[1280,800] frame[0,0,1024,600]
```

## 2. 改动清单

### 2.1 UI 不旋转（默认宏 → 0）

| 文件 | 改动 |
|------|------|
| `desk/.../projector_config.h` | `LV_PROJECTOR_DISP_ROTATE` → **0** |
| `sing_ktv/.../projector_config.h` | 同上 |
| `liyuan_opera/.../projector_config.h` | 同上 |
| `MixStation` / `LiveStreamPlayer` / `BluetoothPlayer` / `ai_mv` 的 `main.c` 兜底 | → **0** |
| `sunxifb.mk` | **无** JYY070 → `DISP_ROTATE` 的 `ifeq` |

```c
#ifndef LV_PROJECTOR_DISP_ROTATE
#define LV_PROJECTOR_DISP_ROTATE  0
#endif
```

### 2.2 视频小窗 / 全屏 rect

不引入 `KTV_BOARD_*`，不改 Makefile。

| 文件 | 改动 |
|------|------|
| `sing_ktv/.../ktv_player/core/ktv_player_ui.c` | 小窗；全屏硬编 `1024×600`；去掉 `sunxifb_get_sizes` |
| `media_session/.../ktv_player_common.h` | `SCREEN` → `1024×600` |
| `media_session/.../ktv_player_ui.c` | 小窗对齐；`right` 高度用 `SCREEN_HEIGHT` |

| | 改前 | 改后 |
|--|------|------|
| 小窗 | (330,360,320×570) | **(278,113,479×237)** |
| 全屏 | FB 1280×800 | **(0,0,1024,600)** |

换算：btn_30 ×(1024/1280)、×(600/800)。

```c
#define KTV_PLAYER_SMALL_RECT_X  (278)
#define KTV_PLAYER_SMALL_RECT_Y  (113)
#define KTV_PLAYER_SMALL_RECT_W  (479)
#define KTV_PLAYER_SMALL_RECT_H  (237)

/* 视频 layer 用 DE 屏坐标，切勿用 FB 1280×800 */
return ktv_player_ui_apply_rect(0, 0, 1024, 600);
```

## 6. 退回改动：恢复为 3 / 适配 p1_nor

本补丁把 UI 默认旋转换成 **0**、视频 rect 写成 JYY DE 屏坐标。编 **`p1_nor`**（竖屏逻辑、**`LV_PROJECTOR_DISP_ROTATE=3`**）前必须整包退回。

目标（退回后）：

| 项 | p1_nor 期望 |
|----|-------------|
| UI 旋转宏默认 | **`LV_PROJECTOR_DISP_ROTATE = 3`**（270°） |
| 日志 | `sunxifb_rot=3` |
| 小窗 / SCREEN | 竖屏原值（见 §6.2） |
| lunch | `h133-p1_nor-tina`（非 JYY070） |

### 6.1 推荐：反打本最小补丁

```bash
cd /path/to/H133-AIKTV
patch -R -p1 < H133-AI-Skills/开发记录/板件开发记录/JYY070/20260714-JYY070-应用层适配硬编码/jyy070-app-layer-adapt-minimal.patch

source build/envsetup.sh && lunch h133-p1_nor-tina
m package/desk/compile package/sing_ktv/compile package/media_session/compile
# 推 desk / sing_ktv / media_sessiond 后重启
```

`patch -R` 会把补丁里所有文件一并还原，包括：各 app 的 `DISP_ROTATE` **0→3**，以及小窗/全屏 rect。

### 6.2 手工对照（改乱 / 无法 patch -R）

**① UI 旋转：全部改回默认 `3`**

| 文件 | 改回 |
|------|------|
| `desk/.../projector_config.h` | `#define LV_PROJECTOR_DISP_ROTATE  3` |
| `sing_ktv/.../projector_config.h` | 同上 |
| `liyuan_opera/.../projector_config.h` | 同上 |
| `MixStation` / `LiveStreamPlayer` / `BluetoothPlayer` / `ai_mv` 的 `main.c` 兜底宏 | 同上 |

```c
#ifndef LV_PROJECTOR_DISP_ROTATE
#define LV_PROJECTOR_DISP_ROTATE  3
#endif
```

**② 视频 rect — sing_ktv `ktv_player_ui.c`**

```c
#include "lv_drivers/display/sunxifb.h"

#define KTV_PLAYER_SMALL_RECT_X               (330)
#define KTV_PLAYER_SMALL_RECT_Y               (360)
#define KTV_PLAYER_SMALL_RECT_W               (320)
#define KTV_PLAYER_SMALL_RECT_H               (570)

/* set_right_rect 高度 */
return ktv_player_ui_apply_rect(115,
                                KTV_PLAYER_SMALL_RECT_Y,
                                570,
                                1280 - KTV_PLAYER_SMALL_RECT_Y);

/* set_full_rect：用 FB，不要写死 1024×600 */
int ktv_player_ui_set_full_rect(void)
{
    uint32_t w = 0, h = 0;
    sunxifb_get_sizes(&w, &h);
    if (w == 0 || h == 0)
        return ktv_player_ui_apply_rect(0, 0,
                                        KTV_PLAYER_SCREEN_WIDTH,
                                        KTV_PLAYER_SCREEN_HEIGHT);
    return ktv_player_ui_apply_rect(0, 0, (int)w, (int)h);
}
```

**③ 视频 rect — media_session**

```c
/* ktv_player_common.h */
#define KTV_PLAYER_SCREEN_WIDTH                (800)
#define KTV_PLAYER_SCREEN_HEIGHT               (1280)

/* ktv_player_ui.c 小窗 */
```

**说明：**

- 视频 WB：p1_nor 树内由 `libtmedia/Makefile` 传 `VIDEO_WB_MIRROR_ROTATE=90`，**不在本补丁内**，退回应用层后 lunch p1_nor 重编即可。
- 若要同树双板共存：先完成本节退回（默认回到 3 + 竖屏 rect），再打 UI / rect **双板**补丁，而不是长期停在 JYY 硬编码。
