JYY070 视频小窗/全屏 rect 双板兼容 — 开发记录（编译宏，不进树）

| 项 | 内容 |

|---|---|

| 日期 | 2026-07-14 |

| 板型 | p1_nor_JYY070 + p1_nor 同树分流 |

| 需求 | 首页小窗对齐；全屏不花屏；与 p1_nor 共用源码 |

| 方案 | KTV_BOARD_JYY070 编译宏 + #ifdef（勿用 LV_PROJECTOR_DISP_ROTATE 区分板型） |

| 补丁 | jyy070-video-rect-dual-board.patch |

| 树内落地 | 应用层适配硬编码（UI 不旋转 + 视频 rect，无板宏） |

| 相关 UI 旋转双板 | LVGL 不旋转双板补丁 |

> 本目录保留「编译宏双板」方案与补丁，默认不进源码树。需要同树编 p1_nor / JYY070 时再打本补丁（见 §7）。

---

1. 背景

JYY070 实机：

  1. 小窗位置不对：沿用竖屏 (330,360,320,570)，与 DE 屏坐标不一致。
  2. 全屏花屏：sunxifb_get_sizes() / FB 1280×800 超出 DE0 1024×600。

| 层 | 分辨率 | 说明 |

|---|---|---|

| UI FB / Guider | 1280×800 | VSU 缩放到面板 |

| DE0 / LVDS | 1024×600 | 视频 frame 坐标系 |

| Guider btn_30 | (347,151,599,316)@1280×800 | 首页播放热区 |

p1_nor：逻辑 800×1280，不可被 JYY 硬编码长期盖掉。

---

2. 方案：KTV_BOARD_JYY070

| 包 | 入口 |

|---|---|

| sing_ktv 等 | sunxifb.mk：-DKTV_BOARD_JYY070=1（可同加 -DLV_PROJECTOR_DISP_ROTATE=0） |

| media_session | Makefile 单独 -DKTV_BOARD_JYY070=1（不能 include sunxifb.mk，会拉 freetype） |

两处都要 -D：客户端与 daemon 分包编译，TARGET_CFLAGS 不共享。

源码：#ifdef KTV_BOARD_JYY070 / #else（p1_nor）。不要用旋转宏区分板型。

rect 取值

| | JYY070（屏坐标） | p1_nor |

|---|---|---|

| 小窗 | (278,113,479,237) | (330,360,320,570) / daemon (330,330,320,600) |

| 全屏 / SCREEN | 1024×600 | 800×1280 |

换算：btn_30 ×(1024/1280)、×(600/800)。

---

3. 变更文件（补丁内）

| 文件 | 说明 |

|---|---|

| openwrt/.../sunxifb.mk | JYY：-DKTV_BOARD_JYY070=1 + DISP_ROTATE=0 |

| openwrt/.../media_session/Makefile | JYY：-DKTV_BOARD_JYY070=1 |

| sing_ktv/.../ktv_player_ui.c | 板分支小窗/全屏；去掉错误的 sunxifb_get_sizes |

| media_session/.../ktv_player_common.h | SCREEN_* 板分支 |

| media_session/.../ktv_player_ui.c | SMALL_RECT_* 板分支 |

---

4. 编译与验收

source build/envsetup.sh && lunch h133-p1_nor_JYY070-tina
m package/media_session/compile package/sing_ktv/compile
# 推 sing_ktv + media_sessiond 后重启；勿 sing_ktv 3

| 检查 | JYY070 期望 |

|------|-------------|

| 小窗 log | x=278, y=113, w=479, h=237 |

| 全屏 frame | frame[0, 0, 1024, 600] |

| p1_nor | 无 KTV_BOARD_JYY070，竖屏原行为 |

---

5. 补丁应用

基线： 假定源码仍为 p1_nor 原 rect（小窗 330/…、SCREEN 800×1280、全屏 sunxifb_get_sizes）。若树内已是 应用层适配硬编码，须先 patch -R 该最小补丁，或手改成 #ifdef 后再合 Makefile。

cd /path/to/H133-AIKTV
patch -p1 < H133-AI-Skills/开发记录/板件开发记录/JYY070/20260714-JYY070-视频小窗全屏rect双板兼容/jyy070-video-rect-dual-board.patch

撤销：patch -R -p1 < .../jyy070-video-rect-dual-board.patch

与 LVGL 不旋转双板 的 sunxifb.mk 重叠时：只保留一处 CONFIG_TARGET_h133_p1_nor_JYY070 块，内含 -DKTV_BOARD_JYY070=1 与 -DLV_PROJECTOR_DISP_ROTATE=0。

---

6. 注意

  1. KTV_BOARD_JYY070 = 板型 / rect；LV_PROJECTOR_DISP_ROTATE = UI 旋转，职责分离。
  2. media_session 必须单独 -D。
  3. 视频 WB 旋转另见 WB-mirror，仍用 Makefile 板型宏（树内保留）。
