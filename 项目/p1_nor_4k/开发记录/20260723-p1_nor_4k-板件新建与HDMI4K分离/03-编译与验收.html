03 — 编译与验收

3.1 编译

# SDK 根目录
./tools/build_p1_nor_4k.sh kernel    # 改 DTS / uboot 后
./tools/build_p1_nor_4k.sh rootfs    # 改 OpenWrt / desk 后
./tools/build_p1_nor_4k.sh full      # 完整

# 产物
out/h133_linux_p1_nor_4k_uart0_nor.img   # PhoenixSuit：IMAGEWTY
# 整片 NOR（编程器）：
out/h133/p1_nor_4k/pack_out/full_img.fex

确认 .buildconfig / lunch 为 p1_nor_4k，勿串板。

3.2 验收清单

  • 串口：DRAM: 256 MiB，分区含 rootfs / rootfs_data
  • 内核：cma: Reserved 8 MiB（基线；叠 CMA 专题后为 48 MiB）
  • 显示：smooth display / HDMI 已连接；fb 或 desk 日志为 3840×2160
  • desk 启动正常（Guider 图标可见）；不要求全屏 4K 壁纸
  • WiFi：rtl8733bu 模块可加载 / 可扫描

3.3 烧录提示

| 文件 | 用途 |

|------|------|

| out/h133_linux_p1_nor_4k_uart0_nor.img | USB 量产工具（头 IMAGEWTY） |

| pack_out/full_img.fex | SPI 整片镜像（头 eGON.BT0） |

NOR 为 32MiB；full_img.fex 须 < 32MiB。

3.4 回归

改本板时不要动其它板 board.dts。

验证：rg '3840|output_mode.*28' device/config/chips/h133/configs/p1_nor{,_8733,_JYY070,_JL_M101} --glob '**/board.dts' 应无命中（仅本板有）。
