# 01 — 板件新建（从 p1_nor_8733 克隆）

## 1.1 新建目录清单

### A. 板级配置（device）

源：`device/config/chips/h133/configs/p1_nor_8733/`  
目标：`device/config/chips/h133/configs/p1_nor_4k/`

| 项 | 处理 |
|---|---|
| 整树拷贝 | `cp -a p1_nor_8733 p1_nor_4k` |
| `linux-5.4/` | **拆软链**：从 `p1_nor/linux-5.4` 拷成**实目录** |
| `uboot-board.dts` / `sys_*.fex` / `env.cfg` | 若为软链 → 从 `p1_nor` 拷成实文件 |
| `board.dts` | `ln -sfn linux-5.4/board.dts board.dts` |
| `bootlogo.bmp` | 可从 8733 复制；可不进补丁 |

随后用 [patches/01-hdmi4k-dts-delta.patch](./patches/01-hdmi4k-dts-delta.patch) 改 HDMI 4K（详见 [02](./02-HDMI-4K-DTS与setting.md)）。

### B. OpenWrt target

源：`openwrt/target/h133/h133-p1_nor_8733/`  
目标：`openwrt/target/h133/h133-p1_nor_4k/`

| 项 | 处理 |
|---|---|
| 整树拷贝 | `cp -a h133-p1_nor_8733 h133-p1_nor_4k` |
| 文本替换 | `h133-p1_nor_8733`→`h133-p1_nor_4k`，`p1_nor_8733`→`p1_nor_4k`（**勿误伤** `RTL8733BU` 字符串时需人工看） |
| `setting.ini` 等 | 打 [02-openwrt-target-delta.patch](./patches/02-openwrt-target-delta.patch) |

包选型继承 8733：`rtl8733bu-kmod` + firmware，**不开 AIC8800 作用户态主 WiFi**。

### C. 编译脚本

[03-build-script.patch](./patches/03-build-script.patch) 新增：

```bash
./tools/build_p1_nor_4k.sh kernel|rootfs|full
# 产物：out/h133_linux_p1_nor_4k_uart0_nor.img
```

## 1.4 手工克隆（对照）

```bash
BASE=device/config/chips/h133/configs
OW=openwrt/target/h133

cp -a $BASE/p1_nor_8733 $BASE/p1_nor_4k
rm -rf $BASE/p1_nor_4k/linux-5.4
cp -a $BASE/p1_nor/linux-5.4 $BASE/p1_nor_4k/linux-5.4
# 拆 uboot/sys/env 软链为实文件后：
ln -sfn linux-5.4/board.dts $BASE/p1_nor_4k/board.dts

cp -a $OW/h133-p1_nor_8733 $OW/h133-p1_nor_4k
# sed 改板名后打 01～04 补丁
```
