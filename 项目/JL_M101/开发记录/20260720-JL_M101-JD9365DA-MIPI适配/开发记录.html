1. 背景与目标

1.1 为何对齐 8733 而不是裸 p1_nor / JYY070

| 参照 | 适用点 | 不直接当基线的原因 |

|---|---|---|

| p1_nor_8733 | 同 MIPI 竖屏 UI、异显、8733BU WiFi | —（选定基线） |

| p1_nor | 显示链路同源 | WiFi 为 AIC8800，与目标板不符 |

| p1_nor_JYY070 | 板件隔绝 / 分阶段文档可抄 | LVDS 横屏 + disp_rotate=0，显示框架不同 |

1.2 硬件要点（规格书 + init + 主板）

| 项 | 值 | 来源 |

|---|---|---|

| 模组 | JL-M101B196-P21WX-M402632 | 规格书 |

| IC | JD9365DA-H3 | 规格书 / 模组说明 |

| 分辨率 | 800(H)×1280(V) | 规格书 |

| 接口 | MIPI 4-lane（D0–D3 + CLK） | 规格书 Pin |

| Reset 时序 | H 5ms → L 10ms → H 120ms，再发码 | init txt |

| Porch（vendor） | HSA20 HBP20 HFP40 / VSA4 VBP20 VFP20 | init 头 |

| Allwinner 换算 | hspw=20 hbp=40 ht=880 / vspw=4 vbp=24 vt=1324 | 与现 p1_nor 注释时序一致 |

| RST / PWM | PB11 = LCD-RST / PB12 = LCD-PWM(=PWM0) | SoC GPIO 页 + s10 LCM 页 |

| 背光 PWM | LCD-PWM → PT4117B EN，50kHz | s10-h133-v1_0625.pdf：PWM_Frequence=50KHz |

| 转接板 RESET | LCD-RST → R52 → LCD_RST → CON5 pin6 RESET；R52/R53 选 3.3V 或 1.8V 分压 | s10-h133-v1_0625.pdf：3.3V-RESET: R52=0R,R53=NC / 1.8V-RESET: R52=1.5K,R53=1.8K |

| RESET 输入高 | VIH ≥ 0.7×IOVCC（VCC=3.3V 时约 2.31V） | JL 规格书 |

| LCD 供电使能 | LCD-EN | 第 14/15 页；控制 LCD 偏压/模拟电源，不是背光 LED 电源 |

| 背光 LED | VLED+ / VLED- | 第 14 页；外部背光接口，规格书典型约 12V/160mA |

| 主板显示历史 | JYY070 为 LVDS，非 MIPI 参考 | 本主板 MIPI 走 PD 组 + 转接板 CON5，未在实机验证过 DSI 出图 |

| 0x80=0x03 | 四 lane | init |

2. 设计原则

  1. 板件隔绝：新板 p1_nor_JL_M101；只改本板 configs/ 与 h133-p1_nor_JL_M101/。
  2. 一屏一驱动：jl_m101_jd9365da.c，不改 default_panel.c。
  3. 拆软链：本板 linux-5.4/ 为实文件（从 p1_nor 拷贝后再改），避免动 8733。
  4. App 先不动：disp_rotate=3、VIDEO_WB_MIRROR_ROTATE=90，复用 8733 竖屏路径。
  5. 最小公共改动：仅 panel 注册、兄弟板 Kconfig/defconfig 的 not set、libtmedia 增加本 target。

5. DTS lcd0 要点（本板，已按 s10 原理图对齐）

下面是按当前原理图结论应采用的方向；实际 DTS 仍需逐项核对 lcd_pwm_ch / LCD-EN 绑定，不能只把 PB12 当普通 GPIO 拉高。

lcd_driver_name     = "jl_m101_jd9365da";
lcd_if              = <4>;          /* DSI */
lcd_x / lcd_y       = <800> / <1280>;
lcd_dclk_freq       = <70>;         /* 实机可再调；vendor PLL_CLOCK=420 为 MTK 口径 */
lcd_hbp/ht/hspw     = <40>/<880>/<20>;
lcd_vbp/vt/vspw     = <24>/<1324>/<4>;
lcd_dsi_lane        = <4>;
lcd_gpio_0          = <&pio PB 11 …>;  /* RESET */
/* s10 原理图：PB12=LCD-PWM → PT4117B EN，禁止当普通 lcd_bl_en GPIO */
lcd_pwm_used        = <1>;
lcd_pwm_ch          = <0>;             /* PB12 复用 PWM0（mux 0x3） */
lcd_pwm_freq        = <50000>;         /* 原理图标注 PWM_Frequence=50KHz（非 500Hz） */

备注：

  • 2026-07-22：已按 s10-h133-v1_0625 + 京龙 init 对齐——开 pwm0@PB12、LCD_bl_open；init/porch 本就与 vendor txt 一致。
  • VLED+ / VLED- 是屏背光 LED 供电输出/接口；板载由 PT4117B 从 5V 升压驱动。
  • LCD-PWM 进 PT4117B 的 EN；勿把 PB12 配成 lcd_bl_en 纯 GPIO。
  • usbc0 里曾残留 usb_id_gpio=PB11、usb_det_vbus_gpio=PB12，会和 LCD RST/PWM 冲突，已从本板 DTS 移除。

9. 2026-07-20 实机调试流水

9.1 初始现象

  • 现象：背光亮，但 LCD 无图；HDMI 有图；烧回 p1_nor_8733 + 原配屏可出图。
  • 结论：主系统、DE/HDMI、rootfs/UI 不是首要问题；问题集中在 JL_M101 的 LCD MIPI/panel/电源控制。

9.2 U-Boot smooth display 问题

| 现象 / log | 判断 | 处理 |

|---|---|---|

| U-Boot 出现 boot_gui_init:start、jl_m101_jd9365da: panel_init，内核出现 smooth display screen:0 | U-Boot 已开屏并写 boot_disp，内核 smooth 复用状态，跳过内核 cfg_open_flow | boot_gui.c 读取 disp_init_enable，为 0 时直接 boot_gui_init:skip (disp_init_enable=0)；uboot-board.dts 设 disp_init_enable=<0> |

| 新 log 出现 boot_gui_init:skip，内核不再 smooth display，并出现 jl_m101_jd9365da: panel_init | smooth 问题排除，内核确实开始灌 JD9365 init | 进入 MIPI/panel 层排查 |

构建注意：一次 uboot_force 触发 OpenWrt rootfs 目标失败，但日志显示 boot_gui.o 和 u-boot.bin 已重新生成；后续用 ./build.sh pack 出包。另一次 U-Boot 增量编译遇到旧 .o 截断，使用 make clean 清理 U-Boot 后恢复。

9.3 init 写法试探

| 改动 | 镜像 md5 | 结果 |

|---|---|---|

| 去掉额外 soft reset，保留 0x11/0x29 特判为 DCS 0 参数 | d0d7f6a699bcd71ce2a1cef0c45a24f6 / 后续修正包 cb7a5b1dd4aef881850edc2750666c91 | U-Boot skip 生效，内核执行 panel_init，但 LCD 仍无图 |

| 全表按同系 jd9366ab_3 方式走 dsi_gen_wr()，不再特判 0x11/0x29 | 46f80d6df6d17389b058c556a18ac8bf | 现象不变 |

结论：单纯在 GEN/DCS 之间切 0x11/0x29 没有命中根因。

| c5132015ca06bfc4ff4ba35b5aeeb7db | 移除 USB 对 PB11/PB12 的占用，保留 probe 日志 |

9.6 DSI 读探针导致 panel_init 挂死（已修复）

| 现象 | 根因 | 处理 |

|---|---|---|

| log 仅有 probe pre 0x0A/0xDA num=0，无 post、后续 DISP 停 | LP 读触发 BTA，屏不回读时 DPHY 卡在读态；后续 dsi_gen_wr 内 while(dsi_inst_busy) 无超时 | 删除 LCD_panel_probe 及全部 sunxi_lcd_dsi_dcs_read |

修复后典型 log：jl_m101_jd9365da: panel_init → attached ok, mgr0<-->dev0 → type:1,mode:0（video）。

9.8 屏侧电压与转接板 RESET（2026-07-21）

| 测量点（用户：屏 FPC 侧） | 值 | 含义 |

|---|---|---|

| VCC | 3.3V | 数字供电正常 |

| RESET | 1.8V（静态） | 低于 VIH≈2.31V（按 3.3V IO 计）时，屏可能无法可靠退出复位/识别高电平 |

转接板 s10-h133-v1_0625.pdf（CON5 40P 座旁）：

  • R52（0402）：串在 LCD-RST（主板）与 LCD_RST（座子 pin5/6 链路）之间；丝印 R52，靠 CON5 LCD-RST / RESET 网络。
  • R53（0402）：分压到 GND，标 1.8K/NC。
  • 注释：3.3V-RESET: R52=0R,R53=NC；1.8V-RESET: R52=1.5K,R53=1.8K。

必做区分（改电阻前）： 万用表量 R52 靠主板 LCD-RST 输入端对地：

| R52 输入端电压 | 结论 | 动作 |

|---|---|---|

| 3.3V | 当前为 1.8V 分压档 | 改 R52=0R、R53=NC，撤外部灌 RESET，用现镜像重试 |

| 1.8V | SoC PB 域或上游即 1.8V | 换 R52/R53 无效，需电平转换或确认屏 IOVCC/逻辑电平 |

无效操作： 对 RESET 外部恒压 3.3V — 驱动需 H→L 10ms→H 硬件复位脉冲，外部强灌高电平会与 PB11 对打，脉冲发不出去，不能代替改 R52/R53。
