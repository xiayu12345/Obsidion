### 改动类型 → 编什么

| 改动 | 命令 |
|---|---|
| panel `.c` / 内核 DTS / config-5.4 | `kernel`，再 `pack` |
| uboot-board / U-Boot panel | `kernel`（含 bootloader）或单独 `./build.sh bootloader` + `pack`；必要时删旧 `u-boot-*.bin` 强制重编 |
| `setting.ini` / rootfs 应用 | `rootfs` |
| 全量 | `full` |

### 注意

- **禁止**在 WSL/x86 上对 desk/panel 源码本地 `gcc -c`（会污染 `.o`，交叉链接炸）  
- U-Boot 增量偶发旧 `.o`：可对 uboot 目录 `make clean` 或删对应 `.o` 后重编 bootloader  
- 改内核后若要重编 `rtl8733bu` ko：先有 `out/kernel/build` 的 `Module.symvers`，再 `rootfs`/`m`

## 5.3 常见问题速查

| 现象 | 优先查 |
|---|---|
| 背光亮无图 | RESET 档（R52/R53）、RESET 波形、MIPI HS；勿外部灌 RESET |
| `panel_init` 后无后续 DISP | 是否又加了 DSI 读；是否 U-Boot smooth |
| 完全不亮 | PWM0 是否 enable、PT4117 5V、VLED 接线 |
| USB 异常 / RESET 浮 1.8V | `usbc0` 是否又占用 PB11/PB12 |
| 8733bu Unknown symbol | 清 `.config` 后未按序编 ko |
