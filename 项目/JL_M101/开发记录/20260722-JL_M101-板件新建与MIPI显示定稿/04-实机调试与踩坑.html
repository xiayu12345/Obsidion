04 — 实机调试与踩坑（到完整出图）

4.1 时间线摘要

| 阶段 | 现象 | 结论 / 动作 |

|---|---|---|

| 初烧 JL 包 | 背光亮（或外部 VLED）、LCD 无图；HDMI 有图；回烧 8733+原屏正常 | 问题在本板 MIPI/panel/电源，非整机 DE/UI |

| U-Boot smooth | 内核 smooth display，跳过 cfg_open_flow | disp_init_enable=0；必要时 bootGUI 跳过 |

| init GEN/DCS | 切 0x11/0x29 写法 | 现象不变，非根因 |

| DSI 读探针 | 0x0A/0xDA 读回 0；后出现仅 pre、无 post | 删探针（DPHY 卡死） |

| USB 占脚 | PB11/PB12 作 usb id/vbus | 本板 DTS 注释掉 |

| burst 试验 | lcd_dsi_if=2 | 与 video 相同仍无图 → 改回 0 |

| RESET 电平 | 屏侧 RESET≈1.8V，VCC=3.3V | 改转接板 3.3V-RESET 档 |

| 背光软件 | 调通期关 PWM；资料对齐后开 PWM0@50kHz | 定稿恢复 LCD_bl_open |

| 2026-07-22 | 完整显示 | 软件管线 + 硬件 RESET + PWM 背光齐备 |

4.2 U-Boot smooth（必知）

若 U-Boot 已 panel_init 并写 boot_disp，内核可能打印 smooth display screen:0，复用状态、跳过内核 open_flow → 京龙 init 不在 Linux 侧重跑。

处理（本板定稿）：

  • uboot-board.dts：disp_init_enable = <0>
  • 串口应见内核 jl_m101_jd9365da: panel_init，且无（或不应依赖）smooth 跳过灌码

出图后再评估是否恢复 U-Boot logo。

4.3 DSI 读探针致命坑

临时加过：

sunxi_lcd_dsi_dcs_read(sel, 0x0A, ...);
sunxi_lcd_dsi_dcs_read(sel, 0xDA, ...);

屏不回读 → BTA/读态卡住 → 后续 dsi_gen_wr 死等。

定稿：禁止在本 panel 灌码路径加 LP 读探针。

4.4 RESET 硬件排查口诀

  1. 量屏 FPC：VCC、RESET 静态电压
  2. 量 R52 主板侧输入：区分「SoC 已是 1.8V」vs「板上分压成 1.8V」
  3. 本屏 VCC=3.3V → 用 R52=0R / R53=NC
  4. 不要外部强灌 RESET 高电平

软件 Reset 脉冲再正确，电平不够 VIH 也等于没复位。

4.5 健康 log（内核）参考

出图后典型应有：

jl_m101_jd9365da: panel_init
… disp_device_attached_and_enable …
… attached ok, mgr0<-->dev0 …
type:1,mode:0          /* video */

desk / fb：800x1280；disp_rotate=3 时 UI 方向与 8733 一致。

dclk real 105 / dsi_rate 150：H133 BSP 时钟表行为，单独出现不等于配错。
