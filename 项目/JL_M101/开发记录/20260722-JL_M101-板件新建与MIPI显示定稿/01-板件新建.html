01 — 板件新建（从 p1_nor_8733 克隆）

1.1 为何对齐 8733

| 参照 | 适用点 | 不直接当基线的原因 |

|---|---|---|

| p1_nor_8733 | 同 MIPI 竖屏 UI、异显、8733BU WiFi | —（选定基线） |

| p1_nor | 显示链路同源 | WiFi 为 AIC8800 |

| p1_nor_JYY070 | 「板件隔绝 + 分阶段文档」可抄 | LVDS 横屏 + disp_rotate=0，显示框架不同 |

目标： 只换屏驱动与本板 DTS；不把京龙屏硬塞进共享 p1_nor。

1.2 新建目录清单

A. 板级配置（device）

源：device/config/chips/h133/configs/p1_nor_8733/

目标：device/config/chips/h133/configs/p1_nor_JL_M101/

| 项 | 处理 |

|---|---|

| 整树拷贝 | cp -a p1_nor_8733 p1_nor_JL_M101 |

| linux-5.4/ | 必须拆软链：从 p1_nor/8733 拷成实目录后再改（8733 原是软链 p1_nor） |

| board.dts | 顶层可软链到 linux-5.4/board.dts（与工程习惯一致） |

| uboot-board.dts | 实文件，与内核 lcd0 同步改 |

| bootlogo.bmp | 可从 8733 复制；可不进补丁 |

| openwrt/、bsp/、env.cfg、分区 fex | 随克隆保留；hostname 等在 OpenWrt target 改 |

关键改动点（详情见 03）：

  • lcd_driver_name = "jl_m101_jd9365da"
  • 时序 / DSI 4-lane / lcd_gpio_0=PB11
  • lcd_pwm_ch=0 + pwm0 绑 PB12
  • usbc0 去掉对 PB11/PB12 的占用
  • config-5.4：CONFIG_LCD_SUPPORT_JL_M101_JD9365DA=y；关无关 LVDS panel（若需）

B. OpenWrt target

源：openwrt/target/h133/h133-p1_nor_8733/

目标：openwrt/target/h133/h133-p1_nor_JL_M101/

| 项 | 处理 |

|---|---|

| defconfig | CONFIG_TARGET_h133_p1_nor_JL_M101=y，BOARD 名改为本板 |

| vendorsetup.sh / lunch | h133-p1_nor_JL_M101-tina |

| busybox-init-base-files/etc/setting.ini | disp_rotate=3，tp_rotate=0（随 8733） |

| 包选型 | 继承 8733（含 rtl8733bu-kmod），不开 AIC8800 |

| hostname | 如 TinaLinux-JL_M101（可选） |

C. 编译脚本

tools/build_p1_nor_JL_M101.sh（对齐 JYY070 / 8733 脚本结构）：

kernel  → ./build.sh kernel bootloader + sync boot.img
rootfs  → m + p
full    → kernel + rootfs

用法：

./tools/build_p1_nor_JL_M101.sh kernel   # panel/DTS/uboot
./tools/build_p1_nor_JL_M101.sh full     # 完整镜像
# 产物：out/h133_linux_p1_nor_JL_M101_uart0_nor.img

1.3 公共挂钩（最小、必须）

仅这些共享点；不改其它板 DTS 业务值。

| 文件 | 内容 |

|---|---|

| kernel/.../lcd/Kconfig | CONFIG_LCD_SUPPORT_JL_M101_JD9365DA（default y，同 JYY070 风格） |

| kernel/.../disp/Makefile | disp-$(CONFIG_…) += lcd/jl_m101_jd9365da.o |

| kernel/.../lcd/panels.c / panels.h | #ifdef 注册 jl_m101_jd9365da_panel |

| U-Boot 侧同上 | 同名 Kconfig / panels |

| p1_nor / 8733 / JYY070 的 config-5.4 | # CONFIG_LCD_SUPPORT_JL_M101_JD9365DA is not set |

| 上述板 OpenWrt defconfig | # CONFIG_TARGET_h133_p1_nor_JL_M101 is not set |

| libtmedia/Makefile | CONFIG_TARGET_h133_p1_nor_JL_M101 → VIDEO_WB_MIRROR_ROTATE=90 |

运行时选屏： 只靠本板 DTS lcd_driver_name。其它板即使误编入 panel .o，只要不写该名字就不会用。

1.4 板件隔绝检查清单

新建或改完后自检：

  • rg jl_m101 device/config/chips/h133/configs/p1_nor{,_8733,_JYY070} → 无业务引用（仅允许 config not-set）
  • rg pwm0_pin_a …/p1_nor_JL_M101 → 仅本板
  • 未改 default_panel.c / 共享 sun8iw20p1.dtsi 迁就本屏
  • lunch / .buildconfig 的 LICHEE_BOARD=p1_nor_JL_M101

1.5 推荐克隆命令（干净树手工复现）

# 在 SDK 根目录
BASE=device/config/chips/h133/configs
cp -a $BASE/p1_nor_8733 $BASE/p1_nor_JL_M101

# 拆 linux-5.4 软链（若 8733 的 linux-5.4 指向 p1_nor）
rm -rf $BASE/p1_nor_JL_M101/linux-5.4
cp -a $BASE/p1_nor/linux-5.4 $BASE/p1_nor_JL_M101/linux-5.4
# 顶层 board.dts 指到实文件
ln -sfn linux-5.4/board.dts $BASE/p1_nor_JL_M101/board.dts

cp -a openwrt/target/h133/h133-p1_nor_8733 openwrt/target/h133/h133-p1_nor_JL_M101
# 再改 defconfig / vendorsetup / setting.ini 中的板名

# 复制并改名编译脚本
cp tools/build_p1_nor_8733.sh tools/build_p1_nor_JL_M101.sh
# 把脚本内 BOARD/LUNCH 改为 p1_nor_JL_M101 / h133-p1_nor_JL_M101-tina

随后按 02 改 panel 与 DTS。

也可直接打 phase1 合并补丁（见 20260720-…/patches/），再叠定稿期的 PWM/bl 改动。
