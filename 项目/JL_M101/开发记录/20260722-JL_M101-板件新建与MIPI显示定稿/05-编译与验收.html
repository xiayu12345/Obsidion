5.0 干净树打补丁

bash H133-AI-Skills/开发记录/板件开发记录/JL_M101/20260722-JL_M101-板件新建与MIPI显示定稿/patches/apply-jl-m101-display-final.sh
# 分段：01 panel | 02 board | 03 hooks | 04 docs

详见同目录 README.md「补丁」一节。当前已出图树不必再打。

5.1 编译

# SDK 根目录；确认 .buildconfig 为 p1_nor_JL_M101
./tools/build_p1_nor_JL_M101.sh kernel   # panel / DTS / bootloader
./tools/build_p1_nor_JL_M101.sh full     # + rootfs + pack

# 仅 pack（已有 boot/rootfs）
source build/envsetup.sh
./build.sh pack

产物：

out/h133_linux_p1_nor_JL_M101_uart0_nor.img

定稿参考 md5（2026-07-22）：05a696f4b7672bc692c645cc3e8bb468（后续重编会变）。

改动类型 → 编什么

| 改动 | 命令 |

|---|---|

| panel .c / 内核 DTS / config-5.4 | kernel，再 pack |

| uboot-board / U-Boot panel | kernel（含 bootloader）或单独 ./build.sh bootloader + pack；必要时删旧 u-boot-*.bin 强制重编 |

| setting.ini / rootfs 应用 | rootfs |

| 全量 | full |

注意

  • 禁止在 WSL/x86 上对 desk/panel 源码本地 gcc -c（会污染 .o，交叉链接炸）
  • U-Boot 增量偶发旧 .o：可对 uboot 目录 make clean 或删对应 .o 后重编 bootloader
  • 改内核后若要重编 rtl8733bu ko：先有 out/kernel/build 的 Module.symvers，再 rootfs/m

5.2 验收清单（出图定稿）

  • 内核编过，含 jl_m101_jd9365da.o
  • DTB：lcd_driver_name=jl_m101_jd9365da，lcd_pwm_ch=0，lcd_pwm_freq=50000，lcd_pwm_used=1
  • dmesg：panel_init → attached ok
  • LCD 完整出图；板载背光（PWM）正常
  • 分辨率 800×1280；desk disp_rotate=3 方向正确
  • WiFi 仍 rtl8733bu
  • （回归）串编 p1_nor_8733 / p1_nor_JYY070 DTS 未被本改动改坏

5.3 常见问题速查

| 现象 | 优先查 |

|---|---|

| 背光亮无图 | RESET 档（R52/R53）、RESET 波形、MIPI HS；勿外部灌 RESET |

| panel_init 后无后续 DISP | 是否又加了 DSI 读；是否 U-Boot smooth |

| 完全不亮 | PWM0 是否 enable、PT4117 5V、VLED 接线 |

| USB 异常 / RESET 浮 1.8V | usbc0 是否又占用 PB11/PB12 |

| 8733bu Unknown symbol | 清 .config 后未按序编 ko |
