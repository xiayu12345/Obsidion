## 1. 产品规则

| 项 | 决策 |
|---|---|
| 三路独立 | 改 UI 不会带动 HDMI / 视频；必须分别配 |
| HDMI 时序 | 始终横屏 1080p；转的是 **WB 从 DE0 抓来的那帧** |
| 视频 WB | **编译宏**，不读 `setting.ini`；`TPlayerSetRotate` 盖不住 |
| 缺 DTS 属性 | `dual_display_rot` 内核默认 **3**（270°） |
| 缺 ini 键 | `disp_rotate` 默认 **3**（`lv_orient_config.h`） |

## 2. 三路分别是什么

```text
                    LVGL 逻辑画布
                         │
              disp_rotate（sunxifb CPU 软转）
                         │
         ┌───────────────┴───────────────┐
         │ fb0 page1 → DE0 → LCD/MIPI    │  UI
         │ fb0 page0 未软转（HDMI 读这页）│  避免和 HDMI G2D 叠两次
         └───────────────┬───────────────┘
                         │
              DE0 合成（UI + 视频层）
                         │
         WB 抓 NV21 → G2D(dual_display_rot) → DE1 HDMI

视频层（同显 / WB mirror，disp_screen=1）：
  解码帧 → VIDEO_WB_MIRROR_ROTATE → 贴 DE0
         （另：video_rotate → TPlayerSetRotate，播放器自己的 G2D）
```

HDMI 转的不是 HDMI 分辨率，是「竖屏主显镜像到横屏 HDMI」的那一帧。

## 3. 控制入口

### 3.1 HDMI — 内核 DTS

| | |
|---|---|
| 键 | `disp` 节点 `dual_display_rot = <0\|1\|2\|3>`（0°/90°/180°/270°） |
| 文件 | `device/config/chips/h133/configs/<BOARD>/linux-5.4/board.dts` |
| 消费 | `kernel/.../disp/dev_disp.c`：`of_property_read` → `disp_dual_display_degree_to_g2d` |
| 缺省 | **未写则 3**。横屏板必须显式写 `<0>`，否则 HDMI 多转 270°（全绿/方向错） |
| 编什么 | kernel |

应用侧 `sunxifb` `FBIO_HDMI_SRC_FB0` 只保证 HDMI 读 **未软转的 fb 页**，不是角度旋钮。子进程勿 `sunxifb_exit()`，否则 desk 要 `sunxifb_hdmi_rotate_restore()`。

### 3.2 UI — `setting.ini`

| | |
|---|---|
| 键 | `[display] disp_rotate=0..3` |
| 文件 | `openwrt/target/h133/h133-<BOARD>/busybox-init-base-files/etc/setting.ini` |
| 运行时 | `/mnt/UDISK/setting.ini` **优先于** `/etc/setting.ini` |
| 启动 | `lv_orient_disp_rotate_boot()` → `sunxifb_init(rotated)`（desk / sing_ktv 等 `main.c`） |
| 覆盖 | 命令行 `argv[1]`（0..6）；`desk` 一般不传参 |
| 消费 | `platform/.../lv_drivers/display/sunxifb.c` CPU 软转 |
| 编什么 | rootfs（改 ini 即可；改 sunxifb 才重编 GUI 包） |

`LV_PROJECTOR_DISP_ROTATE`（`projector_config.h` 默认 3）只在 **没有有效 ini / 未走 `lv_orient_*`** 时兜底。当前 desk 以 ini 为准。

### 3.3 视频 — 两层，别混

| 层 | 入口 | 消费 | 编什么 |
|---|---|---|---|
| WB mirror（同显贴 DE0） | `openwrt/.../libtmedia/Makefile` `-DVIDEO_WB_MIRROR_ROTATE=` | `tlayer_ctrl.c` `dualDispPreparePerScreen`：`90`→`DispNvRotate90`；`0`→原 buffer；`180/270` 未实现 | **libtmedia**（rootfs） |
| 播放器 G2D | ini `[display] video_rotate=0..3` | `ktv_player_ui.c` → `TPlayerSetRotate` | rootfs（ini） |

`TPlayerSetRotate(0)` **不能**关掉 `VIDEO_WB_MIRROR_ROTATE=90`。

小窗/全屏矩形用同一份 ini 的 `disp_rotate` 做 **坐标映射**（`lv_video_fit_to_de`），那是位置不是画面朝向。

当前 Makefile 分板：

```makefile
# 竖屏 MIPI
ifeq ($(CONFIG_TARGET_h133_p1_nor)$(CONFIG_TARGET_h133_p1_nor_8733)$(CONFIG_TARGET_h133_p1_nor_JL_M101)$(CONFIG_TARGET_h133_p1_nor_ZS101),y)
TARGET_CFLAGS+=-DVIDEO_WB_MIRROR_ROTATE=90
endif
# 横屏
ifeq ($(CONFIG_TARGET_h133_p1_nor_JYY070)$(CONFIG_TARGET_h133_p1_nor_4k),y)
TARGET_CFLAGS+=-DVIDEO_WB_MIRROR_ROTATE=0
endif
```

未进任一 `ifeq` 的 target：C 侧默认 **0**。新竖屏板若不加 90，视频会横着。

## 5. 验收

| 检查 | 期望 |
|---|---|
| 串口 `[DISP] dual display ... G2D rotN ... (dual_display_rot=N)` | 与本板 DTS 一致 |
| `sunxifb_rot=N`（desk 启动 log） | 与 ini `disp_rotate` 一致 |
| `logread \| grep WB-MIRROR` | `VIDEO_WB_MIRROR_ROTATE=` 与 Makefile 一致 |
| 肉眼 | LCD / HDMI / 视频同向；竖屏板 HDMI 为横屏电视方向 |
