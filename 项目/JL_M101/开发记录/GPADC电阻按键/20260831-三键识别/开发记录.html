---

1. 硬件约定

原理图 USB/HDMI 页 KEY ADC，SoC 球 C11 = GPADC0：

AVCC 1.8V -- RA20 51k -- GPADC0 -- RA22 6.8k -- J9536 座子信号脚
                 |
               CA1 1nF -- GND

keyN_vol 必须写 芯片脚 mV（cat /sys/class/gpadc/data），不是座子外侧万用表值。两块板电阻档位相同，ADC 不同，不能共用一张电压表。

Vchip = 1.8 × (6.8k + R) / (51k + 6.8k + R)（RA22 串在座子外侧时）

电阻 → 功能（两块板一样）：

| 电阻 | 功能 | keyN_val | hex |

|------|------|------------|-----|

| 0Ω | 播放/暂停 | 164 | a4 |

| 3.3k | 上一曲 | 165 | a5 |

| 5.1k | 下一曲 | 163 | a3 |

| 6.8k | 音量减 | 114 | 72 |

| 15k | 音量加 | 115 | 73 |

板甲（RA22 未串进采样，电压偏低）

cat /sys/class/gpadc/data：3 / 106 / 161 / 208 / 404 mV。hexdump 五档已通过。

| 电阻 | ADC mV | keyN_vol |

|------|--------|------------|

| 0Ω | 3 | 3 |

| 3.3k | 106 | 106 |

| 5.1k | 161 | 161 |

| 6.8k | 208 | 208 |

| 15k | 404 | 404 |

板乙（经 RA22，与原理图一致；当前 DTS）

cat /sys/class/gpadc/data：207 / 291 / 335 / 373 / 533 mV。hexdump 五档已通过。

| 电阻 | ADC mV | keyN_vol |

|------|--------|------------|

| 0Ω | 207 | 207 |

| 3.3k | 291 | 291 |

| 5.1k | 335 | 335 |

| 6.8k | 373 | 373 |

| 15k | 533 | 533 |

J9538 是 MIC，不是 KEY。换板必须重新 cat /sys/class/gpadc/data，不要拿另一块的 mV 硬套。

2. 驱动行为

驱动：kernel/linux-5.4/drivers/input/sensor/sunxi_gpadc.c

  • keyN_vol 单位 mV，须从小到大
  • 电压 < 1.7V 视为按下
  • 窗口取相邻 key_vol 中点
  • EV_REP：长按 value=1 → 2 → 松开 0

4. 读取电压（改表前必做）

驱动已有 sysfs，单位 mV，就是 keyN_vol 该写的数。不要循环刷，按住一颗再读一次。

echo 0 > /sys/class/gpadc/data
cat /sys/class/gpadc/data

先选通道 0（GPADC0，写一次即可）。按住第一颗不松，再 cat；松手换下一颗按住，再 cat。空闲（没按）应接近 1800。读出来仍是 1800，说明没按住或座子不是 J9536。

dmesg 会同时打 vol_data:，和 cat 同一数字。镜像无 evtest。

五颗都记下来，从小到大 写入 key0_vol…key4_vol。换板必须重测，板甲/板乙两套数见第 1 节。

座子是 J9536，不要用旁边的 J9538（MIC-IN1）。

---

5. 测试键码

界面不会动（LVGL evdev 跳过 sunxi-gpadc）。只核 /dev/input。一次只按一颗。

5.1 查节点

grep -A 8 'sunxi-gpadc0' /proc/bus/input/devices

H: Handlers= 里的 eventN（常见 event1，号会变）。KEY= 里应有 114/115/163/164/165。

5.2 hexdump

hexdump -C /dev/input/event1

没有 hexdump 用：od -Ax -tx1 /dev/input/event1。测完一颗 Ctrl+C。

32-bit 一包 16 字节，看后 8 字节：type(2) code(2) value(4)。

| 出现的字节 | 含义 |

|------------|------|

| 01 00 | EV_KEY |

| a4 00 | 164 播放/暂停（0Ω） |

| a5 00 | 165 上一曲（3.3k） |

| a3 00 | 163 下一曲（5.1k） |

| 72 00 | 114 音量减（6.8k） |

| 73 00 | 115 音量加（15k） |

| value 01 | 按下 |

| value 02 | 连发（长按，驱动开了 EV_REP） |

| value 00 | 松开 |

下一行全 00 是 EV_SYN，不是松开。长按：value=1 → 一串 value=2 → 松开 value=0。

5.3 期望（电阻相同，两块板 hex 相同）

| 电阻 | hex | 键码 |

|------|-----|------|

| 0Ω | a4 | 164 |

| 3.3k | a5 | 165 |

| 5.1k | a3 | 163 |

| 6.8k | 72 | 114 |

| 15k | 73 | 115 |

须刷含对应板 keyN_vol 的 dtb 后再验。

7. 踩坑

  • 两块板电阻档位相同，ADC 差一截：板甲 3/106/161/208/404，板乙 207/291/335/373/533，表不能混用
  • key0_vol 在经 RA22 的板上不能写 0：座子短路芯片约 0.21V
  • 板乙上 5.1k 与 6.8k 只差约 38mV，接触不稳会串下一曲/音量减
