## 1. 一句话结论

独立驱动 `zs101_ili9881c` + 本板 DTS 时序（`dclk=73`）+ **Kconfig/panels 挂钩**；内核灌码、PWM0 背光，**2026-08-25 实机已点亮**。  
资料结论与实机一致：原生竖屏 800×1280，产品横屏走 `disp_rotate=3` / `dual_display_rot=3` / `VIDEO_WB=90`。

## 2. 软件定稿（屏）

| 项 | 值 |
|---|---|
| `lcd_driver_name` | `zs101_ili9881c` |
| 分辨率 | **800×1280**（`fb0` 跟物理，不把 fb 转成 1280×800） |
| `lcd_dclk_freq` | **73**（`936×1304×60`） |
| porch | HSA16/HBP60/HFP60 → `hspw=16` `hbp=76` `ht=936`；VSA4/VBP10/VFP10 → `vspw=4` `vbp=14` `vt=1304` |
| DSI | `lcd_if=4`，4-lane，`dsi_if=0`（video non-burst）；`dsi_clk_enable` 后 `dsi_gen_wr` 灌表 |
| RESET | **PB11** `lcd_gpio_0`；开屏 **H 10ms → L 20ms → H 200ms** 再发码 |
| 背光 | **PB12=PWM0 @ 50kHz**（`LCD_bl_open` → `sunxi_lcd_pwm_enable`） |
| UI | `setting.ini` **`disp_rotate=3`** → LVGL 1280×800 |
| HDMI | `dual_display_rot=3` |
| 视频 WB | `VIDEO_WB_MIRROR_ROTATE=90`（libtmedia 按本 target `-D`） |
| 内核 `disp_init_enable` | **1** |
| U-Boot | 调屏期 **`disp_init_enable=0`**（避免 smooth 跳过内核灌码） |
| 触摸 | 当时未做；定稿见 [20260827 GT928](../20260827-ZS101-GT928触摸适配/) |

init 来源：`硬件资料/纽曼/新代码02群创10.1(T2)+ILI9881C-0D_2P_20190920.c`（`0xFF,0x98,0x81` 翻页；`0x11` 120ms、`0x29` 20ms）。**禁止 DSI 读探针**。

关键路径：

| 角色 | 路径 |
|---|---|
| 内核 panel | `kernel/.../lcd/zs101_ili9881c.c` |
| U-Boot panel | `brandy/.../lcd/zs101_ili9881c.c` |
| 内核 DTS | `device/.../p1_nor_ZS101/linux-5.4/board.dts`（`&lcd0`） |
| U-Boot DTS | `device/.../p1_nor_ZS101/uboot-board.dts` |
| kernel config | `…/openwrt/bsp_defconfig` → `CONFIG_LCD_SUPPORT_ZS101_ILI9881C=y` |
| U-Boot 编进驱动 | `sun8iw20p1_defconfig`：`CONFIG_LCD_SUPPORT_ZS101_ILI9881C=y` |
| 工厂 ini | `openwrt/target/h133/h133-p1_nor_ZS101/.../setting.ini` |

## 3. 点亮缺的一环

2026-08-17 已克隆板级、写好 `zs101_ili9881c.c` 和 lcd0 时序，但 **Kconfig / `disp/Makefile` / `panels.c` 未注册**，U-Boot `sun8iw20p1_defconfig` 也没有 `LCD_SUPPORT_ZS101_ILI9881C`。  
结果：`build_p1_nor_ZS101.sh` 的 `verify_zs_uboot_config` 过不了，内核也不会链进本屏。

2026-08-25 补上挂钩后编出镜像，实机点亮。不要改共享 `ili9881c.c` / `default_panel.c`。
