---

1. 产品规则

| 项 | 决策 |

|---|---|

| 默认 | 同显 SAME |

| WB 管道 | 常开（启动/HPD enable 一次）；禁止为切模式拆建 WB |

| 切模式 | 只改 HDMI 上 WB 层显隐 + 视频 disp_screen |

| 播中切模式 | 不允许（-EBUSY） |

| HDMI 未插 | 视频强制 LCD |

| SAME | HDMI=WB 镜像；视频 DE0；hdmi_out=1 |

| DIFF | HDMI 上 WB 层 enable=0；视频 DE1；hdmi_out=0 |

---

2. 架构（最终）

启动/HPD → disp_dual_display_enable()     ← 只做一次，管道常驻
                │
disp_mode same  → SET_HDMI_OUT=1 + 视频下次播 screen=1
disp_mode diff  → SET_HDMI_OUT=0 + 视频下次播 screen=2

已废弃：

  • 用户态 disable / 模式里 DISP_DUAL_DISPLAY_DISABLE
  • g_dual_display_prefer_enable
  • 20260805 TEMP 补丁（编译期关 WB）

DISP_DUAL_DISPLAY_DISABLE 占号 0x408，内核直接 -EINVAL。

---

4. 内核 ioctl

| cmd | 值 | 用途 |

|---|---|---|

| DISP_DUAL_DISPLAY_ENABLE | 0x407 | 确保 WB 起来（幂等） |

| DISP_DUAL_DISPLAY_DISABLE | 0x408 | 废弃 → -EINVAL |

| DISP_DUAL_DISPLAY_GET_EN | 0x409 | WB 是否已 enable |

| DISP_FB_CLONE_ALLOW_* | 0x40a/40b | pan clone，默认关 |

| DISP_DUAL_DISPLAY_SET_HDMI_OUT | 0x40c | 关/开 HDMI 上 WB 层 |

| DISP_DUAL_DISPLAY_GET_HDMI_OUT | 0x40d | 当前 hdmi_out |

踩坑（历史）

曾用 DISABLE 拆 WB → scheduling while atomic（unregister 未 unlock）。产品路径只走 SET_HDMI_OUT。

---

5. 用户态 / 机上命令

disp_mode same|diff|get

sunxi_disp_mode_apply：fb_clone=0 → ensure_wb_up → set_hdmi_output。

按目标板编 kernel + rootfs。首验：./tools/build_p1_nor_JL_M101.sh full。
