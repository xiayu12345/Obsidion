## 2. 验收清单

- [ ] U-Boot 出现 `lq140_mipi2edp: panel_init dsi_clk_enable (no DCS)`（若开了 uboot 显示路径）
- [ ] 内核 `[DISP] dual display enabled: 1920x1080 … (dual_display_rot=0)`（WB 仍跟 lcd 设备）
- [ ] `[desk] fb 1280x800 -> LVGL 1280x800, sunxifb_rot=0 tp_rotate=0`
- [ ] DTS `fb0=1280×800`，`lcd_x/y=1920×1080`，`lcd_dclk_freq=139`（**勿用 93**）；`cma=8M` 即可
- [ ] LCD：1280×800 UI 经 DE0 放大铺满，无全绿/横纹/异常旋转
- [ ] HDMI：同步有图（抓 DE0 1080p），无旋转、无偏绿横纹、无明显右黑边
- [ ] cmdline 中 `cma=` 与预期一致（对照 `env.cfg`）
- [ ] `git diff` 无意外残留的 `dev_disp.c` 改动
