# 01 — 板件新建

## 1. 目标

新建独立板型 **`p1_nor_LQ140M1JW61`**：设备树、OpenWrt target、编译脚本与公共挂钩齐全，可 `lunch` / 出镜像。

推荐基线：横屏 + 双显经验可参考 **`p1_nor_JYY070` / `p1_nor_4k` 的旋转=0 思路**；MIPI 脚与 panel 框架可参考现有 MIPI 板。实际树为独立目录（整树已落地）。

通用流程见：[板件新建指南/如何创建新MIPI板件](../../板件新建指南/20260728-如何创建新MIPI板件/README.md)。


## 3. 公共挂钩（最小）

| 文件 | 做什么 |
|---|---|
| kernel/u-boot `lcd/Kconfig` | `LCD_SUPPORT_LQ140_MIPI2EDP` |
| kernel/u-boot `disp/Makefile` | `lq140_mipi2edp.o` |
| kernel/u-boot `panels.c/.h` | `#ifdef` 注册 |
| `sun8iw20p1_auto_nor_defconfig` | `CONFIG_LCD_SUPPORT_LQ140_MIPI2EDP=y`（U-Boot 侧） |
| **兄弟板** `config-5.4` | `# CONFIG_LCD_SUPPORT_LQ140_MIPI2EDP is not set` |
| 兄弟板 OpenWrt `defconfig` | `# CONFIG_TARGET_h133_p1_nor_LQ140M1JW61 is not set` |
| `libtmedia/Makefile` | 本 target → `VIDEO_WB_MIRROR_ROTATE=0` |

运行时选屏只靠本板 DTS：`lcd_driver_name = "lq140_mipi2edp"`。
