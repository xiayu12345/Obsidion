定稿参考 md5（2026-09-08 18:00 出图包）：`bd312edc87f1506e507d5bae3b8277fc`（后续重编会变）。

### 改动类型 → 编什么

| 改动 | 命令 |
|---|---|
| panel `.c` / 内核 DTS / config-5.4 | `./build.sh kernel`，stamp brandy，再 `m -j1 && p` |
| U-Boot panel / `uboot-board.dts` | **`./build.sh uboot`**（force）。**不要** `./build.sh kernel bootloader`（不会编 U-Boot）。确认 spinor 文件时间和 `strings \| grep xyc_k1_lvds` 后再 `p` |
| `setting.ini` / rootfs | `./tools/build_p1_nor_XYC_K1.sh rootfs` |

### 注意

- **禁止**在 WSL/x86 上对 panel 源码本地 `gcc -c`（会污染 `.o`，交叉链接炸）
- PATH 必须带 `prebuilt/hostbuilt/make4.1/bin`
- 改 U-Boot 后：`ls -l` 时间必须是刚才；`strings u-boot-spinor-sun8iw20p1.bin | grep xyc_k1_lvds`
- 串口认 `xyc_k1_lvds: open_flow`，**不要**认横幅里的 Sep 01 日期
- `./build.sh kernel bootloader` **≠** 编 U-Boot（见 04 §4.8）
- 确认镜像里已是新 U-Boot 后再 stamp，避免下次只编内核时被 skip

### 手工 NOR 流程（kernel 脚本绕过 brandy 时）

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
source build/envsetup.sh
cd brandy/brandy-2.0/u-boot-2018 && make sun8iw20p1_nor_defconfig && make -j
cd "$OLDPWD"
./build.sh kernel
# stamp u-boot-2018 和 spl-pub
m -j1 && p
```

## 5.3 常见问题速查

| 现象 | 优先查 |
|---|---|
| HDMI 纯绿 | TCON0 vsync：是否又加了 `panel_reset`；USB 是否又占 PB11/12 |
| `sunxi_pwm_probe` panic | pwm0 是否又 disabled |
| 有图灯不亮 | PB12 是否常高；VLED 接线；pwm0 是否抢了 pinctrl |
| 烧进去仍是旧 U-Boot / 只画 logo 不开屏 | 是否其实跑了 `kernel bootloader`（没编 U-Boot）；是否 stamp 后 skip brandy；`strings`+文件时间 |
| 触摸无设备 | 见 [BL3676 测试方法](../20260908-XYC_K1-BL3676触摸适配/测试方法.md)；`twi_drv_used=0`；`BETTERLIFE=y` |
