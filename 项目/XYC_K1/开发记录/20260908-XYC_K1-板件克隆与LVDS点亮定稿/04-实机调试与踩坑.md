# 04 — 实机调试与踩坑（到完整出图）

## 4.1 时间线摘要

| 阶段 | 现象 | 结论 / 动作 |
|---|---|---|
| 克隆 JYY070 | 板级/CTP 先通 | BL3676 报点正常 |
| 自写 panel + `panel_reset` | HDMI **纯绿** | 无 `lcd_gpio_0` 时 reset 踩 gpio0 → TCON0 停 vsync；写回 YUV=0 |
| USB 占 PB11/PB12 | 背光/复位脚被抢走 | 本板 `usbc0` 注释这两脚 |
| 照搬 JYY `lcd0` | HDMI **有图** | TCON0 已通；根因不在 DE/HDMI |
| 独立 `xyc_k1_lvds` + PWM `pol=1` | HDMI 有图、**灯不亮** | active low，PB12 大部分时间低，PT4117 EN 启不来 |
| `pwm0 { status=disabled }` | **`sunxi_pwm_probe` panic** | 父节点扫 pwm0~7，disabled 空指针 |
| **定稿** | LCD+HDMI 有图、灯常亮 | pwm0 okay 无 pinctrl；PB12 GPIO 拉高 EN |

## 4.2 HDMI 全绿（必知）

本架构：LCD=DE0/TCON0；HDMI 靠 writeback 跟 TCON0 vsync。TCON0 不出场，HDMI 就是绿。

已钉死会停 vsync 的软件：

1. `panel_reset()` 在没声明 `lcd_gpio_0` 时乱踩 gpio0  
2. `backlight_enable` 去抢未声明的 gpio  
3. USB 占 PB11/PB12  

**不要**为绿屏去改 HDMI 通路或 `chn_cfg_mode`。

## 4.3 pwm0 disabled 崩机

```text
pwm module init!
Unable to handle kernel NULL pointer dereference
PC is at sunxi_pwm_probe+0xbc
```

父 `pwm@2000c00` 的 `sunxi-pwms` 对每个通道 `of_find_device_by_node`。通道 disabled → 设备不存在 → 空指针。

处理：通道保持 **okay**；本板不用 PWM 就 **不要配 pinctrl**，把脚留给 GPIO。

## 4.4 背光不亮

| 查 | 说明 |
|---|---|
| `pwm_pol=1` | 亮度 210 时脚以低电平为主，EN 不满足 |
| 只插 16P | 16P 无灯条供电；必须接 `VLED+/VLED-` |
| PWM 抢脚 | pwm0 配了 `pwm0_pin_a` 则 GPIO EN 无效 |
| 量 PB12 | 定稿应常高 |

## 4.5 NOR U-Boot

| 错 | 对 |
|---|---|
| `./build.sh bootloader uboot force` | 会 distclean，XYC panel 从 `.config` 消失 |
| `make sun8iw20p1_defconfig` 当 NOR 包 | pack 用 **spinor**；必须 **`sun8iw20p1_nor_defconfig`** |
| PATH 没有 make4.1 | 用 SDK `prebuilt/hostbuilt/make4.1/bin` |

编完确认 `u-boot-spinor-sun8iw20p1.bin` 的 **文件时间是刚才**，`strings` 里有 `xyc_k1_lvds`。确认进镜像后再 stamp，避免后续只编内核时 pack 把 brandy 整棵重编。

## 4.8 源码改了 U-Boot，镜像里还是旧的（2026-09-08）

实机：U-Boot 只画 logo、不按 `xyc_k1_lvds` 开 PWM0 背光。串口横幅仍是 `U-Boot 2018.05 (Sep 01 2026 …)`。

两件事叠在一起：

| 错 | 实际发生 |
|---|---|
| `./build.sh kernel bootloader` | `mkcommon.sh` 碰到 `kernel` 就 `break`，ACTION=`build_kernel bootloader`，**根本不编 U-Boot** |
| 先 stamp `u-boot-2018/.newest-*.patch` 再 pack | `skip build brandy`，`u-boot-spinor-*.bin` 还是旧文件 |

横幅日期可能冻在 `lib/version.c`，**不能**当是否重编的依据。要看：

- `ls -l …/u-boot-spinor-sun8iw20p1.bin` 是否刚编出来
- `strings` 有 `xyc_k1_lvds`
- 串口有 `xyc_k1_lvds: open_flow` / `pwm0 bl on`

正确编法：`./build.sh uboot`（这才是 force），再 `p`。

## 4.6 已否定的岔路

| 尝试 | 结果 |
|---|---|
| 用 `jyy070_lvds` 当本板驱动 | 空 `LCD_bl_open`，不拉 EN |
| 把 PB12 当 PWM0 + `pol=1` | 大屏灯不亮 |
| `&pwm0 { status=disabled }` | 内核 panic |
| `lcd_gpio_0=PB11` 做 LVDS RST | 原理图 RST 不到 16P；乱拉会伤 TCON |
