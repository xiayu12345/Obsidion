## 4.1 编译（只动内核，不编 U-Boot）

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
# .buildconfig 须为 p1_nor_XYC_K1
./tools/build_p1_nor_XYC_K1.sh kernel
source build/envsetup.sh && p
```

产物：`out/h133_linux_p1_nor_XYC_K1_uart0_nor.img`

参考 md5（2026-09-09 11:09）：`2464ef33f137ad6e46773cccbb420dbf`（重编会变）。

禁止在 WSL 源码树本地 `make` / `gcc -c` 出 `.o`。

改 `bsp_defconfig` 后确认：

```bash
grep CONFIG_GPIO_SYSFS out/h133/kernel/build/.config
# 应为 y
```

dtb 里应有 `gpio_pin`、`key_cnt = <10>`（或 `<0xa>`）：

```bash
dtc -I dtb -O dts out/h133/kernel/build/arch/arm/boot/dts/board.dtb \
  | awk '/gpadc@/,/^[[:space:]]*\};/'
```

## 4.3 常见问题

| 现象 | 优先查 |
|---|---|
| 没有 `/sys/class/gpio` | 是否改了 `bsp_defconfig` 且 `.config` 为 y |
| 只有 10 键能拉低 ADC | PG18 是否仍被 owa/btlpm 占；驱动是否打印 mux gpio |
| 镜像时间没变 | 编完 kernel 有没有 `p` |
| 界面不动 | 正常：LVGL 仍跳过 `sunxi-gpadc` |
| 组反了 | 对调 `keyN_val` / `BkeyN_val`，或改 `gpio_pin` 极性 |
