# 如何改本板 BL3676

只改 **`p1_nor_XYC_K1` 的 `board.dts` `&twi1`**。`device/product/.../board.dts` 与 chips 同一 inode。不要改 JYY070 / 京龙 dts。

对照：[02-DTS与量程.md](./02-DTS与量程.md)、[测试方法.md](./测试方法.md)

```text
device/config/chips/h133/configs/p1_nor_XYC_K1/linux-5.4/board.dts
```

改完只编 kernel 再 pack：

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
./tools/build_p1_nor_XYC_K1.sh kernel
source build/envsetup.sh && p
```

禁止在 WSL 本地 `make` 出 `.o`。

---

## 1. 量程

`TP_MAX_X` / `TP_MAX_Y` 必须等于模组 ABS 最大值（本板 **1280×800**）。

四角 X 到不了 1280 或贴边：先 `getevent` 看 raw，再改这两个数。不要用 GSL 的 `ctp_report_max`。

## 2. 方向

本驱动没有 `revert` / `exchange`。

| 现象 | 先查 |
|---|---|
| 左右反 | 模组朝向；desk `tp_rotate`（本板应是 0） |
| 上下反 | 同上；不要抄 GSL `ctp_revert_y` 进这个节点 |
| XY 互换 | 不该发生；确认没改 LVGL evdev 校准 |

## 3. 地址 / 脚

换座或改原理图时同步 `reg` 和 `gpios`。`gpios[0]=RST`、`[1]=INT`，对调会没报点。

`bl_chip_custom.h` 的 `CTP_SLAVE_ADDR` 要和 DTS `reg` 一致（本板 `0x2c`）。

## 4. chipID 对不上

`Please specify the IC model:0x??`：I2C 通了但不是 `0x41`。核 `TS_CHIP`（本板 `BL7XX1`）和规格书，不要先改 DTS 地址碰运气。
