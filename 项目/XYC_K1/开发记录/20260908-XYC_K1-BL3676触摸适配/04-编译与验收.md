# 04 — 编译与验收

## 4.0 打补丁

当前出图树（LVDS 定稿已含 CTP）**不必再打**。只在板级仍是 GSL `ctp@40` 时：

```bash
bash H133-AI-Skills/开发记录/板件开发记录/XYC_K1/20260908-XYC_K1-BL3676触摸适配/patches/apply-xyc-k1-bl3676-tp.sh
```

须已有 `p1_nor_XYC_K1`。没有板级树时先打 LVDS 定稿（会连触摸一起带上）。

## 4.1 编译（只动内核，不编 U-Boot）

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
./tools/build_p1_nor_XYC_K1.sh kernel
source build/envsetup.sh && p
```

产物：`out/h133_linux_p1_nor_XYC_K1_uart0_nor.img`

禁止在 WSL 源码树本地 `make` / `gcc -c` 出 `.o`。

确认内核配置：

```bash
grep CONFIG_TOUCHSCREEN_BETTERLIFE_TS out/h133/kernel/build/.config
# 应为 y
grep CONFIG_TOUCHSCREEN_GSLX680NEW out/h133/kernel/build/.config
# 应为 is not set
```

dtb：

```bash
dtc -I dtb -O dts out/h133/kernel/build/arch/arm/boot/dts/board.dtb \
  | awk '/betterlife_ts@/,/^[[:space:]]*\};/'
```

应有 `reg = <0x2c>`，`TP_MAX_X/Y` 1280/800。

## 4.2 验收

机上步骤见 [测试方法.md](./测试方法.md)。

- [x] `1-002c`，不是 `1-0040`
- [x] `chipID = 41`
- [x] `betterlife-touch`，有 `/dev/input/touch`
- [x] 四角 raw 约 1280×800，左上原点
- [x] desk `tp_rotate=0` 跟手（屏时序定稿后）
