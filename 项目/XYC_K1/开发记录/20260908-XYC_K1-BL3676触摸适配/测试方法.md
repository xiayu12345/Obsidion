# BL3676 — 测试方法

串口 root。先确认驱动报点，再看桌面跟手。

---

## 0. 是不是这张镜像

```bash
ls /sys/bus/i2c/devices/
cat /proc/bus/input/devices
dmesg | grep -iE 'btl|betterlife|3676'
```

对了应有 **`1-002c`**、**`betterlife-touch`**、`I2C communication success:chipID = 41`。

| 实际 | 意思 |
|---|---|
| 只有 `1-0040` + `gslX680` | 烧成 JYY070 了 |
| `I2C communication ERROR` | TWI1 / 0x2C / RST |
| `Please specify the IC model:0x??` | 通了但不是 0x41 |
| 完全没 BTL | 没 probe |

I2C 再扫：

```bash
i2cdetect -y 1
# 0x2c 应显示 2c
```

---

## 1. 软链

```bash
ls -l /dev/input/
```

应有 `touch -> eventN`（常见 `event3`）。没有：`input_symlink.sh` 没匹配到设备名。

---

## 2. 报点

```bash
getevent -lt /dev/input/touch
# 没有 getevent 就：
hexdump -C /dev/input/touch
```

手指滑动要持续刷 `ABS_MT_POSITION_X/Y`。完全没输出：INT/RST 或模组没报。

不要用 `getevent -p`（`INOTIFY_USER` 关着会 `Function not implemented`）。

`id:15, x:4095, y:4095` 是空指槽，忽略。

---

## 3. 四角（已验，2026-09-08）

左上 → 右上 → 左下 → 右下：

| 位置 | raw（约） |
|---|---|
| 左上 | (5, 3) |
| 右上 | (1279, 0) |
| 左下 | (59, 779) |
| 右下 | (1260, 782) |

左上原点，X 往右、Y 往下。量程按 **1280×800** 配。desk 保持 `tp_rotate=0`。

## 4. 桌面

`getevent` 有数 = 硬件和驱动通。点不准先核 `TP_MAX` 和屏是否已按 1280×800 出图，再查 `tp_rotate`。
