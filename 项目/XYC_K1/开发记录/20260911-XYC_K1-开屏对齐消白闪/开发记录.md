# XYC_K1 开屏对齐厂 fex · 开机白闪 — 开发记录

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-11 |

| 硬件 | 本板 LTN141AT 系列 LVDS 1280×800。本仓 `p1_nor_JL_M101` 是 10.1" MIPI，**不是**同屏 |

## 1. 结论（先看这个）

| 决策 | 取值 / 做法 |
|---|---|
| 开屏流 | `pin_cfg + lcd_gpio_0(PB10)=1` → `tcon_enable`(50ms) → `pwm_enable` + `backlight_enable` |
| 背光 | **`lcd_pwm_used=1`**，PWM0@50kHz，`pol=0`；`&pwm0` **配 pinctrl**（PB12） |
| LCD-EN | **`lcd_gpio_0 = PB10`**；`usb1-vbus` **不再**占 PB10 |
| 时序 | 厂 fex：`dclk=67`，`ht=1380/hbp=20/hspw=10`，`vt=814/vbp=10/vspw=5` |
| LVDS 极性 | **不配** `lcd_lvds_io_polarity`；**不改** `de_lcd_sun50iw10.c` 去读 DTS |
| 勿做 | `panel_reset`（PB11 只到 MIPI CON5）；`./build.sh kernel bootloader`（U-Boot 编不进） |

09-08 定稿的「PB12 GPIO EN、不开 PWM、无 lcd_gpio_0」已被本专题覆盖。定稿文档已修订指向此处。

---

## 2. 现象与排查（简）

1. 怀疑「原厂翻页 / G2D 旋转」→ **排除**（只动 LVGL 用户态，不碰 BootGUI/内核 logo）。
2. 怀疑 `disp_init_enable` → **排除**（U-Boot `boot_gui_init()` 无条件开 BootGUI，不读该字段）。
3. 09-08 GPIO 开屏出现「logo → 白闪 → logo」→ 差在 **板级 open_flow / 背光 / LCD-EN**（无 PB10、未开 PWM）。
4. 把 DTS `0x1f` 写进 `de_lcd_sun50iw10` → **背光亮、无图**；回退后恢复。不要拿本仓 `JL_M101` MIPI 当同屏对照。

---

## 3. 极性坑（必读）

| | DTS 写 `lcd_lvds_io_polarity=0x1f` | 改 `de_lcd_sun50iw10` 按 DTS 写入 |
|---|---|---|
| H133 实际编的 `de_lcd_sun50iw10.c` | **无效**：只认 `LVDS_REVERT`（sun8iw20 未定义 → 寄存器保持 0） | 硬写 `0x1f` → 全反相 **无图** |

因此：**DTS 字面值不等于硬件极性。** 本专题：DTS **不配**极性；`de_lcd_sun50iw10` 保持原厂 `#if LVDS_REVERT`。

---

## 4. 相对 09-08 定稿的代码差

### 4.1 panel（内核 / U-Boot `xyc_k1_lvds.c`）

```text
旧：pin → (空 panel_init) → tcon 200ms → backlight_enable（仅 lcd_bl_en）
新：pin + PB10 EN → tcon 50ms → pwm_enable + backlight_enable
```

U-Boot 侧可留 `tick_printf("xyc_k1_lvds: open_flow")` / `pwm0 bl on` 便于确认新包进了镜像。

### 4.2 DTS（`linux-5.4/board.dts` 与 `uboot-board.dts` 同步）

| 项 | 09-08 | 本专题 |
|---|---|---|
| `lcd_dclk` / porch | 69 / 1416×816 | **67 / 1380×814**（厂 fex） |
| 背光 | `pwm_used=0` + `lcd_bl_en=PB12` | **`pwm_used=1` ch0 pol=0** |
| `lcd_gpio_0` | 无 | **PB10 LCD-EN** |
| `usb1-vbus` | `gpio=PB10` | **无 gpio**（脚还给 LCD-EN） |
| `&pwm0` | okay、无 pinctrl | okay、**pwm0_pin_a/b** |
| `lcd_lvds_io_polarity` | 无 | **无**（刻意不配） |
