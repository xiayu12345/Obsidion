JYY070 视频 WB mirror 旋转角 — 开发记录

项内容
日期2026-07-13
板型p1_nor_JYY070
关联板型p1_nor、p1_nor_8733（保持 VIDEO_WB_MIRROR_ROTATE=90）
需求JYY070 播视频不再多转 90°，与 UI 横屏 1280×800（不软旋）一致
补丁jyy070-video-wb-mirror-rotate.patch
前置UI 现由 setting.ini disp_rotate=0 控制（见 板级档案）；本补丁只定视频宏
定稿JYY070：VIDEO_WB_MIRROR_ROTATE=0；p1_nor / 8733：90（与远端 tp_good_xia_jyy070 一致）

1. 背景

JYY070 实机现象：LVGL 界面方向正确，TPlayer 视频仍被旋转 90°。

UI 与视频是两条独立链路：

链路配置入口JYY070 取值
UI（LVGL / sunxifb）setting.ini disp_rotate（lv_orient_disp_rotate_boot）0（不软旋）
视频（TPlayer DE 层）libtmedia/Makefile → VIDEO_WB_MIRROR_ROTATE0（本补丁）

应用层 TPlayerSetRotate(0)（如 ktv_player_ui.c）只关播放器 G2D 旋转，不能覆盖 WB mirror 路径里的 DispNvRotate90。

2. 根因

文件： platform/allwinner/multimedia/libtmedia/tplayer/awsink/tlayer_ctrl.c

  1. LayerCreate() 写死 disp_screen = 1（WB mirror：视频只送 DE0/MIPI，HDMI 镜像 DE0 合成）
  2. SetLayerParam() → dualDispPreparePerScreen() → 原逻辑对 disp_screen==1 固定 DispNvRotate90()（CPU 90°）
  3. cedarx.conf 的 g2d_rotate_flag、dual_disp_mipi_rotate 等为 0，不是主因
解码帧 (横屏 NV21)
  → SetLayerParam
  → dualDispPreparePerScreen（改前：无条件 DispNvRotate90）
  → per_screen_* → queueToDisplay → DE0(MIPI)
  → HDMI WB 镜像

3. 放弃的方案

方案不采用原因
cedarx.conf 改 dual_disp_mipi_rotate运行时配置，板型差异难维护；与编译期板型选型不一致
rc.final sed 改配置权宜之计，非根治
libcedarx/Makefile + set_cedar_conf.sh 注入同上，已撤销
板型宏 BOARD_P1_NOR_JYY070 + C 内映射用户要求用角度命名，不用板型宏
Makefile 开 VIDEO_WB_MIRROR_ROTATE_90 / _0 选型宏，C 再映射成数值多一层间接，与 sunxifb.mk 的 -DLV_PROJECTOR_DISP_ROTATE=0 风格不一致

4. 最终实现

4.1 编译宏（按 target 传角度，与 UI 对齐）

openwrt/package/allwinner/multimedia/tina_multimedia/libtmedia/Makefile

openwrt/package/thirdparty/gui/lvgl-8/sunxifb.mk： UI 双板 -DLV_PROJECTOR_DISP_ROTATE=0 不进树（见 LVGL 不旋转双板补丁）；本记录补丁若含该 hunk，与当前最小 UI 树互斥，打补丁时跳过或先恢复头文件默认 3。

4.2 tlayer_ctrl.c 消费宏

顶部： 未定义时默认 0，不再维护 _90/_0 选型宏映射块。

dualDispPreparePerScreen() 按角度分支：

VIDEO_WB_MIRROR_ROTATE行为
90createRotateBuf + DispNvRotate90，填 per_screen_*（p1_nor 原行为）
180 / 270打 log，return -1（预留）
0原横屏 buffer 直填 per_screen_*，走同一 queueToDisplay 路径

SetLayerParam()： disp_screen==1 || disp_screen==3 时始终调 dualDispPreparePerScreen（不再 #if 写死 90°）。

LayerCreate()： 启动 log

[WB-MIRROR] video disp_screen=1 (DE0 only, HDMI WB), VIDEO_WB_MIRROR_ROTATE=%d

4.3 板型隔离

TargetUI 宏视频宏
h133_p1_nor / h133_p1_nor_8733默认 LV_PROJECTOR_DISP_ROTATE=3VIDEO_WB_MIRROR_ROTATE=90
h133_p1_nor_JYY070LV_PROJECTOR_DISP_ROTATE=0VIDEO_WB_MIRROR_ROTATE=0

5. 变更文件

文件说明
openwrt/.../libtmedia/Makefile按 target -DVIDEO_WB_MIRROR_ROTATE=90/0
platform/.../tlayer_ctrl.c角度分支、SetLayerParam 统一走 dualDispPreparePerScreen、启动 log
openwrt/.../sunxifb.mk注释更新（UI/视频均为 0）

未改动： generated/、cedarx.conf、rc.final、TPlayerSetRotate 调用处、内核 disp。

6. 补丁应用

前置： 若尚未打 jyy070-lvgl-no-rotate.patch，本补丁含 sunxifb.mk 的 LV_PROJECTOR_DISP_ROTATE=0 块；若已打过 LVGL 补丁，打本补丁时 sunxifb.mk 可能冲突，可只保留注释行改动或跳过该 hunk。

撤销：

补丁含 3 个文件：

文件必要性
libtmedia/Makefile必须
tlayer_ctrl.c必须
sunxifb.mk可选（注释同步；LVGL 补丁已含逻辑块）

9. 后续新板

  1. 仅 UI 旋转： 在 sunxifb.mk 加 target 分支 -DLV_PROJECTOR_DISP_ROTATE=<0|1|2|3>
  2. 仅视频 WB mirror 旋转： 在 libtmedia/Makefile 加 -DVIDEO_WB_MIRROR_ROTATE=<0|90|180|270>
  3. 两宏独立配置；JYY070 为 UI=0、视频=0 的组合
  4. 180/270 需在 dualDispPreparePerScreen 补实现后再开宏
