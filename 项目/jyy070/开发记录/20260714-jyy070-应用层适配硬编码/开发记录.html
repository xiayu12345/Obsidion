项内容
日期2026-07-14
板型p1_nor_JYY070（硬编码；不兼顾 p1_nor）
范围应用层：UI 不旋转 + 视频小窗/全屏 rect（同属一层适配，合并记录）
方案改头文件默认旋转角、改 DE 屏坐标数字；不改 sunxifb.mk / 板型 ifeq
补丁jyy070-app-layer-adapt-minimal.patch
退回 p1_nor见 §6：patch -R 或手工改回 DISP_ROTATE=3 + 竖屏 rect（应用层适配 p1_nor）
双板（不进树）UI：LVGL 编译宏 · rect：rect双板兼容
非本范围视频 WB：libtmedia/Makefile 的 VIDEO_WB_MIRROR_ROTATE（树内仍按板型宏）

本目录合并原「LVGL 不旋转最小改动」与「视频小窗/全屏 rect 硬编码」。

1. 背景

1.1 UI 旋转

  • 默认 LV_PROJECTOR_DISP_ROTATE=3（270° 软转）不适配 JYY070
  • desk 不读 argv / setting.ini，只能编译期默认或 -D
  • 最小做法：各 app projector_config.h / 兜底宏改默认 0（不在 mk 加板型分支）

1.2 视频小窗 / 全屏

层分辨率说明
UI FB / Guider1280×800VSU 缩放到面板
DE0 / LVDS1024×600视频 frame 坐标系
Guider btn_30(347,151,599,316)热区 @1280×800

现象：小窗仍用竖屏 (330,360,320,570)；全屏用 FB 1280×800 → 花屏。

# mgr0: 1024x600
# UI: fb[1280,800] frame[0,0,1024,600]

6. 退回改动：恢复为 3 / 适配 p1_nor

本补丁把 UI 默认旋转换成 0、视频 rect 写成 JYY DE 屏坐标。编 p1_nor（竖屏逻辑、LV_PROJECTOR_DISP_ROTATE=3）前必须整包退回。

目标（退回后）：

项p1_nor 期望
UI 旋转宏默认LV_PROJECTOR_DISP_ROTATE = 3（270°）

lunchh133-p1_nor-tina（非 JYY070）

6.1 推荐：反打本最小补丁

patch -R 会把补丁里所有文件一并还原，包括：各 app 的 DISP_ROTATE 0→3，以及小窗/全屏 rect。

6.2 手工对照（改乱 / 无法 patch -R）

① UI 旋转：全部改回默认 3

文件改回

sing_ktv/.../projector_config.h同上
liyuan_opera/.../projector_config.h同上
MixStation / LiveStreamPlayer / BluetoothPlayer / ai_mv 的 main.c 兜底宏同上

② 视频 rect — sing_ktv ktv_player_ui.c

③ 视频 rect — media_session

6.3 退回后验收（p1_nor）

检查期望
宏默认LV_PROJECTOR_DISP_ROTATE == 3
日志sunxifb_rot=3
小窗≈ (330,360,320×570) / daemon (330,330,320×600)
全屏sunxifb_get_sizes / SCREEN 800×1280

说明：

  • 视频 WB：p1_nor 树内由 libtmedia/Makefile 传 VIDEO_WB_MIRROR_ROTATE=90，不在本补丁内，退回应用层后 lunch p1_nor 重编即可。
  • 若要同树双板共存：先完成本节退回（默认回到 3 + 竖屏 rect），再打 UI / rect 双板补丁，而不是长期停在 JYY 硬编码。

7. 限制

  • 同树编 p1_nor 会错，须先按 §6 退回（恢复为 3 / 竖屏 rect）或改用双板补丁。
  • set_right_rect 的 x/w（115,570）未按屏重算，仅改高度基准。
  • 视频 WB 旋转不在本补丁内。
