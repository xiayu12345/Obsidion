## 1. 一句话结论

这块 5 寸是 **MIPI 4-lane 720×1280 + ST7121P**，H133 原生 DSI **能驱**。  
京龙 s10 的 **CON5（40P、给 JL-M101 10.1"）不能对插**；缺独立 **IOVCC 1.8V**，RESET 必须改 **1.8V 档**，背光是 **18V / 40mA** 不能走京龙现成 ~160mA。要用京龙板点屏，必须 **转接线 + 补 1.8V + 改 RESET 档 + 背光单独处理**。

项目归属：规格书是 **深圳市婺芯源光电**，不在京龙/纽曼等客户目录，**对不上现有项目**。

### 2.2 FPC（33 pin）与京龙 CON5（40 pin）对不上

规格书 §4（以表格为准；结构图网名顺序不同，做转接线时 **先确认 pin1 方向**）：

| 5" pin | 5" 信号 | 京龙 CON5 | 说明 |
|--------|---------|-----------|------|
| 1–2 | VCC 2.8V | pin2–3 **VCC-3.3V** | 3.3V = 模组工作上限，可试机，长期最好 2.8/3.0V |
| 4–5 | D2N/D2P | pin17–18 D2 | lane **顺序不同**，转接线要重排 |
| 7–8 | D1N/D1P | pin11–12 D1 | |
| 10–11 | TCN/TCP（时钟） | pin14–15 CK | §4 把 10–11 写成「数据」、13–14 写成「时钟」，**以符号 TCN/TCP 为准** |
| 13–14 | D0N/D0P | pin8–9 D0 | |
| 16–17 | D3N/D3P | pin20–21 D3 | |
| 19 | RESET | pin5 RESET | 必须改 1.8V 档，禁止 3.3V 直灌 |

| 26 / 27 | LEDA / LEDK | pin39–40 LED+ / pin31–32 LED− | 电流电压都不同 |
| 29–32 | TP-RST/INT/SDA/SCL | 不在 CON5（京龙 TP 在 JP702 45P / GSL3670） | 触摸另接 TWI，不用 GSL |

### 2.4 Init

`…/ST7121P_MDT5.0(MLAG050WQ11 G)_initial code_gamma2.2_260819 - 副本.txt`

- `SSD_SEND(0x11, cmd, …)`：SSD2828 **DCS write**，后面才是 ST7121P 寄存器
- H133 **不要 SSD2828**，把 payload 转成 `dsi_dcs_wr` / `dsi_gen_wr`
- 收尾：`0x11` delay 120ms → `0x29` → `0x35,0x00`（TE off）delay 20ms
- 一屏一驱动：`wxy050_st7121p.c`，不改 `jl_m101_jd9365da.c`

### 2.5 旋转

模组 70.7×124.8，短边 × 长边，像素 **720×1280** → **原生竖屏**（同类：JL_M101 / ZS101）。  
产品要横屏 UI：拟定 `fb0=720×1280`、`disp_rotate=3`（LVGL 1280×720）、`VIDEO_WB=90`。未实机确认。

## 3. 京龙 s10 硬件：能不能驱

| 项 | 京龙 JL-M101（已点亮） | 本 5" | 结论 |
|---|---|---|---|
| SoC DSI | H133 4-lane video | ST7121P 4-lane video | **能**（软件换 panel） |
| 分辨率 / dclk | 800×1280 / 70 | 720×1280 / 78 | **能**（比京龙还小） |
| 接插件 | CON5 **40P**，脚序=京龙 10.1" | FPC **33P**，脚序完全不同 | **不能对插** |
| VCC | 3.3V（京龙 VCC typ 3.0，max 3.4） | 2.8V typ，**max 3.3** | 3.3V 顶格，可试、有风险 |
| IOVCC | 京龙模组无独立 1.8V 脚 | **必须 1.8V** | CON5 **没有**，要飞线 `VCC-LCD-1V8` |
| RESET | 3.3V 档：R52=0R、R53=NC | IOVCC=1.8V，3.3V 会超 | 改 **1.8V-RESET：R52=1.5K、R53=1.8K** |
| 背光 | 4 串 8 并，**12V / 160mA**；Rs≈1.1Ω→~180mA | 6 串 2 并，**18V / 40mA** | **不能直连**；改取样电阻，并确认驱动能否到 18V |
| TP | 板载 **GSL3670**，45P JP702；主机 TWI1 **3.3V** `0x40` | ST7121P **TDDI 内置**，I2C 在 LCD **33P** 上，IO=**1.8V** | **京龙 TP 通路完全不能用**；见 §3.1 |

H133 电源树有 1.8V（`VCC-LCD-1V8`），**板子上有电，只是没出到 CON5**。

RESET 分压（s10 注释）：

| 档 | R52 | R53 | 用于 |
|---|---|---|---|
| 3.3V-RESET（京龙 10.1" 现用） | 0R | NC | **不要**给本屏 |
| **1.8V-RESET** | **1.5K** | **1.8K** | 本屏 RESX |

禁止：外部恒压灌 RESET（会和 PB11 对打）。

背光：京龙 PT4117 标注 `R=200mV/I(led)`、IMAX=0.2A，已点亮 12V/160mA。本屏 40mA → Rs 约 **5Ω**（0.2/0.04）。18V 是否在该 IC 输出范围内，接线前量 CON5 LED+ 开路电压、核对料号。过流会烧灯条。

### 3.1 触摸（TDDI，不是独立 TP）

这块不是 GT911 / GSL 那种外挂电容芯。ST7121P 是 **显示+触摸一体（TDDI）**：ITO 电极在 IC 里，主机只看到 FPC 上 4 根线。

| 5" pin | 符号 | ST7121P | 电平 |
|--------|------|---------|------|
| 29 | TP-RST | `TP_RESX`，低有效 | **IOVCC 1.8V** |
| 30 | TP-INT | `TP_INT` 数据就绪 | 同上 |
| 31 | TP-SDA | `TP_I2C_SDA` | 同上，400 kHz I2C |
| 32 | TP-SCL | `TP_I2C_SCL` | 同上 |
| 33 | TP-VCC | 规格书 **NC**；结构图写 **TP-VCC3V** | 对不上，飞线前确认 |

京龙现成触摸：

| 京龙 | 本屏 | |
|------|------|--|
| JP702 **45P** → 板载 GSL3670 | 触摸在 **LCD 33P** 上，CON5 **没有** TP 脚 | 插座不通 |
| 主机 TWI1 PG8/PG9，`0x40`，INT=PG3，RST=PG2，**3.3V** | 从机是 ST7121P，IO **1.8V** | 3.3V 直灌会超 IOVCC |
| 驱动 `gslX680new` + `gsl3670.bin` | 工程里 **没有** Sitronix TDDI 驱动 | 软件不通 |

H133 的 TWI1/PG2/PG3 **可以接到这 4 根脚**（和接 GT928 同一组），但必须：

1. 从 5" FPC 飞线，**不要**插 JP702 / 不要走 GSL3670
2. I2C/RST/INT **1.8V**（电平转换，或确认该 GPIO 组已是 1.8V；京龙 CTP 页是 `VCC-3V3`）
3. 厂商要 **I2C 7-bit 地址、报点协议、TP 固件**。Datasheet §5.12 只写了 I2C/SPI 从机，地址在图里抽不出来；模组规格书初始化写「请联系我们」；树内也没有 `.h` / linux 驱动

点屏可以先不接 TP。要触摸就向婺芯源要 TDDI host 协议，不能复用 GSL3670。

## 4. 要用京龙板点屏，硬件最少做什么

1. **33P↔40P 转接线**（或夹具）：MIPI D0–D3 + CLK 按符号对接，不要按 pin 号照抄；GND 多接。
2. **IOVCC**：从 `VCC-LCD-1V8` 接到屏 pin21。
3. **VCC**：可先用 CON5 3.3V 试；稳妥则 LDO 到 2.8/3.0V。
4. **RESET**：改 R52/R53 为 1.8V 档；确认屏脚静态 ≈1.8V，且 PB11 仍能打出 H→L→H。
5. **背光**：不要直接吃 CON5 LED± 的 160mA 档；外接 18V/40mA 恒流，或改 Rs 并确认升压够 18V。
6. 软件：独立 panel + 本板 DTS（720×1280、porch/dclk 如上）；调屏期 U-Boot `disp_init_enable=0`。
7. 触摸：**先不接**。若接：FPC 29–32 飞到 TWI1+PG2/PG3，**1.8V**，关掉 GSL3670；缺地址/固件前不要灌 3.3V。
