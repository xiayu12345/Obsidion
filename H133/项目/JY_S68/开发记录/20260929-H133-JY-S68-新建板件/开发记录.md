# H133 金运 S68 — 新建板件

从京龙 NOR 整板复制，只换板件号。屏驱这一步仍是 `jl_m101_jd9365da`。触摸脚位和固件见同级「触摸」。

选京龙 NOR 做源，是因为 S68 的屏资料也是 JD9365DA-H3 / 800×1280，BOM 是 SPI-NOR。没有另做 eMMC 板。

## 复制出来的目录

- `device/config/chips/h133/configs/p1_nor_JY_S68/`
- `openwrt/target/h133/h133-p1_nor_JY_S68/`
- `tools/build_p1_nor_JY_S68.sh`

文本里的 `p1_nor_JL_M101`、`h133-p1_nor_JL_M101` 改成 JY 板号。`Makefile` 的 BOARDNAME 写成 `金运 S68，克隆京龙 NOR / JD9365DA MIPI + RTL8733BU`。主机名写成 `TinaLinux-JY_S68`。其它板的 OpenWrt defconfig 补上 `# CONFIG_TARGET_h133_p1_nor_JY_S68 is not set`。本板 defconfig 是 `CONFIG_TARGET_h133_p1_nor_JY_S68=y`，并关掉京龙那条 target。

`build/pack` 把金运加进竖屏 `bootlogo.bmp` 覆盖列表。开机图从京龙 NOR 复制来的竖图。`openwrt/README.md` 的 lunch 表加上 `h133-p1_nor_JY_S68-tina`。`libtmedia` 的视频旋转跟京龙一样是 270°。

编译入口：

```bash
./tools/build_p1_nor_JY_S68.sh full
```

这一步还没有镜像。
