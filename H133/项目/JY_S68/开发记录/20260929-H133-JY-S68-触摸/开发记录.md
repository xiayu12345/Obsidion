# H133 金运 S68 — 触摸

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-29 |
| 板件 | `p1_nor_JY_S68` |
| 资料 | `AI-skiil/硬件资料/金运/` 里的 `QD101T41A01-K.h`，原理图页 `HDMI_MIPI_CTP` |
| 补丁 | [patches/](./patches/) |

芯片仍是 GSL3670，配置不是京龙那份。固件头第一项京龙是 `0xd93b89`，金运是 `0xd18509`。驱动按 `ctp_name` 找 `gsl_firmware/<名字>.bin`，所以金运用 `gsl3670_jys68`，不覆盖京龙的 `gsl3670.bin`。

| 项 | 金运 S68 | 京龙 |
|---|---|---|
| 驱动 | `gslX680new` | 同左 |
| 节点 | `ctp@40`，`allwinner,gslX680` | 同左 |
| 名字 | `gsl3670_jys68` | `gsl3670` |
| 总线 | TWI2，PG6=SCL，PG7=SDA | TWI1，PG8=SCL，PG9=SDA |
| 中断 / 复位 | PG5 / PG4 | PG3 / PG2 |
| 地址 | I2C `0x40` | 同左 |
| 量程 | 交换 X/Y 后 1280×800，对齐 `disp_rotate=3` | 同左 |

原理图上 PG8/PG9 是 EEPROM `BL24C02` 的 I2C1，PG2/PG3 是 UART4。SDA/SCL 有 2k 上拉，串联 47Ω。

TWI2 从 PC0/PC1 改到 PG6/PG7，400 kHz，DMA 通道 44。克隆来的 AC107 挂在这条 I2C 上，原理图没有这颗 codec，节点关掉。TWI1 留着，DMA 关掉，避免和触摸抢通道。

头文件装到 `kernel/linux-5.4/drivers/input/touchscreen/gslx680new/GSL3670_JY_S68.h`。bin 在本板 `lib/firmware/gsl_firmware/gsl3670_jys68.bin`，`CONFIG_EXTRA_FIRMWARE` 只编这一份。

上机如果方向反了，再改 `ctp_revert_x_flag` / `ctp_revert_y_flag`。
