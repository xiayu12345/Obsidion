# 07 — DE0 硬件缩放 1280×800 → 1024×600

**上一步：** [05-HDMI异显dual_display_rot.md](./05-HDMI异显dual_display_rot.md)（可与 04 并行，仅改 DTS）  
**下一步：** [06-编译与实机验证.md](./06-编译与实机验证.md)  
**深入阅读：** [05-DE硬件缩放开发记录.md](../../JYY070-7寸LVDS屏-bringup/05-DE硬件缩放开发记录.md)

---

## 1. 本步目标

UI 设计画布 **1280×800**，JYY070 物理屏 **1024×600**。仅改 DTS 使 `fb0=1280×800`，由 **DE0 VSU** 自动缩放到 LCD，**不改 sunxifb / desk / LVGL 源码**。

**补丁段：** `06-dts-hw-scale`

---

## 2. 数据流

```text
LVGL / desk（1280×800 坐标）
        ↓
fb0 双缓冲 1280×800
        ↓  DE0 VSU（crop → screen_win）
LVDS 物理输出 1024×600
```

内核 `dev_fb.c`：`fb_para.width/height` ← DTS `fb0_*`；`output_width/height` ← `lcd_x/lcd_y`。crop ≠ frame 时 DE 通道自动缩放。

---

## 3. 主要变更

| 文件 | 改动 |
|---|---|
| `device/.../p1_nor_JYY070/linux-5.4/board.dts` | `fb0_width=1280`, `fb0_height=800` |
| `device/.../p1_nor_JYY070/uboot-board.dts` | 同上 |
| `&lcd0` | **不变**，仍为 `lcd_x=1024`, `lcd_y=600` |

**不要依赖** DTS 注释中的 `fb0_scaler_mode_enable`（内核无对应实现）。

---

## 4. 与 sunxifb 统一路径的关系

| 项 | 说明 |
|---|---|
| sunxifb | 仍走 `rotatefbp + split_fb`；`vinfo.xres/yres` 随 fb 变为 1280×800 |
| rot=0 | LCD 页 **直拷贝** 1280×800 到 fb page1；**缩放由 DE 输出阶段完成** |
| 应用 | `desk` log 应变为 `fb 1280x800 -> LVGL 1280x800` |

---

## 5. 编译

**仅 DTS 改动**，需重编内核并 pack，**不必**重编 rootfs：

```bash
./tools/build_p1_nor_JYY070.sh kernel
source build/envsetup.sh && lunch h133-p1_nor_JYY070-tina && pack
# 或一步：./tools/build_p1_nor_JYY070.sh full
```

---

## 6. 验收

### 板端

```bash
fbset -fb /dev/fb0
# geometry 1280 800

cat /sys/class/disp/disp/attr/sys
# 期望：crop[...,1280,800]  frame[...,1024,600]
```

### 串口

```text
[desk] fb 1280x800 -> LVGL 1280x800, sunxifb_rot=0
```

### 目视

- UI **铺满** 1024×600 屏，无大面积黑边
- DE 默认 **铺满拉伸**（宽 0.8、高 0.75），略非等比；与 p1_nor 10.1 寸 1:1 不同

---

## 7. 回退

两处 DTS 改回 `fb0_width=1024`, `fb0_height=600`，重新 `kernel` + `pack`。
