## 3. 实机验收（2026-07-08）

### 3.1 必须出现的 log

| log | 对应步骤 |
|---|---|
| `[desk] fb 1280x800 -> LVGL 1280x800, sunxifb_rot=0` | 04 + **07** |
| `[DISP] dual display HDMI G2D rot0: ...` | 05 |
| `[DISP] dual display enabled: ... (dual_display_rot=0)` | 05 |
| `[desk] started` | 04 |

板端（07）：

```bash
fbset -fb /dev/fb0
cat /sys/class/disp/disp/attr/sys   # crop 1280×800, frame 1024×600
```

### 3.2 必须不出现（旧 fix_lcd）

```text
rotate=0: draw ping-pong, LCD fixed page1
fix_lcd_page
```

实机已确认 **无** 上述字符串。

### 3.3 路径一致性总表

| 层级 | p1_nor rot=3 | JYY070 rot=0（实机） |
|---|---|---|
| sunxifb 框架 | rotatefbp + split_fb | **同框架** |
| LCD 页处理 | 软转 270° | 直拷贝 |
| 内核 dual display | G2D rot270 | **G2D rot0** ✅ |
| desk 启动 log | `sunxifb_rot=3` | **`sunxifb_rot=0`，fb/LVGL 1280×800** ✅ |
