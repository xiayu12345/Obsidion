# 01 — 硬件与原厂驱动

## 1. 硬件

规格书：13.36"，**1200×(RGB)×1920**，MIPI；触控脚：

| 信号 | 说明 |
|---|---|
| TP_SCL / TP_SDA | I2C，典型 1.8V |
| TP_INT | 中断，1.8V |
| LCD_RST | 整芯片复位（屏+触控侧按板级接法） |

板级接到 H133：

| 功能 | 管脚 |
|---|---|
| SCL/SDA | PG8/PG9 → **TWI1**，400k |
| RST | **PG2** |
| INT | **PG3** |
| 7-bit 地址 | **0x68**（移植指南） |

SPI 脚本模组 NC，只走 I2C。

---

## 2. 原厂驱动包

解压 `JD9366TP_JD9366TS_QZ_IIC_01.DE.zip` → `jdchipset/`：

| 文件 | 作用 |
|---|---|
| `jadard_platform.c` | I2C 注册、`compatible=jadard,jdcommon`、GPIO/IRQ |
| `jadard_common.c` | 报点、input、proc |
| `jadard_ic_JD9366TP.c` | JD9366TP/**TS** IC（`JD_PRODUCT_TYPE=2`） |
| `jadard_module.c` | 公共 MCU 流程 |
| `jadard_debug.c` / `jadard_sorting.c` | 调试 / MP（可选） |

合入路径：

```text
kernel/linux-5.4/drivers/input/touchscreen/jdchipset/
```

---

## 3. 相对原厂 zip 的本地改动（尽量少）

| 改动 | 原因 |
|---|---|
| `Makefile` 去掉不存在的 `jadard_hid.o` | zip 无 hid 源码 |
| `ccflags` 开 DEBUG/SORTING；`-D_FORTIFY_SOURCE=0` | 与移植指南一致；5.4 fortify 对 debug 误报 |
| `jadard_debug.c`：`copy_from_user` 用 `min_t` 限长 | 双保险，避免 `__bad_copy_to` |
| `GetID` / `chip_detect` 接受 **0x9032** | 本 CSOT 模组曾读到此 ID（原厂期望 0x9386） |
| `jadard_common.c` 交换分支 **Y 镜像** | 横屏 UI 左上原点：`Y = JD_Y_RES-1-x`（`04-jdchipset-y-mirror.patch`） |

未开：`JD_AUTO_UPGRADE_FW`、`JD_ZERO_FLASH`、`JD_CONFIG_FB`、`CONFIG_JD_DB`。
