# 03 — 改动过程与踩坑

## 1. 为何弃用自写 `jd9366ts.c`

自写能报点，但 backdoor、报告格式、多指/压力与原厂不一致。要求「按原厂」→ 整包 **`jdchipset`**。  
该调试驱动已从内核树删除（源码 / Kconfig / Makefile / bsp 项），勿再合入。

---

## 2. 编译踩坑

| 现象 | 处理 |
|---|---|
| `jadard_hid.o` 无规则 | zip 无 hid；用 `patches/files/Makefile.jdchipset` |
| `mpap_pw` 无成员 | 开 `CONFIG_TOUCHSCREEN_JADARD_SORTING` |
| `__bad_copy_to` | debug `copy_from_user` 限长 + Makefile `-D_FORTIFY_SOURCE=0` |
| `m kernel` 后 openwrt 报 fail | 若已 `compile Kernel successful`，直接 `p` |
| WSL 卡死 | 重启 Ubuntu 后再编 |

---

## 3. IC ID

原厂期望 **0x9386**。本 CSOT 模组曾见 **0x9032**。  
`GetID` / `chip_detect` 兼收二者（`03-jdchipset-ic-id.patch`）。

---

## 4. 坐标：交换 + Y 镜像（定稿）

### 4.1 原厂交换 XY

移植指南：由驱动交换时改 Resolution：

```text
jadard,panel-coords = <0 1200 0 1920>;   →   <0 1920 0 1200>;
```

`jadard_report_points`：`JD_X_RES > JD_Y_RES` 时上报 `ABS_X=芯片Y`，`ABS_Y=芯片X`。

实机交换后四角（点击顺序 左上→右上→左下→右下）曾为：

| 角 | X | Y |
|---|---|---|
| 左上 | ~46 | **~1128** |
| 右上 | ~1875 | **~1126** |
| 左下 | ~18 | **~91** |
| 右下 | ~1876 | **~59** |

→ X 已对，**Y 上下反**。

### 4.2 本板 Y 镜像

在交换分支对 Y：`JD_Y_RES - 1 - 芯片X`（`04-jdchipset-y-mirror.patch`）。  
期望左上 (小,小)、右上 (大,小)、左下 (小,大)、右下 (大,大)。

`tp_rotate` 保持 **0**（无单独翻 Y 的档位；且 getevent 需与桌面一致，故放驱动）。
