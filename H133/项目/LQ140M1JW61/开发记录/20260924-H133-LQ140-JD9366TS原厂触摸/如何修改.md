# 如何修改

只动 **`p1_nor_LQ140M1JW61`**。

```text
device/config/chips/h133/configs/p1_nor_LQ140M1JW61/linux-5.4/board.dts
device/config/chips/h133/configs/p1_nor_LQ140M1JW61/openwrt/bsp_defconfig
kernel/linux-5.4/drivers/input/touchscreen/jdchipset/
openwrt/target/h133/h133-p1_nor_LQ140M1JW61/busybox-init-base-files/etc/setting.ini
```

```bash
source build/envsetup.sh
m kernel -j4
p
```

---

## 1. 量程 / 方向

| 要改什么 | 改哪里 |
|---|---|
| 触发原厂 XY 交换 | DTS `jadard,panel-coords`：竖屏写 `<0 1200 0 1920>`；横屏 UI 对调为 `<0 1920 0 1200>` |
| Y 上下反 | `jadard_common.c` 交换分支的 `JD_Y_RES-1-x`；不要先改 `tp_rotate` |
| UI 旋屏 | `disp_rotate`；本板保持 `3` |
| 桌面再旋触摸 | `tp_rotate`；本板保持 `0` |

---

## 2. 脚位 / 地址

同步 `reg`、`jadard,irq-gpio`、`jadard,rst-gpio`。

---

## 3. IC ID

新 ID：改 `jadard_ic_JD9366TP.h` 的 `JD9366TP_ID`，或在 `GetID`/`chip_detect` 兼收。

---

## 4. 禁止

不要再加回 `jd9366ts.c`、`TOUCHSCREEN_JD9366TS`、`compatible = "jadard,jd9366ts"`。
