# 测试方法

## 1. 驱动

```bash
dmesg | grep -iE 'jdtp|jadard|9366'
ls -l /sys/bus/i2c/devices/   # 期望 *-0068
ls /proc/jadard_touch/ 2>/dev/null
```

---

## 2. 四角 getevent

```bash
getevent /dev/input/event3    # 以实机 event 号为准
```

点击顺序：**左上 → 右上 → 左下 → 右下**。

定稿期望（约 1920×1200，左上原点）：

| 角 | X | Y |
|---|---|---|
| 左上 | 小 | 小 |
| 右上 | 大 | 小 |
| 左下 | 小 | 大 |
| 右下 | 大 | 大 |

`0035`=ABS_MT_POSITION_X，`0036`=ABS_MT_POSITION_Y。

若仅 Y 反：查 `jadard_common.c` 镜像是否合入。若 XY 整体像竖屏：查 `panel-coords` 是否为 `<0 1920 0 1200>`。

---
