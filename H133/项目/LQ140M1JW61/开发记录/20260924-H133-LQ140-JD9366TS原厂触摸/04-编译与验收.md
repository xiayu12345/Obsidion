# 04 — 编译与验收

## 1. 编译

在 SDK 根目录：

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
source build/envsetup.sh
lunch 10   # h133-p1_nor_LQ140M1JW61-tina
# 若补丁未合入：
# bash AI-skiil/板件开发记录/LQ140M1JW61/20260924-H133-LQ140-JD9366TS原厂触摸/patches/apply.sh
m kernel -j4
p
md5sum out/h133_linux_p1_nor_LQ140M1JW61_uart0_nor.img
```

定稿镜像示例：MD5 **`bf248144000094f48bc7fff27b727630`**（仅删未链接的自写驱动时 MD5 可与 Y 镜像定稿相同）。

禁止在 WSL 对内核源码树本地 `make modules` 出半截 `.o` 弄乱 out。

若 `m kernel` 已打印 **`compile Kernel successful` / `uImage is ready`**，而 openwrt 的 `kernel` 目标假失败，直接执行 **`p`**。

## 2. 编译结果自检

```bash
ls out/h133/kernel/build/drivers/input/touchscreen/jdchipset/*.o
test ! -e kernel/linux-5.4/drivers/input/touchscreen/jd9366ts.c
test ! -e out/h133/kernel/build/drivers/input/touchscreen/jd9366ts.o
grep JADARD out/h133/kernel/build/.config
grep JD9366TS out/h133/kernel/build/.config || true
# 期望：
# CONFIG_TOUCHSCREEN_JADARD_CHIPSET=y
# CONFIG_TOUCHSCREEN_JADARD_MODULE=y
# CONFIG_TOUCHSCREEN_JADARD_IC_JD9366TP=y
# 无 TOUCHSCREEN_JD9366TS；无 jd9366ts.c / .o
```

## 3. 实机验收

见 [测试方法.md](./测试方法.md)。最低标准：

1. dmesg 有 JDTP / detect IC successfully  
2. `getevent` 有报点  
3. 四角 getevent：左上(小,小) → 右上(大,小) → 左下(小,大) → 右下(大,大)  
4. 桌面可点（设备名 `jadard_tp`）
