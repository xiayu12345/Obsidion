# 如何改本板 GPADC 双组键

只改 **`p1_nor_XYC_K1` 的 `board.dts` `&gpadc`**。组选逻辑已在驱动里，无 `gpio_pin` 的板不受影响。

对照：[00-总览.md](./00-总览.md)（键表）、[测试方法.md](./测试方法.md)

```text
device/config/chips/h133/configs/p1_nor_XYC_K1/linux-5.4/board.dts
```

`device/product/.../board.dts` 与 chips 是同一 inode，改一处即可。不要改 JYY070 / 京龙 dts。

改完只编 kernel 再 pack：

```bash
export PATH="$PWD/prebuilt/hostbuilt/make4.1/bin:$PATH"
./tools/build_p1_nor_XYC_K1.sh kernel
source build/envsetup.sh && p
```

禁止在 WSL 本地 `make` 出 `.o`。

---

## 1. 电压 / 键码

`keyN_vol` 单位 **mV**，须严格递增，都 **&lt; 1800**。`key_cnt` 等于写了的档数。

| 项 | 含义 |
|---|---|
| `keyN_vol` | 该档按下时芯片脚 mV |
| `keyN_val` | GPIO **低**（界面组）linux 键码 |
| `BkeyN_val` | GPIO **高**（音效组）linux 键码；省略则同 `keyN_val` |
| `gpio_pin` | 组选脚；删掉则退回单组 |

换电阻网：按住一档 `cat /sys/class/gpadc/data`，把 10 个数从小到大写进 `keyN_vol`。不要套京龙表。

## 2. 组反了

现象：按「向上」日志是 `group=1`，或室内/室外是 `group=0`。

两种改法（只做一种）：

1. 对调每一档的 `keyN_val` 与 `BkeyN_val`
2. 把 `gpio_pin` 的 `GPIO_ACTIVE_HIGH` 改成 `GPIO_ACTIVE_LOW`（驱动按 raw `gpio_set_value`，优先用方法 1）

## 3. 不要动的

- 不要把厂商 `sunxi-keyboard.c` 拷进本树
- 不要改其它板的 `&gpadc` 去「顺便」加 `gpio_pin`
- 不要为了按键重开 `&owa_plat`（会再抢 PG18）
