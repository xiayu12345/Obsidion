# 01 — 硬件与组选

## 1. 座子

J9536（原理图 KEY ADC）：

| 脚 | 信号 |
|---|---|
| ① | ADC → SoC **GPADC0** |
| ② | GND |
| ③ | 弱上拉 3.3V（**不是**给按键板供电） |

空闲芯片脚约 **1800 mV**。电压必须写芯片脚 mV（`/sys/class/gpadc/data`），不是座子外侧万用表值。

20 键全进这一根 ADC，不是矩阵，也不是电气接到 DSP。

## 2. 组选脚 PG18

原理图标注 `TWI3-SDA [18]`「按键SDA口」。第 18 页缺失，按丝印和厂商参考认定：

- PG18 作 **GPIO 输出** 切两组
- `gpio 1` = B 组（前十音效）
- `gpio 0` = A 组（后十界面）

Linux 编号：PG18 = `6*32+18` = **210**（调试 sysfs 用过）。

## 3. 克隆残留占脚

从 `p1_nor_JYY070` 克隆带来：

| 占用 | 脚 | 处理 |
|---|---|---|
| `&owa_plat` / `&owa_mach` SPDIF | PG18 | 本板 `disabled` |
| `btlpm` `bt_hostwake` | PG18 | 本板 `disabled` |
| `btlpm` `bt_wake` | PG16 | 原理图 NC；随 btlpm 一起关 |

`owa_pins_*` 节点可留着，只要 owa status=disabled 就不会占脚。

## 4. 厂商参考不能直接用

`H133-AI-Skills/硬件资料/鑫宇宸/sunxi-keyboard.c`：

- 老内核 **LRADC** + `#define CHANNEL_B`
- GPIO 输出翻转切两组；**空闲切、按下停**
- `gpio 0=A`，`gpio 1=B`

H133 按键驱动是 `sunxi_gpadc.c`，不是 LRADC。把那份文件丢进本树会编不过、也绑不上 GPADC 中断。本专题把 CHANNEL_B 的**时序约定**迁到 `sunxi_gpadc`，DTS 无 `gpio_pin` 的板不走 mux。
