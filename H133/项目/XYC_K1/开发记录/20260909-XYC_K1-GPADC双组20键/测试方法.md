# GPADC 双组 20 键 — 测试方法

串口 root。界面不动**不算失败**（LVGL 仍跳过 `sunxi-gpadc`）。只核 ADC、dmesg 键码、hexdump。

---

## 0. 确认 dtb / 驱动

```bash
dmesg | grep -E 'gpadc key mux|sunxi-gpadc'
dtc -I dtb -O dts /sys/firmware/fdt 2>/dev/null \
  | awk '/gpadc@/,/^[[:space:]]*\};/' | head -80
```

应看到 mux gpio、`key_cnt` 为 10。没有 mux：PG18 仍被占，或补丁没进这张镜像。

## 1. 空闲电压

```bash
echo 0 > /sys/class/gpadc/data
cat /sys/class/gpadc/data
```

应接近 **1800**。远低于 1800 且没按键：座子被拉低或接错。

## 2. 按一次看日志

```bash
dmesg -c >/dev/null
# 按一颗再松
dmesg | grep 'gpadc key'
```

期望：

```text
gpadc key down group=0 idx=0 linux=103 mv=5
gpadc key up group=0 linux=103
```

`group=1` 是音效十键。按住应**只有一条** down，直到松手才 up。

## 3. 对照丝印（抽查）

| 丝印 | group | linux |
|---|---|---|
| 向上 | 0 | 103 |
| 向下 | 0 | 108 |
| 确认 | 0 | 28 |
| 返回 | 0 | 1 |
| 室内/室外 | 1 | 59 |
| 变声 | 1 | 60 |
| 混响 | 1 | 68 |

对不上先看 [如何修改.md](./如何修改.md) 极性，不要先改电压。

## 4. hexdump（可选）

```bash
cat /proc/bus/input/devices   # 找 sunxi-gpadc 的 eventN
hexdump -C /dev/input/eventX
```

按下 value=1，松开 0。同一颗键不要连续刷 1。

## 5. 手翻 GPIO（仅调试；驱动已 mux 时不必）

须 `CONFIG_GPIO_SYSFS=y`。PG18 = gpio210：

```bash
echo 210 > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio210/direction
echo 1 > /sys/class/gpio/gpio210/value   # B 组
echo 0 > /sys/class/gpio/gpio210/value   # A 组
```

export 失败：脚仍被 owa/btlpm/驱动占用。驱动 probe 成功后不要再 export。
