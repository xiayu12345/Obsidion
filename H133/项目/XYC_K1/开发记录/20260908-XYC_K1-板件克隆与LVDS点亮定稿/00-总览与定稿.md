# 00 — 总览与定稿

| 项 | 内容 |
|---|---|
| 板型 | `p1_nor_XYC_K1` |
| 定稿日 | 2026-09-08 |
| 状态 | **LCD + HDMI 双显；fb0=1280×800；背光 PB12 GPIO 常高** |

---

## 1. 一句话结论

独立板级接入鑫宇宸 H133-K1 的 LTN141AT 系列 14.1" LVDS。HDMI 全绿的根因是 TCON0 没 vsync（错误 `panel_reset` / USB 抢 PB11·PB12）；背光不亮是 `pwm_pol=1` 把 PT4117 EN 拉低。定稿：**独立 `xyc_k1_lvds`，PB12 当 GPIO 拉 EN，pwm0 保持 okay 但不占脚。**

## 4. 硬件要点

| 项 | 事实 |
|---|---|
| 存储 | SPI NOR（BY25FQ256ES 32MiB） |
| 16P LVDS | **只有 LCD-VCC + 差分**，无背光脚 |
| 40P MIPI CON5 | 另座；**LCD-RST=PB11 只接到 CON5 pin4**，不到 16P |
| PT4117B | EN=PB12，高电平工作；灯条 `VLED+/VLED-` 走 CON5/CN6 |
| CTP | BL3676，TWI1，RST=PG2，INT=PG3 |

只插 16P、灯条没接到 VLED，软件拉 EN 也没灯。
