## 1.2 原厂驱动包

`硬件资料/鑫宇宸/betterlife_ts.7z` → 进树：

```text
kernel/linux-5.4/drivers/input/touchscreen/betterlife_ts/
```

接入点（公共 `touchscreen/`，**default n**，只本板 defconfig 打开）：

| 文件 | 内容 |
|---|---|
| `touchscreen/Kconfig` | `source ".../betterlife_ts/Kconfig"` |
| `touchscreen/Makefile` | `obj-$(CONFIG_TOUCHSCREEN_BETTERLIFE_TS) += betterlife_ts/` |
| `betterlife_ts/Kconfig` | `TOUCHSCREEN_BETTERLIFE_TS`，`compatible = "BTL,betterlife_ts"` |

`device/product/...` 与 `chips/...` 同 inode，`bsp_defconfig` 改一处即可。

## 1.3 本板裁剪（`bl_chip_custom.h`）

| 宏 | 本板 |
|---|---|
| `TS_CHIP` | `BL7XX1` → `BTL_FLASH_ID=0x41` |
| `BTL_CHIP_NAME` | `"BL3676"` |
| `CTP_SLAVE_ADDR` | `0x2c` |
| `BTL_CONFIG_OF` | 开，读 DTS |
| `BTL_CHECK_CHIPID` | 开 |
| `RESET_PIN_WAKEUP` | 开 |
| `BTL_THREADED_IRQ` | 开 |
| `BTL_UPDATE_FIRMWARE_ENABLE` | 开（原厂模板） |
| 充电 / ESD / debugfs / apk / 压力 | **关**（充电检测未接） |

输入设备名必须带 `touch`，`input_symlink.sh` 才链到 `/dev/input/touch`：

```c
static const char *btl_ts_name = "betterlife-touch";
```

本板脚本额外加了 `*betterlife*`，双保险。

## 1.4 DTS 脚序

`of_get_gpio(np, 0)` = RST，`(np, 1)` = INT。必须：

```dts
gpios = <&pio PG 2 GPIO_ACTIVE_HIGH>, <&pio PG 3 GPIO_ACTIVE_HIGH>;
```

对调会复位/中断反了，I2C 可能通但没报点。
