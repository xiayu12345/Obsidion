# 00 — 总览

| 项 | 内容 |
|---|---|
| 板型 | `p1_nor_XYC_K1` |
| 定稿日 | 2026-09-08 |
| 状态 | **BL3676 报点**；四角左上原点，X 右、Y 下 |

---

## 1. 一句话结论

本板 CTP 是 **Betterlife BL3676**，不是克隆源 JYY070 的 GSL1680。走 TWI1（PG8/PG9），地址 **`0x2C`**，chipID **`0x41`**。原生量程 **1280×800**，跟 `fb0` 一致，不用 `ctp_exchange` / `revert` / `tp_rotate`。

---

## 2. 与其它板对照

| 项 | JYY070 | **本板 XYC_K1** |
|---|---|---|
| 芯片 | GSL1680 | **BL3676** |
| 驱动 | `gslX680` | **`betterlife_ts`** |
| 地址 | `0x40` | **`0x2C`** |
| 脚 | TWI1 + PG2/PG3 | **同脚，IC 不同** |
| 量程 | 1024×600 映到 1280×800 | **直接 1280×800** |

---

## 3. 定稿关键量

| 项 | 取值 |
|---|---|
| 节点 | `betterlife_ts@2c` |
| `compatible` | `"BTL,betterlife_ts"` |
| `reg` | `<0x2c>` |
| `gpios` | `[0]=PG2 RST`，`[1]=PG3 INT` |
| `TP_MAX_X/Y` | 1280 / 800 |
| `twi_drv_used` | **0**（DMA 申请不到通道） |
| `bsp_defconfig` | `CONFIG_TOUCHSCREEN_BETTERLIFE_TS=y`；GSL/GT9xx **not set** |
| `setting.ini` | `tp_rotate=0` |
| 输入名 | `betterlife-touch` → `/dev/input/touch` |

---

## 4. 和 LVDS 定稿的关系

触摸是 09-08 跟屏一起做的，当时写进了显示专题。本目录是按其它板「触摸适配」拆出来的检索入口。

| 树的状态 | 怎么做 |
|---|---|
| 已出图（有 `betterlife_ts@2c`） | **不要再打本补丁** |
| 干净树 | 打 LVDS `display-final` 即可，里面已含 CTP |
| 只有 JYY070 克隆、CTP 仍是 `ctp@40` | 打本专题 `01`+`02` |

不要在兄弟板开 `CONFIG_TOUCHSCREEN_BETTERLIFE_TS`。
