## 1. 结论（先看这个）

| 决策 | 取值 / 做法 |
|---|---|
| 接口 / 开屏驱 | 仍是 LVDS `lcd_if=3`，`xyc_k1_lvds`；**不要**改成 `default_lcd` |
| 分辨率 | **1366×768**，`fb0` 同步改 |
| 时钟 / 刷新率 | `dclk=70`；`70e6/(1492×782) ≈ 60 Hz` |
| 时序 | `ht=1492/hbp=88/hspw=48`，`vt=782/vbp=8/vspw=4` |
| `lcd_hbp` | **88 = 40+48**。厂参数把 HBP、HSW 分开写了，全志要 `hbp = 实际HBP + HSPW`，且必须 `hbp > hspw` |
| PWM | **不动**：`used=1`，`freq=50000`，`ch=0`，`pol=0`，`backlight=210` |
| 线序 / 极性 | **不动**：不写 `lcd_lvds_clk_polarity` / `lcd_lvds_io_polarity` |
| LVDS | 仍单路 6bit NS，`lcd_frm=1` |
| UI 旋 | 仍 `disp_rotate=0`，`tp_rotate=2` |
| 触摸量程 | **未改** `TP_MAX_X/Y=1280×800` |

旧 1280×800 参数在 dts 里用注释留底，回退时按注释填回去即可。

## 2. 厂参数怎么落到全志

厂 fex 给的是：

```text
lcd_x=1366  lcd_y=768  lcd_dclk_freq=70
lcd_hbp=40  lcd_ht=1492  lcd_hspw=48
lcd_vbp=8   lcd_vt=782   lcd_vspw=4
lcd_pwm_used=0  lcd_pwm_freq=2000
lcd_lvds_clk_polarity=1  lcd_lvds_io_polarity=15
lcd_driver_name="default_lcd"
```

不能整段覆盖到 K1：

1. **PWM**：K1 是 PB12 PWM0 → PT4117B，必须 `pwm_used=1`、50 kHz。厂值 `pwm_used=0` / 2 kHz 会丢掉调光。
2. **极性**：H133 实际编 `de_lcd_sun50iw10.c`，dts 极性写了也不进 TCON；板上线序已对，保持默认 0。见 09-09 记录第 3 节。
3. **驱动名**：继续 `xyc_k1_lvds`，开屏仍是 LCD-EN(PB10) → LVDS → PWM。`default_lcd` 可能发 MIPI 命令。
4. **水平时序**：全志 `lcd_hbp = HBP + HSPW`。U-Boot 还检查 `lcd_hbp > lcd_hspw`。原值 `40 < 48` 非法，TCON 里会算出负 porch。水平空白 `1366+48+40+38=1492`，所以 `lcd_hbp=88`。
5. **垂直时序**：`vbp=8 > vspw=4` 已合法，按全志格式保留 8。若以后上下黑边再试 `vbp=12`（把 8 也当成 datasheet 纯 VBP）。

对应时序：

| | 水平 | 垂直 |
|---|---|---|
| 有效 | 1366 | 768 |
| sync | 48 | 4 |
| back porch | 40 | 4 |
| front porch | 38 | 6 |
| total | 1492 | 782 |

## 3. `setting.ini`

全屏视频跟新 FB：

| 键 | 旧 | 新 |
|---|---|---|
| `video_screen_w/h` | 1280×800 | **1366×768** |
| `sun_video_screen_w/h` | 1280×800 | **1366×768** |

小窗 `video_small_*` / `sun_video_home_*` / `sun_video_lb_*` 暂沿用 1280×800 布局，未按新分辨率重排。

`setting.ini` 是 conffile。PhoenixSuit 通常不覆盖 UDISK；烧完若画面尺寸仍是旧的，删 `/mnt/UDISK/setting.ini` 再重启，让 `rc.final` 从 `/etc` 再拷。

## 4. 编译与验收

```bash
export LICHEE_JLEVEL=4
./tools/build_p1_nor_XYC_K1.sh kernel
# 改 ini 后重编 base-files，再 target/install；增量 world 可能不更新 squashfs 里的 conffile
./build.sh openwrt_rootfs package/subpackage/allwinner/system/busybox-init-base-files/compile
./build.sh openwrt_rootfs target/install
./build.sh pack
```

输出：`out/h133_linux_p1_nor_XYC_K1_uart0_nor.img`

| 检查 | 期望 |
