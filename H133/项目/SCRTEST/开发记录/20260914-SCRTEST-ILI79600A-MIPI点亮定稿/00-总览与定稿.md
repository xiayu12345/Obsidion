## 1. 一句话结论

独立板接入亿中 13.36" ILI79600A（原生竖屏 1200×1920 MIPI 直连）。  
时序按厂家 porch 换算，**HSA 不能填 2**；dts 时钟填 **110**（驱动 `tcon_div=4` / `dsi_div=6`，实际像素钟约 **165MHz**，约 **59Hz**）。**不改**公共 `disp_al.c`。

---

## 2. 与原厂对照（定稿）

厂家：`PORCHSETTING 2,64,270,2,20,20`（VSA/VBP/VFP/HSA/HBP/HFP），`PCLK 169`，`RESOLUTIONXY 1200,1920`。  
全志：`lcd_hbp/vbp` = 实际 porch + sync。

| 物理项 | 原厂 | **定稿** |
|---|---|---|
| 分辨率 | 1200×1920 | **同** |
| HSA | 2 | **4**（`dsi_hsa=hspw×3-10`，2 会算负卡死） |
| HBP / HFP | 20 / 20 | **同** |
| VSA / VBP / VFP | 2 / 64 / **270** | **同**（VFP 不砍） |
| 像素钟 | 169 | 实际约 **165**（dts 写 **110**） |
| 刷新率 | ≈60Hz | 约 **59Hz** |

| dts 项 | 原厂直换 | **定稿** |
|---|---|---|
| `lcd_hspw/hbp/ht` | 2 / 22 / 1242 | **4 / 24 / 1244** |
| `lcd_vspw/vbp/vt` | 2 / 66 / 2256 | **2 / 66 / 2256** |
| `lcd_dclk_freq` | 169 | **110** |

## 3. 时钟换算（必知）

DSI video：`实际 dclk = dts × dsi_div / tcon_div = dts × 6 / 4 = dts × 1.5`。  
`clk_tbl` 把 DSI 模块钉在 **150MHz**。

| dts | 实际像素钟 | 相对 150 带宽（需 ≥ dclk×0.75） | 现象 |
|---|---|---|---|
| 70 | ≈105 | 够 | 亮，约 25–37Hz |
| **110** | **≈165** | 165×0.75=124 **＜150** | **定稿**，约 59Hz |
| 157 / 168 / 169 | ≈234 / 252 | 不够 | 软件通、屏黑 |

日志认：`clk real: … dclk(…) dsi_rate(150000000)`，不要认 dts 字面。

公式（`Linux_CCU_开发指南.pdf`，标题是 Linux LCD）：

```text
lcd_dclk_freq(MHz) = ht × vt × fps / 1e6
Freq_dsi_clk = (Dclk × 8 × 3 / 4) / 2    # 时钟 lane，DDR
```
