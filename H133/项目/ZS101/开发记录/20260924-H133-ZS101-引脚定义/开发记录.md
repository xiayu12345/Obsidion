# H133 纽曼 ZS101 — 引脚定义

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-24 |
| 板件 | `p1_nor_ZS101`，内核 `linux-5.4/board.dts` |
| 补丁 | [patches/](./patches/) |

原理图按纽曼 ZX30。屏复位和触摸总线与京龙相同，抢脚的地方改掉。U-Boot 设备树这一步不动，背光节点在「屏幕」里和内核一起改。

| 功能 | ZS | 相对京龙 |
|---|---|---|
| USB VBUS | PB10 不控 5V，板上 SY6280 供电 | 京龙 `regulator-fixed` 用 PB10 |
| LCD-RST | PB11，`lcd_gpio_0` | 相同 |
| LCD-PWM | PB12 / PWM0 | 极性在「屏幕」里改成 0 |
| LCD-BL-EN | PG17，高有效 | 京龙把 PG17 当 SDIO WiFi `wlan_regon` |
| 触摸 I2C | TWI1，PG8/PG9 | 相同 |
| 触摸 INT / RST | PG3 / PG2 | 相同 |
| WiFi 32 kHz | PG11 改为 `gpio_in`（I2S1-MCLK） | 京龙 `clk_fanout1` |
| SDIO WiFi / BT / btlpm | 关闭 | 京龙打开，占 PG10/PG11/PG16/PG17/PG18 |
| AC107、TWI2、I2S1 | 关闭 | 京龙打开。ZX30 无这颗麦 |

PG16 = DC_DET，PG18 = SPDIF-OUT，不能再给蓝牙唤醒。

背光芯片 PT4117B，RL7 = 1.1 Ω，100% 高电平约 182 mA，对齐屏 If = 180 mA。`lcd_backlight`、`lcd_pwm_pol`、`lcd_bl_en` 写在屏幕那一步。这组脚位在 16:12 镜像里，15:58 那张还没有。
