## 复制出来的目录

- `device/config/chips/h133/configs/p1_nor_ZS101/`
- `openwrt/target/h133/h133-p1_nor_ZS101/`
- `tools/build_p1_nor_ZS101.sh`

文本里的 `p1_nor_JL_M101`、`h133-p1_nor_JL_M101` 改成 ZS 板号。`Makefile` 的 BOARDNAME 写成 `ZS101 ILI9881C MIPI + GT928 + RTL8733BU`。其它板的 OpenWrt defconfig 补上 `# CONFIG_TARGET_h133_p1_nor_ZS101 is not set`。本板 defconfig 是 `CONFIG_TARGET_h133_p1_nor_ZS101=y`。

`build/pack` 把 ZS 加进竖屏 `bootlogo.bmp` 覆盖列表。开机图从京龙 NOR 复制来的竖图。`openwrt/README.md` 的 lunch 表加上 `h133-p1_nor_ZS101-tina`。

编译入口：

```bash
./tools/build_p1_nor_ZS101.sh full
```

## 并行编译标记

编 rootfs 时，一批 LVGL 包把 `PKG_NAME` 写在 `include package.mk` 之后。`STAMP_BUILT` 若用 `:=` 会在 include 时展开成同一个 `build_dir/target/.built`，`-j` 下后面的包会跳过编译直接安装。`openwrt/openwrt/include/package.mk` 改成递归赋值 `STAMP_BUILT=$(PKG_BUILD_DIR)/.built`，和同文件里的 `STAMP_PREPARED` 一样。
