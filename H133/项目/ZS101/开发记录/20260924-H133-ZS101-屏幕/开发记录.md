# H133 纽曼 ZS101 — 屏幕

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-24 |
| 板件 | `p1_nor_ZS101` |
| 补丁 | [patches/](./patches/) |

屏驱源码本来就在树里，这一步只把 ZS 板接到 `zs101_ili9881c`。

| 项 | 取值 |
|---|---|
| 屏 | 群创 10.1 (T2) + ILI9881C-0D，料号 ZS101NI4042J4H8II-B |
| 驱动名 | `zs101_ili9881c` |
| 内核配置 | `CONFIG_LCD_SUPPORT_ZS101_ILI9881C=y`，关掉 `JL_M101_JD9365DA` |
| 接口 | MIPI 4-lane，800×1280 |
| 像素钟 | `lcd_dclk_freq = 49`（dts ×1.5 ≈ 73.5 MHz，约 60 Hz） |
| 时序 | HSA16 HBP60 HFP60 / VSA4 VBP10 VFP10 → `hbp=76 ht=936 hspw=16` / `vbp=14 vt=1304 vspw=4` |
| 背光 | `lcd_backlight = 255`，PWM0 极性 0，`lcd_bl_en = PG17` |
| U-Boot | 共用 `sun8iw20p1_nor_defconfig` 里已有 `CONFIG_LCD_SUPPORT_ZS101_ILI9881C=y` |

源码：

- `kernel/linux-5.4/drivers/video/fbdev/sunxi/disp2/disp/lcd/zs101_ili9881c.c`
- `brandy/brandy-2.0/u-boot-2018/drivers/video/sunxi/disp2/disp/lcd/zs101_ili9881c.c`

内核 `board.dts` 与 `uboot-board.dts` 的 `lcd0` 一致。背光 255 / 极性 0 / PG17 打进 16:12 镜像。

`LCD_bl_open()` 先 `sunxi_lcd_pwm_enable()`，再 `sunxi_lcd_backlight_enable()`，把 PG17 拉高。关屏时先关使能再关 PWM。内核和 U-Boot 的 panel 都是这一步。15:58 镜像只有 PWM，没有拉 PG17。

桌面方向：`setting.ini` 的 `disp_rotate = 3`。显示驱动把 LVGL 的 90° 和 270° 对调，所以 3 实际转到屏幕上是 90°。

视频层：`libtmedia` 里 ZS 的 `VIDEO_WB_MIRROR_ROTATE=90`。京龙 NOR / HXR NOR 仍是 270。`video_rotate` 仍是 2。
