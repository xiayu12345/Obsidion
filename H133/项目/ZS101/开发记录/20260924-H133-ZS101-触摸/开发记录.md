# H133 纽曼 ZS101 — 触摸

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-24 |
| 板件 | `p1_nor_ZS101` |
| 补丁 | [patches/](./patches/) |

汇顶 GT928，模组 FXT101041，配置 20260827。配置表 `CTP_CFG_GROUP2` 本来就在 `gt9xx.h`，这一步只改板级节点和内核开关。

| 项 | ZS | 京龙 |
|---|---|---|
| 驱动 | `gt9xxnew`，`CONFIG_TOUCHSCREEN_GT9XXNEW_TS` | `gslX680new` + `gsl3670.bin` |
| 节点 | `ctp@5d`，`compatible = "allwinner,goodix"` | `ctp@40`，`allwinner,gslX680` |
| 名字 | `ctp_name = "gt928_fxt101041"` → `CTP_CFG_GROUP2` | `gsl3670` |
| 地址 | TWI1，I2C `0x5d` | TWI1，I2C `0x40` |
| 量程 | 1280×800（配置里已经是横向量程） | 固件竖屏，驱动里 `exchange_x_y = 1` |
| 翻转 | `revert_y = 1`，不交换 X/Y | 不翻转 Y，交换 X/Y |
| 软件旋转 | `tp_rotate = 0` | `tp_rotate = 0` |

脚位与京龙相同：INT PG3，RST PG2。GT928 不把 `gsl3670.bin` 编进内核，`CONFIG_EXTRA_FIRMWARE` 关掉。

配置表在 `kernel/linux-5.4/drivers/input/touchscreen/gt9xxnew/gt9xx.h` 的 `CTP_CFG_GROUP2`。X = `0x0500`（1280），Y = `0x0320`（800）。
