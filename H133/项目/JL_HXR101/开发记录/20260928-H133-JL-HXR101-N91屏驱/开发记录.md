## 1. 结论

| 决策 | 取值 |
|---|---|
| 用哪份 init | 厂商 `N91ILI9881最新版本.txt`，不用 09-18 的群创 ILI9881C-0D 拷贝 |
| 驱动名 | `jl_hxr_n91`。`jl_hxr_ili9881c` 源码还在，HXR 板不再选它 |
| 分辨率 | 规格书 800×1280，MIPI 4-lane，IC ILI9881C-0H |
| porch | HSA20 HBP20 HFP40 / VSA4 VBP12 VFP30 |
| Allwinner | `hspw=20 hbp=40 ht=880` / `vspw=4 vbp=16 vt=1326` |
| `lcd_dclk_freq` | **47**。dts×1.5≈70.5MHz，对应 N91 `PLL_CLOCK=421` 换算的约 70.2MHz、60Hz |
| 发码 | 192 条 Generic 与原文一致，停在 `0x35`。其后 DCS `0x11` 等 120ms、`0x29` 等 20ms |
| 复位 / 背光 | PB11、PWM0/PB12，50kHz，`lcd_pwm_pol=1`。试机确认 `lcd_backlight=15`（低有效，导通约 94%） |
| JL-M101 | 仍是 `jl_m101_jd9365da`，`dclk=70`，`lcd_backlight=200` |

规格书没有 porch 表。porch 和 `PLL_CLOCK=421` 只在初始化文件开头。`421` 是联发科 lane 时钟，不是全志 `lcd_dclk_freq`。`421×4/24≈70.2MHz`。全志 DSI 实际像素钟约为设备树值的 1.5 倍，所以填 47，不要填 70（会跑到约 105MHz）。

原文没有 Sleep Out / Display On。把 `0x11`/`0x29` 塞进 Generic 表会变成错误包型；点亮的这一版在表后用 DCS 0 参数写出去。

`新建文件夹/` 与 `HXR10106B28/` 两份规格书和 txt 内容相同，以 `HXR10106B28/` 为准。

## 2. 试亮

同一套 MIPI、复位和 PWM，先挂在 `p1_nor_JL_M101` 上烧录确认出图，再把 dts 和配置改到两块 HXR 板。M101 的 lcd 已退回 JD9365DA。

HXR 的 NOR / eMMC 设备树已经是 `jl_hxr_n91`。这两块板的镜像还没按新屏驱重编。要出 HXR 镜像：

```bash
./tools/build_p1_nor_JL_HXR101.sh kernel
./tools/build_p1_emmc_JL_HXR101.sh kernel
```

U-Boot 日志应出现 `jl_hxr_n91: panel_init`。
