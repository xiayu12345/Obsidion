## 2. 为什么新建板件，不改 JL-M101

用户要求对照 `H133-AIKTV`，**包括新建板件**。

AIKTV 已经点亮同一块 HXR10106B-28：整板复制 `p1_nor_JL_M101` → `p1_nor_JL_HXR101`，原 JL 板仍留 JD9365DA。JL-M101 和 HXR 是两块屏（IC 分别是 JD9365DA / ILI9881C），烧错 lunch 会花屏。

09-17 把 `p1_*_JL_M101` 的 `lcd_driver_name` 改成新屏，等于占掉旧京龙工程。这次按 AIKTV 拆开。

---

## 3. 为什么 init 用 zs101，不用 N91

规格书：HXR10106B-28 LB，ILI9881C-0H，800×1280，MIPI 4-lane，40pin，AA 135.36×216.576。厂商码在 `AI-skiil/硬件资料/四川京龙/HXR10106B28/N91ILI9881最新版本.txt`（page3/4/1/0，无 `0x11`/`0x29`）。

AIKTV 没有用这份 N91。同 IC 家族的 `zs101_ili9881c` 已经在本 SDK 点亮过，init 表直接拷过来，kernel / U-Boot 各一份。U-Boot 侧类型是 `__lcd_panel_t` / `tick_printf`。

09-17 用 N91 + 自补 `0x11`/`0x29`，再按厂商 porch 填 `dclk=70`。全志 dts 的 `lcd_dclk_freq` 会再 ×1.5，70 实际约 105MHz，会超频。AIKTV 注释写明：勿填厂家 73（会跑成 ~110MHz / 90Hz）。

| 来源 | H / V porch | Allwinner | dclk |
|---|---|---|---|
| 厂商 N91（09-17 已弃） | HSA20 HBP20 HFP40 / VSA4 VBP12 VFP30 | `hbp=40 ht=880 hspw=20` / `vbp=16 vt=1326 vspw=4` | 70（过快） |
| ZS101 / AIKTV（本次） | HSA16 HBP60 HFP60 / VSA4 VBP10 VFP10 | `hbp=76 ht=936 hspw=16` / `vbp=14 vt=1304 vspw=4` | **49** |

换算：`hspw=HSA`，`hbp=HSA+HBP`，`ht=x+HSA+HBP+HFP`；V 同理。`vt=1280+4+10+10=1304`。

## 4. 板级 lcd0（kernel / U-Boot 同数）

`board.dts` 是 `linux-5.4/board.dts` 的符号链接，只改后者。

```dts
/* 京龙 HXR10106B-28 / ILI9881C-0H；init 见 jl_hxr_ili9881c.c */
lcd_driver_name     = "jl_hxr_ili9881c";
lcd_x               = <800>;
lcd_y               = <1280>;
/* dts×1.5=实际像素钟；49→约73.5MHz≈60Hz，勿填厂家 73 */
lcd_dclk_freq       = <49>;
lcd_pwm_ch          = <0>;          /* PB12 / PWM0 */
lcd_hbp             = <76>;
lcd_ht              = <936>;
lcd_hspw            = <16>;
lcd_vbp             = <14>;
lcd_vt              = <1304>;
lcd_vspw            = <4>;
lcd_dsi_lane        = <4>;
lcd_gpio_0          = <&pio PB 11 GPIO_ACTIVE_HIGH>; /* RST */
```

本板 `bsp_defconfig` / `config-5.4`：关 `JL_M101`，开 `JL_HXR`。触摸固件路径改到新 OpenWrt target：

```text
CONFIG_EXTRA_FIRMWARE_DIR="../../openwrt/target/h133/h133-p1_{emmc,nor}_JL_HXR101/busybox-init-base-files/lib/firmware"
```

`device/product` 是 `device/config/chips/h133` 的符号链接，不必再拷一份。

## 5. NOR boot1

NOR U-Boot 上限 **933888** 字节。`sun8iw20p1_nor_defconfig` 里 Kconfig `default y` 的屏必须关掉。本次：

```text
CONFIG_LCD_SUPPORT_JL_M101_JD9365DA=y
CONFIG_LCD_SUPPORT_JL_HXR_ILI9881C=y
CONFIG_LCD_SUPPORT_XYC_K1_LVDS=y
# CONFIG_LCD_SUPPORT_ZS101_ILI9881C is not set
```

eMMC 走 `sun8iw20p1_defconfig`，可以同时留 JL / ZS101 / HXR。本次实测 `u-boot-spinor.fex` **507904**。

U-Boot 按 defconfig md5 会跳过刷新；编译脚本会删 `.config` / `u-boot.cfg`，并清 `out/h133/kernel/build/.config`，避免残留 09-17 的 `HXR10106B28`。

```bash
./tools/build_p1_emmc_JL_HXR101.sh kernel
# 再 p，或 ./tools/build_p1_emmc_JL_HXR101.sh full
# 产物：out/h133_linux_p1_emmc_JL_HXR101_uart0.img

# 产物：out/h133_linux_p1_nor_JL_HXR101_uart0_nor.img
```

脚本会检查 U-Boot `.config` 里 `CONFIG_LCD_SUPPORT_JL_HXR_ILI9881C=y`。

2026-09-18 第一次 pack：**没有重编 OpenWrt**，rootfs 从旁边 JL 板拷过来（eMMC←`p1_emmc_JL_M101`，NOR←`p1_nor_JL_M101`）。要全新 rootfs 再跑 `full`。`m -j$(nproc)` 在本机容易把 host cmake 打挂，rootfs 用 `-j4`，见 [20260915 eMMC 记录](../20260915-H133-JL-M101-eMMC/开发记录.md)。

`build/pack` 对 HXR 两块新板也覆盖竖屏 `bootlogo.bmp`（100×432），不要留 common 312×76 横图。
