# 00 — 总览与定稿

## 0.1 一句话结论

从 **`p1_nor_8733` 克隆独立板级 `p1_nor_JL_M101`**，只换京龙 JD9365DA MIPI panel（独立驱动 + 厂商 init）；UI/WiFi/视频旋转对齐 8733。  
**2026-07-22 实机已完整出图**（内核灌码 + PWM0 背光 + 转接板 RESET 电平正确）。

禁止改共享的 `p1_nor` / `p1_nor_8733` / `p1_nor_JYY070` DTS 迁就本屏。

## 0.4 设计原则（必须遵守）

1. **板件隔绝**：只改 `configs/p1_nor_JL_M101/`、`h133-p1_nor_JL_M101/`、本 panel 源。  
2. **一屏一驱动**：`jl_m101_jd9365da.c`，不改 `default_panel.c`。  
3. **拆软链**：本板 `linux-5.4/` 为实目录，避免动 8733。  
4. **App 先不动**：复用 8733 竖屏（`disp_rotate=3`、`VIDEO_WB=90`）。  
5. **最小公共改动**：仅 panel 注册 + 兄弟板 config `not set` + libtmedia 本 target。  
6. **PB12 是 PWM，不是 bl_en GPIO**。
