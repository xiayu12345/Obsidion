# HDMI 同显 DE1 linebuf：超宽 YUV「1:1」黑边

日期：2026-07-30  
触发板型：`p1_nor_LQ140M1JW61`（横屏，LCD / HDMI 均为 1920×1080，`chn_cfg_mode=1`，`dual_display_rot=0`）  
修复文件：`kernel/linux-5.4/drivers/video/fbdev/sunxi/disp2/disp/de/lowlevel_v2x/de_rtmx.c`  
补丁：[patches/01-de-rtmx-coarse-linebuf.patch](./patches/01-de-rtmx-coarse-linebuf.patch)

---

## 1. 现象

- LCD（MIPI）正常满屏  
- HDMI 同显右边约 1/3、底部有黑边，内容像只显示左上一块  
- 旋转板（如 JL，`dual_display_rot≠0`，中间帧尺寸 ≠ HDMI）HDMI 往往能铺满  
- 曾用「WB 缩到 fb0 再 DE1 拉满」可绕过，属 workaround，非根因  

路径：`DE0(LCD) → capture WB(NV21) →（可选 G2D 旋转）→ DE1 HDMI layer`

---

## 2. 根因

H133（sun8iw20）DE 能力在 `de_feat.c` 写死：

| 屏 | scale_line_buffer |
|----|-------------------|
| DE0（LCD） | **2048** |
| DE1（HDMI） | **1024** |

同显缓冲是 **YUV（NV21）**。`de_hal.c` 里 **YUV 即使源宽=屏宽也会开 VSU**（色度处理）；只有 RGB 且尺寸相等才关 scaler。

`de_rtmx_get_coarse_fac()` 原逻辑：

```c
/* 源 == 屏 → 直接 return，后面的 linebuf 检查不跑 */
if ((ovl_w == vsu_outw) && (ovl_h == vsu_outh))
	return ...;
linebuf = de_feat_get_scale_linebuf(sel);
/* 仅非 1:1 时才可能把取数压到 linebuf */
```

因此 LQ 上 HDMI：**1920→1920 的 YUV「假 1:1」** 把整幅 1920 塞进只有 **1024** linebuf 的 DE1 VSU → 花屏 / 黑边。

旋转或「源≠屏」会走 coarse，把取数压到 ≤1024 再拉满，所以看起来「正常」。

**不是**「1:1 想法错了」，而是驱动在超宽时少做了 linebuf 保护。

---

## 3. 正确逻辑（已落地）

仅当同时满足才 early return：

1. 源宽高 == 屏宽高  
2. **且** 源宽 ≤ 该屏 `scale_line_buffer`

否则（例如 DE1 上 1920 > 1024）**即使名义 1:1 也走 coarse**：先压到 linebuf，再由 VSU 拉满屏幕。

`dev_disp.c` **无需**为此改同显架构；勿再靠「WB 裁切 / 强制缩到 fb0」绕路。

---

## 4. 对其它板的影响

| 路径 | 影响 |
|------|------|
| DE0 LCD，宽 ≤ 2048 | 与改前相同（1920 仍 ≤ 2048） |
| DE1 已「源≠屏」缩放（如 JYY 小 LCD→1080p HDMI） | 本就会走 coarse，行为不变 |
| DE1 1080p YUV 真·源=屏 | **会触发本修复**（正是要修的场景） |

补丁在公共 `lowlevel_v2x`，所有 H133 同套 DE 的板都会编进内核。

---

## 5. 排查中走过的弯路（勿再采用）

| 做法 | 结果 |
|------|------|
| 改 `fb0=1920` 对齐 LCD | 未解决 DE1 linebuf；UI 仍 1280 时只会左上有图 |
| HDMI layer crop fb0 再拉满 | 裁的是满幅缩放图的左上 → 放大截断 |
| WB 硬件缩到 1280 再 DE1 拉满 | 能满屏，但是绕路 |
| 改 `dev_disp` 大量同显旁路 | 与根因无关，已撤回 |

## 6. 应用补丁

在 SDK 根目录：

```bash
patch -p1 < H133-AI-Skills/开发记录/系统BUG修复/20260730-HDMI同显-DE1-linebuf超宽1比1黑边/patches/01-de-rtmx-coarse-linebuf.patch
./tools/build_p1_nor_LQ140M1JW61.sh kernel
# 再 p 打包
```

验收（LQ140）：

- HDMI 满屏、无大块右/底黑边  
- LCD 正常  
- 串口 dual display 仍为 LCD 分辨率 WB（不必再出现 `WB scale ... fb0` 类绕路日志）
