# 板件新建指南（通用）

从实机定稿经验提炼的**新板创建流程**，不绑某一块具体屏的参数。具体板的定稿仍放在对应板型目录。

| 指南 | 适用 | 范本板 |
|------|------|--------|
| [20260728-如何创建新MIPI板件](./20260728-如何创建新MIPI板件/README.md) | 新开 **MIPI/DSI** LCD 板级 | `p1_nor_JL_M101` ← `p1_nor_8733` |
| [20260728-如何创建新LVDS板件](./20260728-如何创建新LVDS板件/README.md) | 新开 **LVDS** LCD 板级 | `p1_nor_JYY070` |

**铁律（两份指南共用）：**

1. **板件隔绝**：只改本板 `configs/<BOARD>/`、`h133-<BOARD>/`、本 panel 源；禁止改共享 `p1_nor` / 兄弟板 DTS 迁就新屏  
2. **一屏一驱动**：独立 `xxx_panel.c`，不改 `default_panel.c`  
3. **拆软链**：本板 `linux-5.4/` 必须是实目录  
4. **WiFi 选型跟基线**：要 8733BU → 从 `p1_nor_8733` 克隆；勿顺带开 AIC8800  
5. **大改先通报**：新板名、分辨率、旋转、是否 DE 缩放，写进本板 `board-profile-*.md`  
6. **旋转只改旋钮**：HDMI / UI / 视频三路独立，见 [显示旋转](../显示旋转/README.md)

现有板型索引：[板件与项目对照](../板件与项目对照.md)
