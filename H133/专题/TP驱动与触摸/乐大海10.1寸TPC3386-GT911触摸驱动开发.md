### 2.1 模组参数

| 项目 | 值 |
|------|-----|
| 模组型号 | **TPC3386** |
| 触摸 IC | **GT911**（非 GT9110） |
| 触点数 | **5** |
| TP 逻辑分辨率（cfg） | **1280×800** |
| LCD 物理分辨率 | **800×1280** 竖屏 |
| I2C 地址（实测） | **0x5d** |

### 2.2 主板 JP13（TP-H10，MX1.25-6P）

| JP13 Pin | 信号 | SoC |
|----------|------|-----|
| 1 | CTP-RST | **PG2** |
| 2 | CTP-INT | **PG3** |
| 3 | CTP-SDA | **PG9**（TWI1） |
| 4 | CTP-SCK | **PG8**（TWI1） |
| 5 | GND | |
| 6 | VCC-CTP 3.3V | |

### 2.3 乐大海 TPC3386 FPC（6P）

| FPC Pin | 信号 |
|---------|------|
| 1 | GND |
| 2 | SDA |
| 3 | SCL |
| 4 | INT |
| 5 | RST |
| 6 | VCC 3.3V |

### 2.4 转接线（不能 1:1 对插）

JP13 与乐大海 FPC **引脚顺序不同**，仅 VCC/GND 碰巧同侧，**必须按信号名转接**：

```text
JP13-1 RST  → 乐大海 TP-5 RST
JP13-2 INT  → 乐大海 TP-4 INT
JP13-3 SDA  → 乐大海 TP-2 SDA
JP13-4 SCL  → 乐大海 TP-3 SCL
JP13-5 GND  → 乐大海 TP-1 GND
JP13-6 VCC  → 乐大海 TP-6 VCC
```

> **教训**：1:1 直插会导致 SDA/SCL/RST/INT 全错；首片 TP 因线序错误可能导致芯片损坏，更换模组并改正线序后 I2C 恢复正常。

### 2.5 屏厂 Config 解析

| 寄存器 | cfg 字节 | 值 | 含义 |
|--------|----------|-----|------|
| 0x8047 | [0] | `0x5D` | 配置版本 / I2C 地址 **0x5d** |
| 0x8048~9 | [1][2] | `0x00, 0x05` | X max = **1280** |
| 0x804A~B | [3][4] | `0x20, 0x03` | Y max = **800** |
| 0x804C | [5] | `0x05` | **5 点**（GT911，勿改 0x0A） |
| 0x804D | [6] | `0x3D` | 模块开关（上升沿中断） |

### 阶段 2：I2C 不通（硬件层）

**现象：**

```text
sunxi:twi@2502400.twi[ERR]: Timeout when sending 9th SCL clk
gt9xxnew_ts: probe of 1-005d failed with error -1
lv_tp_test: evdev_touch_init failed
```

`i2cdetect -y 1`：**0x08~0x77 每个地址均超时**，表格全 `--`。

**排查过程：**

| 步骤 | 操作 | 结论 |
|------|------|------|
| 万用表 | TP Pin1=0V(GND)，Pin6≈3.3V，Pin2/3/5≈3.3V，Pin4(INT)=0V | 供电正常 |
| 示波器 | 跑 `i2cdetect` 时 SCL/SDA 在 JP13 与 TP 侧均有方波且一致 | 线已打通 |
| 示波器 | 第 9 个 SCL 时 SDA 无 ACK 拉低 | 无从机应答 |
| 分析 | 非地址/DTS 问题；疑线序错或芯片损坏 | — |
| 换片 + 改正转接线 | 按 §2.4 转接 | **I2C 恢复** |

**驱动成功日志：**

```text
input: gt9xxnew_ts as /devices/virtual/input/input3
ctp-irq-request: gpio=195 virq=225
evdev touch opened: /dev/input/event3
```

### 阶段 3：坐标 Y 轴被压缩

**现象：** 四角测试时，上角红点位置正确，下角红点抬到屏幕中部（约 Y≈493，应为 ≈799）。

**根因：** `lv_drv_conf.h` 仍保留 GSL 时代配置：

```c
#define EVDEV_CALIBRATE  1
#define EVDEV_HOR_MAX    800   // 误把 raw 当 800×1280
#define EVDEV_VER_MAX    1280
```

GT911 实际 raw 为 **1280×800**，`CALIBRATE` 将 Y 按 `×800/1280≈0.625` 压缩，与实测 `493/799≈0.62` 吻合。

**修复：** `EVDEV_CALIBRATE = 0`，`EVDEV_SWAP_AXES = 0`（与拓步 GT911 最终方案一致）。

**涉及文件：**

- `lv_tp_test/src/lv_drv_conf.h`
- `lv_projector/src/lv_drv_conf.h`
- `aiktv_desktop/src/lv_drv_conf.h`

**重编 rootfs 后镜像 MD5：** `29dcf54b229f59441e2e16a96771d132`

## 5. 软件实现详情

### 5.1 `bsp_defconfig`

```text
CONFIG_TOUCHSCREEN_GT9XXNEW_TS=y
# CONFIG_TOUCHSCREEN_GSLX680NEW is not set
# CONFIG_EXTRA_FIRMWARE is not set
```

### 5.2 `board.dts`（`&twi1`）

```dts
ctp@5d {
    compatible = "allwinner,goodix";
    device_type = "ctp";
    reg = <0x5d>;
    status = "okay";
    ctp_name = "gt911_tpc3386";
    ctp_twi_id = <0x1>;
    ctp_twi_addr = <0x5d>;
    ctp_screen_max_x = <0x320>;   /* 800，用于 revert 计算 */
    ctp_screen_max_y = <0x500>;  /* 1280 */
    ctp_revert_x_flag = <0x0>;
    ctp_revert_y_flag = <0x0>;
    ctp_exchange_x_y_flag = <0x0>;
    ctp_int_port = <&pio PG 3 GPIO_ACTIVE_HIGH>;
    ctp_wakeup = <&pio PG 2 GPIO_ACTIVE_HIGH>;
};
```

### 5.3 驱动 Config

- 屏厂 cfg **原样**写入 `gt9xx.h` 的 **`CTP_CFG_GROUP1`**（替换原 GT9110 配置）；
- `gt9xx.c`：`ctp_name == "gt911_tpc3386"` → `sensor_id = 0` → 使用 GROUP1。

### 5.4 开机启动

`openwrt/target/h133/h133-p1_nor/busybox-init-base-files/etc/init.d/rc.final`：

```sh
lv_projector 3 &
/usr/bin/lv_daemon.sh &
```

参数 `3` = `sunxifb_out_rotate=270°`，MIPI 软旋转；LVGL 逻辑 **1280×800**。触摸调试可手动 `lv_tp_test 3` 或 `tp_debug.sh start-test`。

## 6. 坐标映射（核心）

### 6.1 数据流

```text
GT911 芯片（cfg 1280×800）
    ↓ gt9xxnew_ts（DTS revert/swap 全 0）
/dev/input/event3   raw: X 0~1279, Y 0~799
    ↓ evdev（EVDEV_CALIBRATE=0，1:1）
LVGL 1280×800（lv_tp_test / lv_projector）
    ↓ sunxifb rot=3（仅转显示，不转触摸）
MIPI 800×1280 物理屏 + HDMI 1280×800 逻辑
```

### 6.2 各层分辨率

| 层级 | 宽×高 | 说明 |
|------|-------|------|
| GT911 / getevent | **1280×800** | 与屏厂 cfg 一致 |
| LVGL / canvas | **1280×800** | `sunxifb_rot=3` 时由 fb 800×1280 换算 |
| fb 物理（MIPI） | 800×1280 | `sunxifb_get_sizes` |
| DTS screen_max | 800×1280 | 面板物理像素，供内核 revert 用 |

### 6.3 关键配置（定稿）

**内核 `board.dts`：**

```dts
ctp_revert_x_flag = <0x0>;
ctp_revert_y_flag = <0x0>;
ctp_exchange_x_y_flag = <0x0>;
```

**应用 `lv_drv_conf.h`：**

```c
#define EVDEV_SWAP_AXES     0
#define EVDEV_CALIBRATE     0   /* GT911 已是 1280×800，勿用 GSL 的 CALIBRATE */
```

**`lv_tp_test/main.c`：**

```c
disp_drv.rotated = LV_DISP_ROT_NONE;  /* 旋转仅由 sunxifb 负责 */
```

### 6.4 四角验收

| 角 | 期望坐标 | 红点位置 |
|----|---------|---------|
| 左上 | (0, 0) | 贴左上角 |
| 右上 | (1279, 0) | 贴右上角 |
| 左下 | (0, 799) | 贴左下角 |
| 右下 | (1279, 799) | 贴右下角 |

### 6.5 方向仍不对时

| 现象 | 改一处即可 |
|------|-----------|
| X/Y 对调 | `ctp_exchange_x_y_flag=1`（kernel）**或** `EVDEV_SWAP_AXES=1` |
| 左右反 | `ctp_revert_x_flag=1` |
| 上下反 | `ctp_revert_y_flag=1` |
| 画面方向 | `lv_tp_test 1` 或 `3`（只改 sunxifb，不动触摸） |

> **禁止** 同时在 kernel 与应用层做 swap，也禁止 `disp_drv.rotated` 与 sunxifb 双重旋转。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `i2cdetect` 每地址超时 | 线序错/芯片坏/未供电 | §2.4 转接表；测 3.3V；换 TP 模组 |
| SCL/SDA 有方波但无 ACK | 线序错或芯片损坏 | 改正转接线；换片 |
| probe 失败 `0x5d` | 同上或地址不对 | 扫 `0x14`；改 DTS `reg` |
| 上角对、下角抬高 ~62% | `EVDEV_CALIBRATE=1`（GSL 遗留） | 改 `CALIBRATE=0`，重编 rootfs |
| 红点只在中间一块 | 双重旋转或 CALIBRATE 错误 | `disp_drv.rotated=NONE` + `CALIBRATE=0` |
| `evdev_touch_init failed` | 驱动未 probe | 先解决 I2C |
| AC107 TWI2 报错 | 乐大海板无话筒 | 可忽略 |
| `ctp_power is fail` | JP13 直供 3.3V | 正常，非故障 |
