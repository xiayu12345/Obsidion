# GPADC 电阻按键

京龙板 KEY 走 H133 **GPADC0** 电阻分压，内核 `sunxi-gpadc` 出 evdev。跨板可复用通道/阈值算法；电压表按板件 DTS。

| 文档 | 说明 |
|------|------|
| [20260831-三键识别/](./20260831-三键识别/) | **0Ω / 3.3k / 5.1k / 6.8k / 15k** 五档；两块板电压不同 |
| └ [开发记录.md](./20260831-三键识别/开发记录.md) | 硬件约定、两套电压定稿、当前 DTS 为板乙 |
| └ [测试方法.md](./20260831-三键识别/测试方法.md) | 读 ADC、查 event 节点、hexdump 键码、长按、失败判定 |
| └ [如何修改.md](./20260831-三键识别/如何修改.md) | 改 dts 电压表 / 键码 / 阈值 |
| └ [gpadc-5btn-0R-3.3k-5.1k-6.8k-15k.patch](./20260831-三键识别/gpadc-5btn-0R-3.3k-5.1k-6.8k-15k.patch) | 相对全志默认 `&gpadc`，电压按 **板乙** |

## 产品一句话

J9536 外侧接电阻；芯片脚电压由 RA20 51k + RA22 6.8k 决定。功能五档：播放/暂停、上一曲、下一曲、音量减、音量加。换板先按 [测试方法.md](./20260831-三键识别/测试方法.md) 读电压，不要混用另一块板的 mV。
