---

## 1. 要解决什么

京龙 KEY 走 H133 **GPADC0** 电阻分压，内核 `sunxi-gpadc` 出 evdev。座子外侧五档电阻对应播放/暂停、上一曲、下一曲、音量减、音量加。全志默认电压表对不上这块板，要按芯片脚实测 mV 重写 `&gpadc`。

---

## 2. 硬件约定

原理图 USB/HDMI 页 **KEY ADC**，SoC 球 **C11 = GPADC0**：

```
AVCC 1.8V -- RA20 51k -- GPADC0 -- RA22 6.8k -- J9536 座子信号脚
                 |
               CA1 1nF -- GND
```

`keyN_vol` 必须写 **芯片脚 mV**（`cat /sys/class/gpadc/data`），不是座子外侧万用表值。两块板电阻档位相同，ADC 不同，**不能共用一张电压表**。

`Vchip = 1.8 × (6.8k + R) / (51k + 6.8k + R)`（RA22 串在座子外侧时）

电阻 → 功能（两块板一样）：

| 电阻 | 功能 | `keyN_val` | hex |
|------|------|------------|-----|
| 0Ω | 播放/暂停 | 164 | `a4` |
| 3.3k | 上一曲 | 165 | `a5` |
| 5.1k | 下一曲 | 163 | `a3` |
| 6.8k | 音量减 | 114 | `72` |
| 15k | 音量加 | 115 | `73` |

### 板甲（RA22 未串进采样，电压偏低）

`cat /sys/class/gpadc/data`：3 / 106 / 161 / 208 / 404 mV。hexdump 五档已通过。

| 电阻 | ADC mV | `keyN_vol` |
|------|--------|------------|
| 0Ω | 3 | 3 |
| 3.3k | 106 | 106 |
| 5.1k | 161 | 161 |
| 6.8k | 208 | 208 |
| 15k | 404 | 404 |

### 板乙（经 RA22，与原理图一致；当前 DTS）

`cat /sys/class/gpadc/data`：207 / 291 / 335 / 373 / 533 mV。hexdump 五档已通过。

| 电阻 | ADC mV | `keyN_vol` |
|------|--------|------------|
| 0Ω | 207 | 207 |
| 3.3k | 291 | 291 |
| 5.1k | 335 | 335 |
| 6.8k | 373 | 373 |
| 15k | 533 | 533 |

`J9538` 是 MIC，不是 KEY。换板必须重新测电压，不要拿另一块的 mV 硬套。步骤见 [测试方法.md](./测试方法.md)。

## 3. 驱动行为

驱动：`kernel/linux-5.4/drivers/input/sensor/sunxi_gpadc.c`

- `keyN_vol` 单位 **mV**，须从小到大
- 电压 **&lt; 1.7V** 视为按下
- 窗口取相邻 `key_vol` 中点
- `EV_REP`：长按 `value=1` → `2` → 松开 `0`

## 5. 实测结论

读电压、hexdump、长按、失败判定的**完整步骤**在 [测试方法.md](./测试方法.md)，不要只看本节。

- 板甲五档 ADC：3 / 106 / 161 / 208 / 404；板乙：207 / 291 / 335 / 373 / 533；空闲 ~1800
- 电阻档位相同，两块板 hex 相同：`a4` / `a5` / `a3` / `72` / `73`（164 / 165 / 163 / 114 / 115）
- 须刷含对应板 `keyN_vol` 的 dtb 后再验；界面不动是正常的（LVGL 未接）

## 7. 踩坑

- 两块板电阻档位相同，ADC 差一截：板甲 3/106/161/208/404，板乙 207/291/335/373/533，表不能混用
- `key0_vol` 在经 RA22 的板上不能写 0：座子短路芯片约 0.21V
- 板乙上 5.1k 与 6.8k 只差约 38mV，接触不稳会串下一曲/音量减
