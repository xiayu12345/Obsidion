# sst_test 操作方法

串口或 adb，root。固件须已合 [../patches/](../patches/)（含 `libkey-demo`）。PhoenixSuit 选 **分区擦除升级**，禁止全盘。

```bash
sst_test -w snum '你的SN'
sst_test -r snum
```

成功：

```
write data to secure storage done
[api] snum = 你的SN
[sst] snum = 你的SN
```

- 有空格必须加引号；本版最长 **512 字节**。
- 第一次写可能有 `Map magic is bad` / `map is empty` / `private bare key not supported`，正常。
- **写完已落盘，不用 reboot。** 立刻 `-r` 能读到。
- 失败 `Read snum fail`：没写过或被全盘擦除清了。改号再 `-w` 一次即可。

reboot 后确认开机带号：

```bash
cat /proc/cmdline
```

应有 `snum=` 和 `androidboot.serialno=`。
