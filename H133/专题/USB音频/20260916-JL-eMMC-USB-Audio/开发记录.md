# JL-M101 打开 USB Audio（2.4G 空鼠麦）

- 日期：2026-09-16
- 板级：首验 `p1_emmc_JL_M101`；补丁对各板相同
- 设备：`Tmall.c0m 2.4G Wireless Air Mouse`（`7045:2018`）
- 目标：内核枚举 USB Audio，开 Mixer 后长按语音键，用 `arecord` 采到有效 PCM

> **说明（同日傍晚）**：中途已 **更换遥控器**。此前针对旧遥控的空鼠无位移、部分「必卸 HID / 短窗才可录」等对照结论 **一律不作数**。下文以 **录音流程与板上配置** 为准。

## 1. 接口与前提

| 接口 | class | 含义 | 驱动 |
|---|---|---|---|
| `*:1.0` | `01/01` | Audio Control | `snd-usb-audio` |
| `*:1.1` | `01/02` | Audio Streaming | `snd-usb-audio` |
| `*:1.3` | `03` | HID 键盘（`KEY_F24`） | hid-generic |
| `*:1.4` | `03` | HID 鼠标 | hid-generic |

改前 `config-5.4` 为 `# CONFIG_SND_USB is not set`，只有 HID、无 USB 采集节点。

- 接收头挂在 **usbc0 → ehci0/ohci0**（现场设备节点常见 `2-1`，以当时 sysfs 为准）。
- 声卡名一般为 `Mouse`（`/proc/asound/cards`）。
- 描述符 `invalid interface number: 4` / `no interface number 2` 为 warning，可忽略。

## 2. 配置改动

所有板件打同一套补丁，改该板的 `bsp_defconfig` / `config-5.4` / `board.dts`。

### 2.1 内核：打开 USB Audio

真正加载的是 **`openwrt/bsp_defconfig`**。`linux-5.4/config-5.4` 同步改，作备份。

```text
CONFIG_SND_HWDEP=y
CONFIG_SND_RAWMIDI=y
CONFIG_SND_USB=y
CONFIG_SND_USB_AUDIO=y
```

本板未开 `MEDIA_CONTROLLER`，不设 `CONFIG_SND_USB_AUDIO_USE_MEDIA_CONTROLLER`。

改完 `bsp_defconfig` 后若 `out/h133/kernel/build/.config` 偏旧，需删掉再编：

```sh
rm -f out/h133/kernel/build/.config
./tools/build_<当前板件>.sh kernel
```

补丁：`patches/0001-jl-emmc-enable-snd-usb-audio.patch`

### 2.2 DTS：usbc0 默认 Host

原 `usb_port_type = <0x0>`（从机）时 EHCI0/OHCI0 不能稳定作 Host。已改为：

```dts
&usbc0 {
	usb_port_type = <0x1>;   /* 1=host */
```

补丁：`patches/0002-jl-emmc-usbc0-default-host.patch`  
PB11/PB12 仍给京龙屏，ID 检测保持注释。

注意：这两个 sysfs **一读就切角色**（不是读状态）：

| 节点 | 效果 |
|---|---|
| `.../usb_host` | 切 Host |
| `.../usb_device` | 切 Device（接收头立刻没） |

usbc0 默认 Host 后，ADB/RNDIS 若走此口会受影响。

## 4. 录音流程（主流程）

插上接收头，确认有 USB 声卡后按下列步骤。

### 4.1 确认声卡

```sh
cat /proc/asound/cards
arecord -l
```

期望出现类似：`Mouse` / `USB-Audio - 2.4G Wireless Air Mouse`。

可选稳住电源管理（设备路径以现场为准，常见 `2-1`）：

```sh
echo -1 > /sys/module/usbcore/parameters/autosuspend
echo on > /sys/bus/usb/devices/2-1/power/control
```

### 4.2 打开 Mixer（必做）

未开时 wav 长度可正常但 **peak=0（全静音）**：

```sh
amixer -c Mouse cset numid=3 1    # Mic Capture Volume
amixer -c Mouse cset numid=2 on   # Mic Capture Switch
```

### 4.3 语音键

| 项 | 值 |
|---|---|
| 节点 | `/dev/input/usb-kbd`（多为 `event4`） |
| 键码 | `KEY_F24` = 194 |
| 物理键 | 遥控器 **蓝色麦克风键**，录音期间 **按住并说话** |

可选确认：`hexdump -C /dev/input/usb-kbd`

### 4.4 录制

```sh
arecord -D hw:Mouse,0 -f S16_LE -r 16000 -c 1 -d 10 /tmp/tmall_f24.wav
ls -l /tmp/tmall_f24.wav   # 10s 约 320044 字节
```

卡号也可用 `hw:3,0`（以 `arecord -l` 为准）。  
dmesg 若出现 `retire_capture_urb: ... suppressed`，多为等时传输告警；短录仍可录满。

### 4.5 成功判据

- 文件大小与时长匹配（10s ≈ 320044 B @ 16 kHz / S16 / mono）
- PCM **peak 明显非 0**（样例 peak 约 13000～21000）
- 导出样例：`artifacts/tmall_f24.wav`

### 4.6 掉线时

若 card 消失或 `arecord` I/O error：优先 **物理拔插接收头**，确认声卡回来后再从 §4.2 重做。  
避免反复 `cat .../usb_host` / `usb_device`（易把口打进异常状态）。

## 6. 附录：USB 注意点（非主流程）

- 设备常先短暂 EHCI HS，再落到 OHCI FS；超时日志里的 `-62` = `ETIMEDOUT`。
- 误 `cat .../usb_device` 会卸 Host；需再 `cat .../usb_host` 或拔插恢复。
- 旧遥控上做过的 HID 负载/空鼠位移等专项实验 **已作废**，换新遥控后不再作为结论引用。
- pack 若报 `boot.fex` 过大，加大该板 `boot` 分区即可。

## 7. 产品接入：独立 F24 PTT + CaptureUSB（2026-09-28）

方案全文：[`接入方案-F24与USB麦.md`](./接入方案-F24与USB麦.md)。

### 7.1 思路（当前定案）

```text
独立进程 aas_f24_ptt
  听 /dev/input 上 KEY_F24
  DOWN → aas_voice_start("tmall")
  UP   → aas_voice_stop("tmall")
       → ai_audio_sessiond → aas_capture（优先 CaptureUSB）→ ASR
```

- **不进** desk / LVGL。
- **不做** daemon 内嵌按键线程（会话与按键分离，定案为独立 `aas_f24_ptt`）。
- 与雷石 UI 同一入口：`libaas_client` → `/tmp/aas_cmd`。

### 7.5 已知问题：开机自启

- 镜像里已有 `/etc/rc.d/S83ai_audio_sessiond`、`S84aas_f24_ptt` 与二进制。
- 板子是 **busybox init**（无真正 `/sbin/procd`）；`/etc/rc.common` 用 stub：`procd_set_param command` → `exec $@`。
- **现场现象**：上电后 `ps` 里看不到两个进程；手动 `/etc/init.d/... start` 或直接跑二进制后，按键录音正常。
- `/tmp/processlog` 为空（未见 boot 写入的启动记录）。
- **后续**：待查 rcS 是否真正执行到 S83/S84、`exec` 与后台 `&` 是否导致中途退出；再决定改 init 脚本（非 procd 直启）或别处拉起。**暂不改代码**，先记在此。

其它：无 `/etc/aas/secrets.env` 时 ASR `missing credentials`；`evt publish failed` 无读者时可忽略。
