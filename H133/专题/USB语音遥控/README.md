# USB 语音遥控

2.4G USB 接收器：HID 按键 + USB Audio 麦。按键走现成 `usb-kbd`；语音麦要开 `snd-usb-audio`，AAS 按键选麦，不顶替板载 AC107。

## 产品一句话

按住遥控语音键只采遥控麦；机身语音仍采 AC107。两路同时按，先按的算数。没插接收器按语音键就失败，不会偷偷改走机身麦。
