## 1. 改前 → 改后

| 板件 | 改前 color / contrast | 改后 |
|---|---|---|
| 多数板（JL_M101 / HXR / K1 / 4k / 8733 / JYY070 / LQ140 NOR / LQ190 / p1_nor / p2 / fastboot） | 90 / 55 | **50 / 50** |
| `p1_emmc_LQ140M1JW61` | 60 / 45 | **50 / 50** |

四个模式 `[standard]` `[dynamic]` `[mild]` `[user]` 相同。未动 `brightness`（仍 45）、`sharpness`（仍 0）。

## 2. 设置页「恢复默认」

`desk_huiyin` 的 `DESK_PQ_DEFAULT_COLOR` / `DESK_PQ_DEFAULT_CONTRAST` 从 90 / 55 改成 **50 / 50**，与 ini `[standard]` 对齐。只改宏，不改 PQ 通路。

`4K_app/app_depend` 是指向 `app_depend` 的软链，一份即可。

## 3. 生效注意

应用优先读 `/mnt/UDISK/setting.ini`。旧机上 UDISK 还是 90/55 时，刷新包也会被盖掉。删掉那份或改成 50/50 再开 desk。
