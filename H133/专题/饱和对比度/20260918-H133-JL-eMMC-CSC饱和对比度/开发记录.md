## 1. 结论（先看这个）

| 决策 | 取值 / 做法 |
|---|---|
| 饱和度 | **90**（`setting.ini` 的 `color`） |
| 对比度 | **55**（`setting.ini` 的 `contrast`） |
| 谁下发 | `desk` 启动时 `soc_write_pq()` 写 `enhance_saturation` / `enhance_contrast` |
| 不采用 | 改 `dev_disp.c`；开机脚本 echo sysfs |

本板 overlay `/etc/setting.ini` 已是 90 / 55，四个图像模式相同：

```ini
[standard]
contrast = 55
brightness = 45
color = 90
sharpness = 0
```

设置页「恢复默认」也是 55 / 90。

---

## 2. 应用怎么调

`desk_huiyin` 开机：

1. `lv_init_pq()` → 写 `enhance_mode`
2. 读 `setting.ini`
3. `set_all_pq_for_current_picture_mode()` → 下发对比度 / 颜色

| 文件 | 作用 |
|---|---|
| `app_depend/desk_huiyin/src/projector_port/pq/pq_control.c` | `soc_write_pq()` |
| `app_depend/desk_huiyin/src/main.c` | `desk_system_init_early()` + `lv_init_sys_param_late()` |
| 板级 `busybox-init-base-files/etc/setting.ini` | 默认值 |

---

## 3. 板上命令

看当前值（desk 起来后期望 `90 90`、`55 55`）：

```bash
cat /sys/class/disp/disp/attr/enhance_saturation
cat /sys/class/disp/disp/attr/enhance_contrast
```

手动改（立刻生效；重启后仍由 `desk` 按 `setting.ini` 再下发）：

```bash
echo 90 > /sys/class/disp/disp/attr/enhance_saturation
echo 55 > /sys/class/disp/disp/attr/enhance_contrast
```

查配置（应用优先读 UDISK 那份；若仍是 50，多半是旧文件盖掉了 `/etc/setting.ini`）：

```bash
grep -E 'contrast|color' /mnt/UDISK/setting.ini /etc/setting.ini
```

UDISK 里不是 55/90 就改它，或删掉再开 desk。
