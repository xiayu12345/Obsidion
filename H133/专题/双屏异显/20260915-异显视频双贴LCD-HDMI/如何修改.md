# 如何改异显视频贴屏

产品路径只改 **`sunxi_disp_video_screen_mask()`**。`tlayer` / `videoOutPort` 的 `disp_screen==3` 已按位掩码送两路，不要再写死 `2`。

```text
platform/allwinner/display/libuapi/src/disp_dual.c
platform/allwinner/display/libuapi/src/include/disp_dual.h
platform/allwinner/display/libuapi/src/disp_mode_cli.c
```

改完只重编 `libuapi` 再 pack，禁止在 WSL 对源码树本地 `gcc -c`。

---

## 1. 异显视频上哪几路

`sunxi_disp_video_screen_mask()`（已插 HDMI 时）：

| 返回值 | 效果 |
|---|---|
| `1` | 只 LCD（同显；HDMI 靠 WB） |
| `2` | 只 HDMI（20260806 旧异显） |
| `3` | LCD + HDMI（本次定稿） |

未插 HDMI 必须继续返回 `1`。

切完要停播再播，`LayerCreate` 才重新读 mask。

## 2. HDMI 要电视全屏时

当前 `disp_dual_scale_win` 把 LCD `video_screen` **等比**映射到 HDMI。点歌小窗则电视上也是小窗。

若电视要 0,0,screen1_w × screen1_h 全屏，再改：

```text
platform/allwinner/display/libuapi/src/videoOutPort.c   ← disp_dual_scale_win
```

不要把 mask 改回 2 来「借」`LayerSetDisplayRect` 里 `disp_screen==2` 的全屏 override（那条会让 LCD 没视频层）。

## 3. 不要动的

- 内核 WB / `SET_HDMI_OUT` / fb clone
- 同显仍 mask=1
- 不要为两路出图去 `DISP_DUAL_DISPLAY_DISABLE`
