## 1. 需求

20260806 定稿的 **② 第一版**是：异显 **视频只贴 HDMI**（`video_screen=2`），LCD 只留 UI。产品改为 **③**：异显**播放视频时 HDMI 和 LCD 都有画面**。

空闲未播时 HDMI 仍可能无图（WB 层关掉、又没有视频层）——这次不改。

---

## 2. 决策

全志 `videoOutPort.c` 的 `disp_screen` 是位掩码：

| 值 | 含义 |
|---|---|
| **1** | 只贴 DE0 / LCD |
| **2** | 只贴 DE1 / HDMI |
| **3** | 同一层同时贴两路 |

`tlayer_ctrl.c` 里 `disp_screen==3` 的双屏送显、竖屏旋转、HDMI 按 LCD 窗口等比缩放（`disp_dual_scale_win`）**已经写好**。卡点只在 `sunxi_disp_video_screen_mask()` 异显仍返回 2。

| 做 | 不做 |
|---|---|
| 异显已插 HDMI：mask 返回 **3** | 不改内核、不改 WB、`SET_HDMI_OUT` |
| 更新 `disp_dual.h` / `disp_mode` 注释 | 不把 HDMI 改成电视全屏（等比缩放保留） |
| 同显仍返回 1 | 不改 `tlayer` / fence / fb clone |

`LayerCreate` 只在建层时读一次 mask，切完必须**停播再播**。

---

## 3. 改后行为

```text
disp_mode same  → SET_HDMI_OUT=1 + 下次播 screen=1（视频 LCD，HDMI=WB）
disp_mode diff  → SET_HDMI_OUT=0 + 下次播 screen=3（视频 LCD+HDMI）
未插 HDMI       → 强制 screen=1
```

HDMI 窗口跟 LCD `video_screen` **等比放大**，不是整屏。若电视要全屏，见 [如何修改.md](./如何修改.md)。

竖屏板（`VIDEO_WB_MIRROR_ROTATE=90`）走现成 `dualDispPreparePerScreen`：LCD 旋转、HDMI 横屏原图。横屏板 rot=0 两路都是横屏 buffer。

## 5. 编译 / 验收

只重编 OpenWrt **`libuapi`**（`disp_mode` 在同一包），再 pack。不要只编内核。

```bash
rm -rf out/h133/<板名>/openwrt/build_dir/target/libuapi
./build.sh openwrt_rootfs
./build.sh pack
```

首验镜像：`out/h133_linux_p1_emmc_JL_M101_uart0.img`（2026-09-15）。

| 步骤 | 期望 |
|---|---|
| 已插 HDMI，`disp_mode get`（异显） | `hdmi_out=0`，`video_screen=3` |
| 停播 → `diff` → 再点播 | LCD 视频窗有画面，HDMI 有同比视频窗 |
| `disp_mode same` 再播 | 同显恢复（视频 LCD，HDMI=WB 整屏） |
| 播中切换 | EBUSY |
| 未插 HDMI | 视频仍在 LCD（mask=1） |
