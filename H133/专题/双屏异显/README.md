# 双屏异显

MIPI/LCD（screen0）+ HDMI（screen1），跨板共用。同显一度是：视频在 LCD，HDMI 靠 WB 镜像整屏；
**⑤ 起产品取消了同显**，WB 降级成不自动启动的独立功能。

**画面走了五轮**，先看表，再进对应目录。当前产品行为以 [使用与构建.md](./使用与构建.md) 为准。

---

## 演进（按代读）

```text
同显（基线）
  LCD：UI + 视频
  HDMI：WB 镜像整屏（UI+视频一起过去）
        │
        ▼
① 最小验证  20260805
  编译期关掉 WB，视频死贴 HDMI
  只证明「异显通路能出片、能流畅」
  LCD 无视频；未播时 HDMI 也没有 UI
        │
        ▼
② 第一版    20260806
  WB 常开，切模式只关/开 HDMI 上的 WB 层
  异显 video_screen=2：视频只上 HDMI
  LCD 只留 UI（点歌窗是空的）
        │
        ▼
③ 迭代      20260915
  仍用 ② 的 WB 常开 / SET_HDMI_OUT
  异显 video_screen=3：同一层视频同时贴 LCD + HDMI
  设置页「异屏」= 这一档
        │
        ▼
④ 扩充      20260918
  SAME / DIFF 不动
  加 DIFF_HDMI：video_screen=2，LCD 没视频（机上命令，设置页未接）
        │
        ▼
⑤ 取消同显  20260920   ← 当前
  WB 不再自动启动，也不再参与切模式
  只剩两种，名字不变但含义搬家：
    SAME（设置页「同屏」）= 旧 DIFF   → mask 3，LCD+HDMI 都有
    DIFF（设置页「异屏」）= 旧 DIFF_HDMI → mask 2，只上电视
```

| 代 | 目录 | 异显 LCD | 异显 HDMI | 怎么贴视频 |
|---|---|---|---|---|
| ① 最小验证 | [20260805-HDMI异显最小验证/](./20260805-HDMI异显最小验证/) | 无视频 | 有视频 | 编译期关 WB，写死 `disp_screen=2`（**补丁已删**） |
| ② 第一版 | [20260806-同异显切换/](./20260806-同异显切换/) | 无视频（只 UI） | 有视频 | WB 常开；`SET_HDMI_OUT=0`；mask=**2** |
| ③ 迭代 | [20260915-异显视频双贴LCD-HDMI/](./20260915-异显视频双贴LCD-HDMI/) | **有视频** | **有视频** | 同上，只把 mask 改成 **3** |
| ④ 扩充 | [20260918-异显仅HDMI第三模式/](./20260918-异显仅HDMI第三模式/) | DIFF：有；DIFF_HDMI：**无** | 有视频 | 加 `diff_hdmi`（mask=**2**）；`diff` 仍是 3 |
| ⑤ 取消同显 | [20260920-取消WB同显-两模式/](./20260920-取消WB同显-两模式/) | 同屏：有；异屏：**无** | 有视频 | **WB 不再启动**；`same`=mask 3，`diff`=mask 2，删 `diff_hdmi` |

① 补丁与 ② 冲突，只留文字记录。② 的切换框架③④ 还在用，但 **⑤ 把其中的 WB 耦合层拆了**；
③ 只改选屏；④ 只加第三种模式；⑤ 取消同显并重新分配 `SAME` / `DIFF` 的含义。
