## 1. 需求

③ 把产品异显改成 **LCD+HDMI 都有视频**（`DIFF`，mask=`3`）。还需要一种 **LCD 没有视频、只上电视** 的异显，对应 ② 的 mask=`2`。

约束：

- `sunxi_disp_mode_set / get` **不改名**
- `SAME` / `DIFF` 语义不动
- 设置页「异屏」仍是 `DIFF`（两路都有）
- 不同显改成永久 `3`（同显 WB 与 HDMI 视频层抢 DE1 `ch0/lyr0`）

---

## 2. 决策

| 模式 | 值 | WB（`SET_HDMI_OUT`） | mask（已插 HDMI） | 设置页 |
|---|---|---|---|---|
| SAME | 0 | 开 | 1 | 同屏 |
| DIFF | 1 | 关 | 3 | 异屏（不变） |
| **DIFF_HDMI** | **2** | 关 | **2** | **未接**；机上 `disp_mode diff_hdmi` |

未插 HDMI 仍强制 mask=`1`。播中切仍 `-EBUSY`。切完须停播再播。

`tlayer` 里 `disp_screen==2` 的 HDMI 整屏覆盖、`fenceScreenId` 跟 screen1：**留给 DIFF_HDMI**，本代不改 `tlayer`。

---

## 3. 改动文件

只动 libuapi 三文件。内核、`tlayer`、设置页、`ktv_player_ui` **不改**。

| 文件 | 改什么 |
|---|---|
| `disp_dual.h` | 枚举加 `SUNXI_DISP_MODE_DIFF_HDMI = 2` |
| `disp_dual.c` | `set` 认 2；`mode_load` 可读 2；DIFF_HDMI 返回 mask=`2`；两种异显都关 WB |
| `disp_mode_cli.c` | 加 `diff_hdmi` |

---

## 4. 编译 / 验收

只重编 OpenWrt **`libuapi`**，再 pack。

```bash
rm -rf out/h133/<板名>/openwrt/build_dir/target/libuapi
./build.sh openwrt_rootfs
./build.sh pack
```

| 步骤 | 期望 |
|---|---|
| 设置页选异屏，停播再点播 | 与 ③ 相同：LCD+HDMI 都有视频，`video_screen=3` |
| 停播 → `disp_mode diff_hdmi` → 再点播 | LCD 点歌窗空，视频只 HDMI，`video_screen=2` |
| `disp_mode diff` 再播 | 回到两路都有 |
| `disp_mode same` 再播 | 同显（视频 LCD，HDMI=WB） |
| 播中切换 | EBUSY |
