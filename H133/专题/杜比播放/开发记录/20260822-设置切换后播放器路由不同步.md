# 设置切换 HDMI / SPDIF 后播放器路由不同步

| 项 | 内容 |
|---|---|
| 日期 | 2026-08-22 |
| 范围 | **杜比 / libaudioroute 方案**（跨板型，非京龙专属） |
| 状态 | **待修**（记录问题，后续处理） |
| 关联 | `tsound_ctrl.c` mode 文件同步、`desk_setting_param.c`、FIFO `REOPEN_SOUND` |

---

## 现象

1. **开机**默认 HDMI，播放杜比/普通视频 → HDMI 有声 ✅  
2. 设置切 **SPDIF（喇叭）** 再切回 **HDMI** → 再播 → **HDMI 无声** ❌  
3. 仅改设置、不重启 / 不杀 `media_sessiond`，问题可稳定复现  

与「京龙屏参、触摸、MIPI」无关；凡走 **desk + media_session + libaudioroute** 的板子均可能遇到。

---

## 根因

### 1. desk 与 media_session 各一份 Audio HAL

| 操作 | desk 进程 | media_session / tplayer |
|------|-----------|-------------------------|
| 设置切路由 | `adev_set_output_device` + `audio_route.sh` 写 `/etc/audio_output.mode` | **不通知** |
| 建声卡 | — | 仅在 `TSoundDeviceCreate` 读 mode 文件定 `OUT_HDMI_ARC` / `OUT_SPK` |

设置改的是 desk 和 mode 文件；**正在跑的播放器声卡类型不变**。

### 2. 典型恶化路径

```
开机 hdmi → 播放器 sndi2s2 (OUT_HDMI_ARC) → 正常
  ↓ 设置 spdif，中间若重建播放器
播放器读 spdif → sndowa (OUT_SPK)
  ↓ 设置 hdmi（只改文件 + desk adev）
播放器仍绑 sndowa → 声音走 MCU，电视 HDMI 无声
```

### 3. 已有能力未接上

工程里已有：

- `ms_changba_reopen_sound_route()` → FIFO `REOPEN_SOUND`
- `ktv_player_ui_reopen_sound_route()` → 重建播放器，会重新 `TSoundDeviceCreate` 读 mode

**`desk_setting_param.c` 切 `P_SOUND_OUT_MODE` 时未调用上述接口。**

---

## 临时规避

设置切路由后任选其一：

```bash
# 1. 重启播放守护（会重建播放器）
killall media_sessiond

# 2. 若 FIFO 可用
echo REOPEN_SOUND changba > /tmp/media_session_cmd
```

---

## 建议修复（未实施）

在 `desk_setting_audio_param()` 的 `P_SOUND_OUT_MODE` 分支，`audio_route.sh` 成功后：

```c
#include "ms_changba.h"

/* audio_set_output_device + desk_setting_apply_audio_route 之后 */
(void)ms_changba_init();  /* 若尚未 init */
ms_changba_reopen_sound_route();
```

同步改：`app/desk` 与 `4K_app/desk` 两处 `desk_setting_param.c`。  
`ms_changba_reopen_sound_route` 在播放器未 init 时为 no-op，可安全调用。

**注意**：`openSoundDevice` 内禁止再调 `syncAdevOutputRoute`（会触发 `handleAudioDeviceChange` 与 `TSoundDeviceStart` 抢 mutex 死锁）；路由同步应靠 **重建播放器** 或 **REOPEN_SOUND**，不要在持锁路径里 `adev_set_output_device` 回调。

## 验收（修完后）

1. 开机 HDMI 播 AC3 → 电视有声  
2. 设置 → SPDIF → 播一首 → 喇叭有声  
3. 设置 → HDMI → **不重启** → 再播 AC3 → 电视有声；log 有 `snd_type=32`、`pcm_open card:0`  
4. 设置切换时 log 有 `REOPEN_SOUND` / `[KTV_UI] reopen sound route`
